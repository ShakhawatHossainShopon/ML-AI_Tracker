স্মার্ট স্টোর বিলিং ইঞ্জিন (Billing & Scoring Engine)

মোবাইলে পড়ার জন্য সম্পূর্ণ প্রজেক্টের কোড-বাই-কোড লাইনভিত্তিক ব্রেকডাউন। কোনো কোড রান করার প্রয়োজন নেই—স্ক্রিন দেখেই ইনপুট, আউটপুট ও লজিক পরিষ্কারভাবে বুঝে নিন।

০০ প্রজেক্টের রিয়েল-লাইফ দৃশ্যপট

আমরা একটি সুপারশপের অটোমেটিক বিলিং ও প্রাইস অ্যানালাইসিস ইঞ্জিন তৈরি করছি:

  • ধাপ ০১: ১ জন কাস্টমার ৩টি জিনিস কিনলে ভেক্টর ডট প্রোডাক্ট দিয়ে নিমেষেই মোট বিল বের করা।
  • ধাপ ০২: একসাথে ৩ জন কাস্টমার শপিং করলে ম্যাট্রিক্স-ভেক্টর গুণ দিয়ে এক ক্লিকে সবার আলাদা আলাদা বিল বের করা।
  • ধাপ ০৩: ধানমন্ডি ব্রাঞ্চ বনাম উত্তরা ব্রাঞ্চের পণ্যের দাম ভিন্ন হলে, ম্যাট্রিক্স-ম্যাট্রিক্স গুণ (@) দিয়ে বের করা কোন কাস্টমার কোন ব্রাঞ্চে গেলে কত বিল আসত!

০১ ধাপ ০১: একক কাস্টমারের বিল (Vector Dot Product)

কাস্টমার কিনেছে ৩ কেজি আপেল, ২ লিটার দুধ এবং ৫টি ডিম। প্রতিটির দাম যথাক্রমে ৫০ টাকা, ৯০ টাকা ও ১২ টাকা।

Python Code (Step 1) 
import numpy as np

# ১ জন কাস্টমারের পণ্যের পরিমাণ (1D Vector)
cart = np.array([3, 2, 5])

# প্রতি পণ্যের একক মূল্য (1D Vector)
unit_prices = np.array([50, 90, 12])

# ডট প্রোডাক্ট দিয়ে মোট বিল বের করা
single_customer_bill = np.dot(cart, unit_prices)

print("Total Bill for Customer 1:", single_customer_bill)
🖥️ টার্মিনাল আউটপুট (Terminal Output)
Total Bill for Customer 1: 390

🔍 কোড-বাই-কোড সহজ বাংলা ব্যাখ্যা:

cart = np.array([3, 2, 5])
১D অ্যারে তৈরি হলো। ৩টি সংখ্যা যথাক্রমে ৩টি পণ্যের পরিমাণ নির্দেশ করছে (আপেল ৩, দুধ ২, ডিম ৫)।
unit_prices = np.array([50, 90, 12])
আরেকটি ১D অ্যারে যাতে প্রতিটি পণ্যের নির্দিষ্ট দাম রাখা হয়েছে।
np.dot(cart, unit_prices)
ডট প্রোডাক্টের হিসাবটি ভেতরে এভাবে হয়েছে:
(3 × 50) + (2 × 90) + (5 × 12) = 150 + 180 + 60 = 390 টাকা। কোনো লুপ ছাড়াই এক নিমেষে সম্পূর্ণ বিল হিসাব হয়ে গেছে!

০২ ধাপ ০২: একসাথে একাধিক কাস্টমারের বিল (Matrix-Vector Mult)

দোকানে এবার ৩ জন কাস্টমার কেনাকাটা করেছেন। সবার অর্ডার একটি ২D টেবিল (ম্যাট্রিক্স)-এ সাজানো।

Python Code (Step 2) 
# ৩ জন কাস্টমারের ডেটা টেবিল (Shape: 3 Rows x 3 Cols)
customers_orders = np.array([
    [3, 2, 5],   # Customer 1 (আপেল ৩, দুধ ২, ডিম ৫)
    [1, 4, 10],  # Customer 2 (আপেল ১, দুধ ৪, ডিম ১০)
    [0, 2, 12]   # Customer 3 (আপেল ০, দুধ ২, ডিম ১২)
])

# টেবিলের সাথে প্রাইস ভেক্টরের গুণ
all_customers_bills = np.dot(customers_orders, unit_prices)

print("All Customers Bills:", all_customers_bills)
🖥️ টার্মিনাল আউটপুট (Terminal Output)
All Customers Bills: [390 530 324]

🔍 কোড-বাই-কোড সহজ বাংলা ব্যাখ্যা:

customers_orders টেবিলের শেপ হলো (3, 3)। ৩টি সারি মানে ৩ জন কাস্টমার, ৩টি কলাম মানে ৩ প্রকার পণ্য।
np.dot(customers_orders, unit_prices)
পাইথন ম্যাট্রিক্সের প্রতিটি রো-এর সাথে প্রাইস ভেক্টরকে ডট প্রোডাক্ট করেছে:
  • Customer 1: (3×50)+(2×90)+(5×12) = 390 টাকা
  • Customer 2: (1×50)+(4×90)+(10×12) = 530 টাকা
  • Customer 3: (0×50)+(2×90)+(12×12) = 324 টাকা
আউটপুট এসেছে ১D অ্যারে [390, 530, 324]। ১০০০ জন কাস্টমার হলেও এই একই এক লাইনের কোডেই সবার বিল বের হয়ে যেত!

০৩ ধাপ ০৩: মাল্টি-স্টোর তুলনা (Matrix-Matrix Mult: @)

এবার কোম্পানি জানতে চায়: যদি এই ৩ জন কাস্টমার ধানমন্ডি ব্রাঞ্চে কেনাকাটা করেন তবে কার কত খরচ হবে, আর উত্তরা ব্রাঞ্চে করলে কার কত খরচ হবে?

Python Code (Step 3) 
# দুটি ব্রাঞ্চের মূল্যের টেবিল (Shape: 3 Items x 2 Branches)
# Col 0: ধানমন্ডি ব্রাঞ্চ (আপেল ৫০, দুধ ৯০, ডিম ১২)
# Col 1: উত্তরা ব্রাঞ্চ   (আপেল ৪৮, দুধ ৯৫, ডিম ১০)
store_prices = np.array([
    [50, 48],
    [90, 95],
    [12, 10]
])

# আধুনিক @ অপারেটর দিয়ে ম্যাট্রিক্স ও ম্যাট্রিক্স গুণ
comparison_table = customers_orders @ store_prices

print("Comparison Table (Cols: Dhanmondi vs Uttara):")
print(comparison_table)
🖥️ টার্মিনাল আউটপুট (Terminal Output)
Comparison Table (Cols: Dhanmondi vs Uttara): [[390 384] [530 528] [324 310]]

🔍 কোড-বাই-কোড সহজ বাংলা ব্যাখ্যা:

store_prices হলো একটি (3, 2) ম্যাট্রিক্স। ৩টি রো হলো পণ্য, আর ২টি কলাম হলো ২টি ব্রাঞ্চ।
customers_orders @ store_prices
এখানে (3, 3) ম্যাট্রিক্সের সাথে (3, 2) ম্যাট্রিক্স গুণ হয়েছে।
শেপ ম্যাচিং রুল: কাস্টমার টেবিলের কলাম ৩ এবং স্টোর টেবিলের রো ৩ হুবহু মিলে গেছে! ফলাফল হয়েছে একটি নতুন (3, 2) টেবিল।
ফলাফলের রিয়েল-লাইফ অর্থ:
  • সারি ১ (Customer 1): ধানমন্ডিতে বিল ৩৯০ টাকা, উত্তরা ব্রাঞ্চে ৩৮৪ টাকা (উত্তরায় ৬ টাকা সাশ্রয়!)।
  • সারি ২ (Customer 2): ধানমন্ডিতে ৫৩০ টাকা, উত্তরায় ৫২৮ টাকা।
  • সারি ৩ (Customer 3): ধানমন্ডিতে ৩২৪ টাকা, উত্তরায় ৩১০ টাকা।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

ভবিষ্যতে পিসিতে টেস্ট করার জন্য পুরো প্রজেক্টটি একসাথে দেখতে চাইলে:

applied.py 
import numpy as np

# ১. একক কাস্টমার
cart = np.array([3, 2, 5])
unit_prices = np.array([50, 90, 12])
single_customer_bill = np.dot(cart, unit_prices)

# ২. একাধিক কাস্টমার
customers_orders = np.array([
    [3, 2, 5],
    [1, 4, 10],
    [0, 2, 12]
])
all_customers_bills = np.dot(customers_orders, unit_prices)

# ৩. মাল্টি-স্টোর তুলনা
store_prices = np.array([
    [50, 48],
    [90, 95],
    [12, 10]
])
comparison_table = customers_orders @ store_prices

print("Single Bill :", single_customer_bill)
print("All Bills   :", all_customers_bills)
print("Store Bills :\n", comparison_table)
🎯 মোবাইলে মনে রাখার মূল কথা:
  • Vector · Vector = Single Number (১টি কার্টের মোট বিল)।
  • Matrix · Vector = 1D Array (অনেক কাস্টমারের মোট বিলের লিস্ট)।
  • Matrix @ Matrix = 2D Table (অনেক কাস্টমার × অনেকগুলো দোকানের মূল্যের তুলনা)।
