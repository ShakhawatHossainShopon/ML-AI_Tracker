Programmer Lab Phase 02 — Topic 05 NumPy Arrays

ভেক্টর ও ম্যাট্রিক্স: সহজ প্রোগ্রামার ল্যাব

ম্যাথের কোনো জটিল থিওরি নেই! একজন প্রোগ্রামার হিসেবে আমরা বুঝবো: ভেক্টর মানে ১D অ্যারে এবং ম্যাট্রিক্স মানে একটি সাধারণ ২D টেবিল।

০১ প্রোগ্রামারের চোখে ভেক্টর বনাম ম্যাট্রিক্স

  • Vector (ভেক্টর): ১ জন ব্যক্তির ডেটা — [বয়স, বেতন, ক্রেডিট স্কোর]। এটি ১D অ্যারে যার শেপ (3,)।
  • Matrix (ম্যাট্রিক্স): ৩ জন ব্যক্তির পুরো ডেটা টেবিল — Rows হলো ব্যক্তি এবং Columns হলো তাদের বৈশিষ্ট্য। এর শেপ (3, 3)।
  • Column Operations: টেবিলের নির্দিষ্ট কলাম নিয়ে কাজ করা (যেমন: সবার বেতনের গড় বের করা)।
আপনার ফাইলসমূহ:
  • main.py: আপনার রান ও টেস্ট করার ফাইল (কোনো কমেন্ট ছাড়া একবারে একটি করে সহজ ধাপ)।
  • applied.py: সম্পূর্ণ রেফারেন্স সল্যুশন (৩টি ধাপের পূর্ণাঙ্গ রূপ বাংলা কমেন্ট সহ)।

০২ রান ও টেস্টের নিয়ম

টার্মিনালে main.py চালিয়ে ধাপটি পরীক্ষা করুন:

python main.py PowerShell / CMD

সম্পূর্ণ কোডের আউটপুট দেখতে চাইলে:

python applied.py PowerShell / CMD
ওয়ার্কফ্লো: আপনি python main.py চালিয়ে আউটপুট দেখার পর চ্যাটে শুধু বলবেন "next" — আমি সাথে সাথে ধাপ ০২ (স্লাইসিং) যোগ করে দেবো!
