বিদ্যুৎ খরচ ও মোট রাজস্ব ক্যালকুলেটর (Cumulative Area Engine)

পরিবর্তনশীল লোডের প্রতি সেকেন্ডের পাওয়ার থেকে মোট বিদ্যুৎ ব্যবহার হিসাব করা।

০১ ধাপ ০১: ক্ষুদ্র স্লাইস দিয়ে ক্ষেত্রফল যোগ (Riemann Sum)

ফাংশন f(x) = 2x এর x = 0 থেকে x = 5 পর্যন্ত মোট ক্ষেত্রফল বের করা:

Python
def f(x):
    return 2 * x

a, b = 0.0, 5.0
n_slices = 1000
dx = (b - a) / n_slices

total_area = sum(f(a + i * dx) * dx for i in range(n_slices))
print('Approximate Area (Integral):', round(total_area, 4))
print('Exact Analytical Result    :', 25.0)
🖥️ Terminal Output
$ python -c "..."
Approximate Area (Integral): 24.9875
Exact Analytical Result    : 25.0

🔍 কোড ব্রেকডাউন:

dx = (b - a) / n: প্রতিটি ক্ষুদ্র স্লাইসের প্রস্থ (width)।
f(...) * dx: প্রতিটি আয়তক্ষেত্রের ক্ষেত্রফল (উচ্চতা × প্রস্থ)।
sum(...): সবগুলো স্লাইস যোগ করে মোট ক্ষেত্রফল বের করা হয়েছে (যা প্রায় ২৫.০)!

০২ ধাপ ০২: স্লাইস সংখ্যা বাড়িয়ে নিখুঁত মান পাওয়া

স্লাইস ১০০০ থেকে ১০,০০০ করলে রেজাল্ট কতটা নিখুঁত হয়:

Python
n_slices_large = 10000
dx_small = (b - a) / n_slices_large
refined_area = sum(f(a + i * dx_small) * dx_small for i in range(n_slices_large))
print('Refined Area (10,000 slices):', round(refined_area, 4))
🖥️ Terminal Output
$ python -c "..."
Refined Area (10,000 slices): 24.9988

🔍 কোড ব্রেকডাউন:

24.9988 ≈ 25.0: স্লাইস যত সূক্ষ্ম হয়, ইন্টিগ্রেশনের মান তত নিখুঁত বাস্তবতায় পৌঁছায়।

০৩ ধাপ ০৩: রিয়েল-লাইফ বিদ্যুৎ বিল হিসাব

ঘণ্টাপ্রতি বিদ্যুতের চাহিদা কার্ভ থেকে সারাদিনের মোট কিলোওয়াট-আওয়ার হিসাব:

Python
hourly_power = [1.2, 1.5, 2.0, 3.5, 4.0, 3.2, 2.1, 1.8]
total_kwh = sum(p * 1.0 for p in hourly_power)
print('Total Power Consumed (kWh):', total_kwh)
🖥️ Terminal Output
$ python -c "..."
Total Power Consumed (kWh): 19.3

🔍 কোড ব্রেকডাউন:

sum(power * dt): বাস্তব জীবনের এই যোগফলই হলো ইন্টিগ্রেশনের বাস্তব রূপ!

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
def f(x):
    return 2 * x

a, b = 0.0, 5.0
n = 10000
dx = (b - a) / n
area = sum(f(a + i * dx) * dx for i in range(n))
print('Integral of 2x from 0 to 5:', round(area, 4))
🖥️ Full Terminal Run
Integral of 2x from 0 to 5: 24.9988
🎯 মোবাইলে মনে রাখার সারমর্ম:
• ইন্টিগ্রেশন = অবিচ্ছিন্ন মোট যোগফল (Accumulation)।
• গ্রাফের নিচের ক্ষেত্রফল বের করার আধুনিক কোডিং পদ্ধতি。
• ডেটা সায়েন্সে সম্ভাব্যতা ও কিউমুলেটিভ মেজারমেন্টে ব্যবহৃত হয়।
