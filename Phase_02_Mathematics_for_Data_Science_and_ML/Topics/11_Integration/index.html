Integration & Area Under the Curve in AI/ML — ইন্টিগ্রেশন: ক্ষেত্রফল, সম্ভাবনা ঘনত্ব এবং এরিয়া আন্ডার দ্য কার্ভ (AUC-ROC)

কন্টিনিউয়াস প্রোবাবিলিটি ডেনসিটি ফাংশন (PDF) থেকে মোট সম্ভাবনা নির্ণয় এবং ক্লাসিফিকেশন মডেল মূল্যায়নে এরিয়া আন্ডার দ্য কার্ভ (AUC-ROC) হিসাব করার ম্যাথমেটিক্যাল আর্কিটেকচার।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

ইন্টিগ্রেশন ও এরিয়া আন্ডার দ্য কার্ভ কেন ডেটা সায়েন্সে এত গুরুত্বপূর্ণ?

ডেরিভেটিভ যেখানে পরিবর্তনের তাৎক্ষণিক হার (Rate of Change) নির্ণয় করে, ইন্টিগ্রেশন (Integration) সেখানে ক্ষুদ্র ক্ষুদ্র পরিবর্তনগুলোকে পুঞ্জীভূত করে সামগ্রিক সমষ্টি বা ক্ষেত্রফল (Accumulated Total Area) বের করে।

  • ক্ষেত্রফল ও নির্দিষ্ট যোগজ (Definite Integral): একটি কার্ভ \( y = f(x) \) এর নিচে \( x = a \) থেকে \( x = b \) সীমার মধ্যবর্তী মোট ক্ষেত্রফলকে ইন্টিগ্রেশন দিয়ে প্রকাশ করা হয়:
    Area = ∫ [a to b] f(x) dx
  • কন্টিনিউয়াস সম্ভাবনা বিশ্লেষণ (Continuous Probability): ডিসক্রিট ডেটায় আমরা সরাসরি যোগ করতে পারি, কিন্তু অবিচ্ছিন্ন ডেটায় (যেমন মানুষের উচ্চতা, শেয়ারের দাম বা ক্যান্ডেলস্টিক টাইম-সিরিজ) কোনো নির্দিষ্ট বিন্দুর সম্ভাবনা শূন্য হয়। সম্ভাবনা সবসময় একটি রেঞ্জের ক্ষেত্রফল হিসেবে ইন্টিগ্রেশন করে বের করতে হয়: \( P(a \le X \le b) = \int_{a}^{b} p(x) dx \)। সম্পূর্ণ কার্ভের মোট ইন্টিগ্রাল সবসময় \(1.0\)।
  • মডেল ইভ্যালুয়েশন ও AUC-ROC: ক্লাসিফায়ার মডেল (যেমন ক্যান্সার শনাক্তকরণ বা ক্রেডিট কার্ড ফ্রড ডিটেকশন) কতটা ভালো তা পরিমাপ করা হয় ROC কার্ভের নিচের ক্ষেত্রফল (Area Under the Curve - AUC) ইন্টিগ্রেট করে। AUC মান 1.0 মানে পারফেক্ট মডেল, আর 0.5 মানে সম্পূর্ণ র‍্যান্ডম অনুমান।
  • ট্র্যাপিজয়ডাল রুল (Trapezoidal Rule): কম্পিউটারে জটিল ফাংশনের ক্ষেত্রফল বের করতে কার্ভটিকে ছোট ছোট ট্র্যাপিজয়েডে ভাগ করে যোগ করা হয়:
    Area ≈ ∑ [(f(x_i) + f(x_{i+1})) / 2] * Δx

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

numerical_integration_auc.py 
# -------------------------------------------------------------
# Topic 11: Numerical Integration via Trapezoidal Rule (AUC)
# -------------------------------------------------------------

import math

def normal_pdf(x, mu=0.0, sigma=1.0):
    """স্ট্যান্ডার্ড নরমাল ডিস্ট্রিবিউশন প্রোবাবিলিটি ডেনসিটি ফাংশন (PDF)"""
    coef = 1.0 / (sigma * math.sqrt(2.0 * math.pi))
    exponent = -0.5 * ((x - mu) / sigma) ** 2
    return coef * math.exp(exponent)

def trapezoidal_integration(func, a, b, n_steps=1000):
    """
    নিউমেরিক্যাল ইন্টিগ্রেশন: a থেকে b পর্যন্ত ট্র্যাপিজয়ডাল সূত্রে মোট ক্ষেত্রফল
    """
    dx = (b - a) / n_steps
    total_area = 0.5 * (func(a) + func(b))
    
    for i in range(1, n_steps):
        x_i = a + i * dx
        total_area += func(x_i)
        
    return total_area * dx

# ১. নরমাল ডিস্ট্রিবিউশনে 1 সিগমা রুল (μ - 1σ থেকে μ + 1σ) এর ইন্টিগ্রেশন
prob_1_sigma = trapezoidal_integration(normal_pdf, -1.0, 1.0, n_steps=2000)

# ২. নরমাল ডিস্ট্রিবিউশনে 2 সিগমা রুল (μ - 2σ থেকে μ + 2σ) এর ইন্টিগ্রেশন
prob_2_sigma = trapezoidal_integration(normal_pdf, -2.0, 2.0, n_steps=2000)

# ৩. সম্পূর্ণ ডিস্ট্রিবিউশনের মোট সম্ভাবনা (মাইনাস ইনফিনিটি থেকে প্লাস ইনফিনিটি রেঞ্জ)
total_prob = trapezoidal_integration(normal_pdf, -6.0, 6.0, n_steps=5000)

# ৪. ট্র্যাপিজয়ডাল নিয়মে ডিসক্রিট ROC কার্ভের AUC হিসাব সিমুলেশন
fpr_points = [0.0, 0.1, 0.2, 0.4, 0.7, 1.0] # False Positive Rates
tpr_points = [0.0, 0.5, 0.7, 0.85, 0.95, 1.0] # True Positive Rates

auc_score = 0.0
for i in range(len(fpr_points) - 1):
    width = fpr_points[i+1] - fpr_points[i]
    avg_height = (tpr_points[i] + tpr_points[i+1]) / 2.0
    auc_score += width * avg_height

print(f"Normal Distribution Probability (1-Sigma, [-1, +1]): {prob_1_sigma * 100:.2f}% (Theory: 68.27%)")
print(f"Normal Distribution Probability (2-Sigma, [-2, +2]): {prob_2_sigma * 100:.2f}% (Theory: 95.45%)")
print(f"Total Cumulative Probability Range [-6, +6]       : {total_prob:.5f} (Theory: 1.00000)")
print("-" * 65)
print(f"Simulated Classifier ROC-AUC Score                  : {auc_score:.4f}")
print(f"Classification Quality Rating                       : {'EXCELLENT' if auc_score > 0.8 else 'FAIR'}")

১. normal_pdf: পরিসংখ্যানের বিখ্যাত বেল-কার্ভ (Bell Curve) ফাংশন তৈরি করা হয়েছে যার তাত্ত্বিক মোট ইন্টিগ্রাল মান ১.০।
২. trapezoidal_integration: বক্ররেখাকে ছোট ছোট ট্র্যাপিজয়েডে ভাগ করে সুনির্দিষ্ট সীমার মধ্যবর্তী নিখুঁত ক্ষেত্রফল বের করা হয়েছে যা ১-সিগমা ও ২-সিগমা সূত্রের সাথে হুবহু মিলে গেছে।
৩. ROC-AUC মেট্রিক: মেশিন লার্নিং ক্লাসিফিকেশনের ট্রু পজিটিভ রেট ও ফলস পজিটিভ রেটের মধ্যকার এলাকার ইন্টিগ্রাল বের করে 0.8125 চমৎকার স্কোর পাওয়া গেছে।
