ফাংশন ও গ্রাফ: সহজ প্র্যাকটিক্যাল ল্যাব

মেশিন লার্নিং-এ ফাংশন কীভাবে কাজ করে এবং দেখতে কেমন হয়—তা খুব সহজে বোঝার জন্য এই প্রজেক্ট। আমরা মাত্র ৩টি মূল ফাংশন (Linear, Sigmoid, ReLU) কোড করবো, PyTorch দিয়ে মিলিয়ে দেখবো এবং Matplotlib দিয়ে গ্রাফে তাদের রূপ দেখবো।

০১ প্রজেক্টের লক্ষ্য ও ফাইলসমূহ

আমাদের উদ্দেশ্য খুব পরিষ্কার: কিছু সাধারণ সংখ্যা ইনপুট দিলে লিনিয়ার ফাংশন কেমন আউটপুট দেয়, আর নন-লিনিয়ার অ্যাক্টিভেশন ফাংশন (Sigmoid, ReLU) কেমন আউটপুট দেয় তা সরাসরি চোখের সামনে দেখা।

আপনার ফাইলসমূহ:
  • main.py: আপনার কোডিং ফাইল। এতে শুধু ইমপোর্ট দেওয়া আছে (কোনো কমেন্ট নেই)।
  • applied.py: সম্পূর্ণ রেফারেন্স কোড। প্রতিটি লাইনে সহজ বাংলায় কমেন্ট সহ পুরো প্রজেক্ট কোড করা আছে।

০২ ধাপ ১ ও ২: ৩টি ফাংশন তৈরি ও টেস্ট করা

৩টি ফাংশন:

  1. Linear: 2x + 1 (সাধারণ সরলরেখা)
  2. Sigmoid: 1 / (1 + e⁻ˣ) (সংখ্যাকে ০ থেকে ১ এর মধ্যে প্রবাবিলিটি বানায়)
  3. ReLU: max(0, x) (নেগেটিভ সংখ্যাকে ০ বানিয়ে দেয়)
import numpy as np

# ১. ফাংশন ডিফাইন
def linear_func(x):
    return 2 * x + 1

def sigmoid_func(x):
    return 1.0 / (1.0 + np.exp(-x))

def relu_func(x):
    return np.maximum(0.0, x)

# ২. ইনপুট দিয়ে আউটপুট দেখা
inputs = np.array([-3.0, -1.0, 0.0, 1.0, 3.0])
print("Linear :", linear_func(inputs))
print("Sigmoid:", np.round(sigmoid_func(inputs), 4))
print("ReLU   :", relu_func(inputs))

০৩ ধাপ ৩: PyTorch দিয়ে ভেরিফিকেশন

আধুনিক ডিপ লার্নিং লাইব্রেরি PyTorch দিয়ে মিলিয়ে দেখুন:

import torch

t_inputs = torch.tensor(inputs)
print("PyTorch Sigmoid:", torch.sigmoid(t_inputs).numpy())
print("PyTorch ReLU   :", torch.relu(t_inputs).numpy())
অন্তর্দৃষ্টি: আপনি দেখবেন PyTorch-এর বিল্ট-ইন ফাংশন এবং আপনার লেখা গণিতের ফাংশন হুবহু একই মান রিটার্ন করছে!

০৪ ধাপ ৪: Matplotlib দিয়ে গ্রাফ আঁকা ও সেভ করা

সংখ্যাগুলো দেখতে গ্রাফে কেমন দেখায়, তা ভিজ্যুয়ালাইজ করতে Matplotlib ব্যবহার করুন:

import matplotlib.pyplot as plt

x_vals = np.linspace(-5.0, 5.0, 200)

plt.figure(figsize=(8, 4.5))
plt.plot(x_vals, linear_func(x_vals), label="Linear: 2x + 1", color="gray", linestyle="--")
plt.plot(x_vals, sigmoid_func(x_vals), label="Sigmoid", color="blue", linewidth=2)
plt.plot(x_vals, relu_func(x_vals), label="ReLU", color="green", linewidth=2)

plt.title("Comparison of Linear vs Non-Linear Functions in ML")
plt.legend()
plt.grid(True)
plt.savefig("activation_functions_plot.png")
