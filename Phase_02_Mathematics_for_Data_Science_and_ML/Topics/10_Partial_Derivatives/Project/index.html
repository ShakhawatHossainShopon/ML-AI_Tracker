Project Breakdown Phase 02 — Topic 10 Mobile View

বাড়ি মূল্যায়ন ও সংবেদনশীলতা অ্যানালাইজার (Price Sensitivity Engine)

সাইজ এবং রুম সংখ্যার ওপর ভিত্তি করে বাড়ির মূল্যের পৃথক সংবেদনশীলতা হিসাব করা।

০১ ধাপ ০১: সাইজের সাপেক্ষে পার্শিয়াল ডেরিভেটিভ (∂f/∂size)

রুম সংখ্যা অপরিবর্তিত রেখে শুধু সাইজ ১ স্কয়ার ফিট বাড়ালে দাম কত বাড়ে:

Python
def price(size, rooms):
    return 50 * size + 20000 * rooms

h = 0.001
s, r = 1200, 3
d_price_d_size = (price(s + h, r) - price(s, r)) / h
print('Base Price:', price(s, r))
print('Rate of change wrt Size:', round(d_price_d_size, 2))
🖥️ Terminal Output
$ python -c "..."
Base Price: 120000
Rate of change wrt Size: 50.0

🔍 কোড ব্রেকডাউন:

price(size, rooms): সাইজ ও রুম সংখ্যার ফাংশন।
price(s+h, r): রুম সংখ্যা r স্থির রেখে শুধু সাইজে ক্ষুদ্র পরিবর্তন h যোগ করা হয়েছে।
∂price/∂size = 50.0: প্রতি ১ স্কয়ার ফিট সাইজ বৃদ্ধির জন্য দাম ৫০ টাকা বৃদ্ধি পায়।

০২ ধাপ ০২: রুমের সাপেক্ষে পার্শিয়াল ডেরিভেটিভ (∂f/∂rooms)

সাইজ অপরিবর্তিত রেখে শুধু রুম সংখ্যা ১টি বাড়ালে দাম কত বাড়ে:

Python
d_price_d_rooms = (price(s, r + h) - price(s, r)) / h
print('Rate of change wrt Rooms:', round(d_price_d_rooms, 2))
🖥️ Terminal Output
$ python -c "..."
Rate of change wrt Rooms: 20000.0

🔍 কোড ব্রেকডাউন:

price(s, r+h): সাইজ s স্থির রেখে শুধু রুমে পরিবর্তন h দেওয়া হয়েছে।
∂price/∂rooms = 20000.0: প্রতি ১টি বাড়তি রুমের জন্য দাম ২০,০০০ টাকা বৃদ্ধি পায়।

০৩ ধাপ ০৩: সংবেদনশীলতা ভেক্টর (Gradient Vector-এর সূচনা)

উভয় পার্শিয়াল ডেরিভেটিভকে একসাথে একটি ভেক্টরে সাজানো:

Python
sensitivity_vector = [round(d_price_d_size, 2), round(d_price_d_rooms, 2)]
print('Price Sensitivity Vector [Size, Rooms]:', sensitivity_vector)
🖥️ Terminal Output
$ python -c "..."
Price Sensitivity Vector [Size, Rooms]: [50.0, 20000.0]

🔍 কোড ব্রেকডাউন:

[50.0, 20000.0]: এটিই গ্র্যাডিয়েন্ট ভেক্টর—যা বলে দেয় কোন ভ্যারিয়েবলের প্রভাব কতটা শক্তিশালী!

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
def price(size, rooms):
    return 50 * size + 20000 * rooms

h = 0.001
s, r = 1200, 3
d_size = (price(s+h, r) - price(s, r)) / h
d_rooms = (price(s, r+h) - price(s, r)) / h
print('Base Price :', price(s, r))
print('Gradient   :', [round(d_size, 2), round(d_rooms, 2)])
🖥️ Full Terminal Run
Base Price : 120000
Gradient   : [50.0, 20000.0]
🎯 মোবাইলে মনে রাখার সারমর্ম:
• পার্শিয়াল ডেরিভেটিভ = বাকি সব স্থির রেখে শুধু ১টি ভ্যারিয়েবলের পরিবর্তনের হার।
• একাধিক ইনপুটযুক্ত যেকোনো সিস্টেমের জন্য এটি বাধ্যতামূলক。
• সব পার্শিয়াল ডেরিভেটিভকে এক সারিতে সাজালে গ্র্যাডিয়েন্ট তৈরি হয়।
