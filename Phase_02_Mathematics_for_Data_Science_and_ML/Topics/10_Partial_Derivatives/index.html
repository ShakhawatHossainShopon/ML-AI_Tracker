Partial Derivatives in Multivariable Loss Functions — আংশিক অন্তরীকরণ: একাধিক প্যারামিটার যুক্ত মডেলে একক ওয়েটের প্রভাব নির্ণয়

বাস্তব মেশিন লার্নিং মডেলে শত শত বা কোটি কোটি প্যারামিটার থাকে। অন্য সব ভ্যারিয়েবল স্থির রেখে একক প্যারামিটারের সাপেক্ষে লসের পরিবর্তন নির্ণয়ে পার্শিয়াল ডেরিভেটিভের ভূমিকা।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

মাল্টিভেরিয়েবল ক্যালকুলাস ও পার্শিয়াল ডেরিভেটিভ কেন অপরিহার্য?

বাস্তব জীবনে কোনো এআই বা মেশিন লার্নিং মডেল শুধুমাত্র একটি প্যারামিটারের ওপর নির্ভরশীল নয়। উদাহরণস্বরূপ, লিনিয়ার রিগ্রেশন মডেলে প্রেডিকশন হলো \( \hat{y} = w_1 x_1 + w_2 x_2 + b \)। এখানে দুইটি ওয়েট এবং একটি বায়াস রয়েছে।

  • আংশিক অন্তরীকরণ (Partial Derivatives) কী?: যখন কোনো ফাংশনে একাধিক চলক (Variables) থাকে, তখন অন্য সকল চলককে ধ্রুবক (Constant) ধরে রেখে শুধুমাত্র একটি নির্দিষ্ট চলকের সাপেক্ষে যে ডেরিভেটিভ নেওয়া হয়, তাকে পার্শিয়াল ডেরিভেটিভ বলে। একে প্রকাশ করা হয় ডেল চিহ্ন (\( \partial \)) দিয়ে।
  • 'Ceteris Paribus' নীতি: \( rac{\partial L}{\partial w_1} \) বের করার সময় আমরা ধরে নিই \( w_2 \) এবং \( b \) বরফের মতো জমে আছে (সম্পূর্ণ স্থির)। ফলে শুধুমাত্র \( w_1 \) পরিবর্তনের দরুন লস কতটুকু বদলাচ্ছে তা পরিষ্কারভাবে ধরা পড়ে।
  • গ্র্যাডিয়েন্ট ভেক্টরের ভিত্তি: প্রতিটি প্যারামিটারের পার্শিয়াল ডেরিভেটিভগুলোকে একটি সারিবদ্ধ ভেক্টরে সাজালে গঠিত হয় গ্র্যাডিয়েন্ট ভেক্টর (Gradient Vector):
    ∇L = [∂L/∂w1, ∂L/∂w2, ..., ∂L/∂wn]^T
  • ব্যাকপ্রোপাগেশন ইঞ্জিন: ডিপ লার্নিংয়ে যখন লক্ষ লক্ষ ওজন আপডেট করতে হয়, তখন চেইন রুল (Chain Rule) ও পার্শিয়াল ডেরিভেটিভ একসাথে কাজ করে প্রতিটি নিউরনের সুনির্দিষ্ট ভুল নির্ণয় করে।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

partial_derivatives_simulation.py 
# -------------------------------------------------------------
# Topic 10: Multivariable Partial Derivatives in Python
# -------------------------------------------------------------

def multivariable_loss(w1, w2):
    """
    দুইটি চলকবিশিষ্ট লস সারফেস:
    L(w1, w2) = 2*(w1 - 4.0)^2 + 3*(w2 + 2.0)^2 + 10.0
    গাণিতিক মিনিমাম: w1 = 4.0 এবং w2 = -2.0 (যেখানে L = 10.0)।
    """
    return 2.0 * (w1 - 4.0)**2 + 3.0 * (w2 + 2.0)**2 + 10.0

def compute_partial_w1(f, w1, w2, h=1e-5):
    """w2 কে অপরিবর্তিত রেখে w1 এর সাপেক্ষে পার্শিয়াল ডেরিভেটিভ"""
    return (f(w1 + h, w2) - f(w1, w2)) / h

def compute_partial_w2(f, w1, w2, h=1e-5):
    """w1 কে অপরিবর্তিত রেখে w2 এর সাপেক্ষে পার্শিয়াল ডেরিভেটিভ"""
    return (f(w1, w2 + h) - f(w1, w2)) / h

# একটি নির্দিষ্ট পয়েন্টে মডেল টেস্ট করা যাক
test_w1 = 2.0
test_w2 = 1.0

loss_val = multivariable_loss(test_w1, test_w2)
dL_dw1 = compute_partial_w1(multivariable_loss, test_w1, test_w2)
dL_dw2 = compute_partial_w2(multivariable_loss, test_w1, test_w2)

# অ্যানালিটিক্যাল মান: 
# dL/dw1 = 4*(w1 - 4) = 4*(2 - 4) = -8.0
# dL/dw2 = 6*(w2 + 2) = 6*(1 + 2) = +18.0
exact_dw1 = 4.0 * (test_w1 - 4.0)
exact_dw2 = 6.0 * (test_w2 + 2.0)

print(f"Current Weights       : w1 = {test_w1:.2f}, w2 = {test_w2:.2f}")
print(f"Current Loss Value    : {loss_val:.4f}")
print("-" * 55)
print(f"dL/dw1 (Numerical)    : {dL_dw1:+.5f} | Exact: {exact_dw1:+.5f}")
print(f"dL/dw2 (Numerical)    : {dL_dw2:+.5f} | Exact: {exact_dw2:+.5f}")
print("-" * 55)
print(f"Gradient Vector (∇L)  : [{dL_dw1:+.2f}, {dL_dw2:+.2f}]")
print(f"Update Strategy       : w1 needs to INCREASE (slope < 0)")
print(f"                        w2 needs to DECREASE (slope > 0)")

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

১. multivariable_loss(w1, w2): বাস্তব ডেটা সায়েন্সের মতো এখানে দুটি স্বাধীন প্যারামিটার রয়েছে যাদের যৌথ মান লস নির্ধারণ করে।
২. আইসোলেটেড স্টেপ সাইজ: compute_partial_w1 ফাংশনে শুধুমাত্র w1 কে w1 + h করা হয়েছে, কিন্তু w2 সম্পূর্ণ অপরিবর্তিত রাখা হয়েছে।
৩. গ্র্যাডিয়েন্ট ভেক্টর [ -8.00, +18.00 ]: ফলাফল আমাদের স্পষ্ট বার্তা দিচ্ছে: w1 বাড়ানো উচিত এবং w2 কমানো উচিত, যার ফলে লস সর্বনিম্ন বিন্দুর দিকে ধাবিত হবে।
