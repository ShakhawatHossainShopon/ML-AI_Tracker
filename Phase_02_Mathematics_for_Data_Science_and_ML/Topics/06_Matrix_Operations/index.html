ম্যাট্রিক্স অপারেশন (Matrix Operations)

ম্যাথের কোনো জটিল সূত্র মুখস্থ করার দরকার নেই! একজন প্রোগ্রামার হিসেবে বুঝুন: টেবিলের ডেটা যোগ-বিয়োগ করা, সব ডেটাতে একবারে ট্যাক্স বা ডিসকাউন্ট বসানো, এবং টেবিল উল্টানো (Transpose) কীভাবে হয়।

০১ প্রোগ্রামারের চোখে ম্যাট্রিক্স অপারেশন কী?

আগের টপিকে আমরা দেখেছি ম্যাট্রিক্স মানে আসলে একটি ২D ডেটা টেবিল (Rows এবং Columns)।

বাস্তব জীবনে প্রোগ্রামিং করার সময় আমাদের প্রায়ই এই টেবিলগুলোর সাথে বিভিন্ন কাজ করতে হয়:

  • দুটো শাখা বা ব্রাঞ্চের টেবিল যোগ করা: ধানমন্ডি ব্রাঞ্চের বিক্রয় + গুলশান ব্রাঞ্চের বিক্রয় = মোট বিক্রয়।
  • এক ক্লিকে পুরো টেবিলের দাম আপডেট করা: সব পণ্যে ১৫% ভ্যাট যোগ করা বা ১০% ছাড় দেওয়া।
  • টেবিল উল্টে দেখা (Transpose): রো-গুলোকে কলাম এবং কলামগুলোকে রো বানিয়ে নতুনভাবে সাজানো।

০২ ম্যাট্রিক্স যোগ ও বিয়োগ (Element-wise Addition)

খুব সহজ নিয়ম: একই পজিশনের সেল একই পজিশনের সেলের সাথেই যোগ হবে।

ধরুন আপনার দুটি ব্রাঞ্চে ৩টি পণ্যের জানুয়ারি ও ফেব্রুয়ারি মাসের বিক্রয় ডেটা আছে:

পণ্য ব্রাঞ্চ A (জানু, ফেব) ব্রাঞ্চ B (জানু, ফেব) মোট বিক্রয় (A + B)
Laptop [10, 15] [5, 8] [15, 23] (10+5, 15+8)
Phone [20, 25] [12, 10] [32, 35] (20+12, 25+10)
প্রোগ্রামারের সোনালী নিয়ম: দুটি ম্যাট্রিক্স যোগ বা বিয়োগ করতে হলে তাদের Shape (সারি ও কলামের সংখ্যা) হুবহু এক হতে হবে। অন্যথায় এরর আসবে। 
import numpy as np

branch_a = np.array([
    [10, 15],
    [20, 25]
])

branch_b = np.array([
    [5, 8],
    [12, 10]
])

total_sales = branch_a + branch_b
print(total_sales)
# আউটপুট:
# [[15 23]
#  [32 35]]

০৩ স্কেলার অপারেশন (Scalar Operations / Broadcasting)

"Scalar" (স্কেলার) মানে সাধারণ একটি একক সংখ্যা (যেমন: 5, 1.15, 0.10)।

সাধারণ পাইথনে নেস্টেড লুপ চালিয়ে পুরো লিস্টের প্রতিটি উপাদানকে গুণ করতে হতো। কিন্তু ম্যাট্রিক্সে সরাসরি একটি সংখ্যা দিয়ে গুণ বা যোগ করলে তা স্বয়ংক্রিয়ভাবে পুরো টেবিলের প্রতিটি সেলে অ্যাপ্লাই হয়ে যায়! 

prices = np.array([
    [100, 200],
    [300, 400]
])

# সব পণ্যে ১৫% ভ্যাট যোগ করতে ১.১৫ দিয়ে গুণ:
prices_with_tax = prices * 1.15
print(prices_with_tax)
# আউটপুট:
# [[115. 230.]
#  [345. 460.]]
মেশিন লার্নিংয়ে এর ব্যবহার: ইমেজ প্রসেসিংয়ে যখন একটি ছবির উজ্জ্বলতা (Brightness) বাড়ানো হয়, তখন ছবির পিক্সেল টেবিলের সব মানে একটি নির্দিষ্ট সংখ্যা যোগ করা হয়।

০৪ ট্রান্সপোজ (Transpose): টেবিল উল্টানো

এক্সেল ফাইলে যেমন "Paste Transpose" অপশন থাকে, ঠিক তেমনি প্রোগ্রামিংয়ে matrix.T দিলে টেবিলটির Row হয়ে যায় Column, আর Column হয়ে যায় Row!

  • যদি কোনো টেবিলের আকার হয় (2, 3) (২টি সারি, ৩টি কলাম),
  • ট্রান্সপোজ করার পর আকার হবে (3, 2) (৩টি সারি, ২টি কলাম)।
table = np.array([
    [10, 20, 30],
    [40, 50, 60]
])
print("আসল শেপ:", table.shape)  # (2, 3)

transposed_table = table.T
print("উল্টানোর পর শেপ:", transposed_table.shape)  # (3, 2)
print(transposed_table)
# আউটপুট:
# [[10 40]
#  [20 50]
#  [30 60]]
