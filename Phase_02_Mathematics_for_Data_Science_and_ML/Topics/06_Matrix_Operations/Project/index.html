Practical Lab Phase 02 — Topic 06 Matrix Operations

ম্যাট্রিক্স অপারেশন: প্র্যাকটিক্যাল ল্যাব গাইড

প্রজেক্টের নাম: Warehouse Inventory & Tax Manager। দুটি গুদামের পণ্যের খরচ যোগ করা, পুরো ইনভেন্টরিতে ট্যাক্স প্রয়োগ করা এবং ডেটা টেবিল উল্টানো (Transpose)।

০১ প্রজেক্টের ধাপসমূহ

  1. ধাপ ১ (ম্যাট্রিক্স যোগ): দুটি গুদামের খরচ টেবিল warehouse_1 + warehouse_2 যোগ করে মোট ইনভেন্টরি কস্ট বের করা। (এখন এটি main.py-তে আছে)।
  2. ধাপ ২ (স্কেলার মাল্টিপ্লিকেশন): পুরো টেবিলের প্রতিটা সেলে এক লাইনে ১৫% ভ্যাট/ট্যাক্স যোগ করা (* 1.15)।
  3. ধাপ ৩ (ম্যাট্রিক্স ট্রান্সপোজ): .T ব্যবহার করে টেবিলের রো এবং কলাম অদলবদল করা।
ফাইল স্ট্রাকচার:
  • main.py: আপনার রান ও টেস্ট করার ফাইল (কোনো কমেন্ট ছাড়া একবারে একটি করে সহজ ধাপ)।
  • applied.py: সম্পূর্ণ রেফারেন্স সল্যুশন (৩টি ধাপের পূর্ণাঙ্গ রূপ বাংলা কমেন্ট সহ)।

০২ রান ও টেস্টের নিয়ম

টার্মিনালে main.py চালিয়ে ধাপ ১ পরীক্ষা করুন:

python main.py PowerShell / CMD

সম্পূর্ণ কোডের ফলাফল দেখতে চাইলে:

python applied.py PowerShell / CMD
অগ্রগতির নিয়ম: আপনি python main.py চালিয়ে ধাপ ০১ বোঝার পর চ্যাটে লিখবেন "next" — সাথে সাথে ধাপ ০২ যুক্ত করে দেওয়া হবে।
