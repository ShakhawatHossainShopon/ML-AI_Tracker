০১ AI ও Machine Learning-এ বীজগণিত কেন লাগে?

আমরা যখন কোনো মেশিন লার্নিং মডেল বানাই—যেমন একটা বাড়ির দাম প্রেডিক্ট করা, শেয়ার বাজারের ট্রেন্ড বোঝা, অথবা কোনো রোগের ঝুঁকি নির্ণয় করা—ভেতরে কম্পিউটার কিন্তু কোনো জাদু করে না। কম্পিউটার আসলে কিছু Unknown Variables (অজানা মান বা Weights) খুঁজে বের করে, যাতে ইনপুটের সাথে গুণ ও যোগ করে সঠিক আউটপুট পাওয়া যায়।

সহজ কথা: মেশিন লার্নিং-এর মডেল ট্রেনিং মানে হলো এমন কিছু সমীকরণ সমাধান করা, যা আমাদের প্রেডিকশনের ভুল (Error বা Loss) একদম কমিয়ে ফেলে।

হাতে-কলমে সমীকরণ সমাধান করা সময়সাপেক্ষ এবং ডেটাসেটে যখন লাখ লাখ সংখ্যা থাকে তখন হাতে করা অসম্ভব। এজন্যই আমরা NumPy এবং SymPy লাইব্রেরি ব্যবহার করি, যা এক সেকেন্ডেরও কম সময়ে বিশাল সমীকরণ সিস্টেম সমাধান করে ফেলে।

০২ Linear Equation: AI মডেলের ভিত্তি

আমরা স্কুলে সরলরেখার যে সমীকরণ শিখেছিলাম: y = m*x + c, ঠিক এই জিনিসটাই মেশিন লার্নিং-এ লেখা হয় এভাবে:

y = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b যেখানে x = Features (ইনপুট), w = Weights (গুরুত্ব), b = Bias (ইন্টারসেপ্ট), y = Target (আউটপুট)

উদাহরণস্বরূপ, আপনি যদি বাড়ির দাম প্রেডিক্ট করতে চান:

  • x₁ = বেডরুমের সংখ্যা
  • x₂ = মোট স্কয়ার ফিট
  • w₁ ও w₂ = এই বৈশিষ্ট্যগুলোর প্রভাব বা ওজন (Weights)
  • b = বেইস মূল্য (Bias)

ভেক্টর আকারে এটাকে খুব সংক্ষেপে লেখা যায়: y = wᵀ · x + b।

০৩ সমীকরণ জোট (Systems of Linear Equations): A x = b

ধরা যাক আমাদের কাছে ২টি নমুনা বা ডেটা পয়েন্ট আছে এবং অজানা মান হলো x ও y:

2x + y = 5
x - 3y = -1

ম্যাট্রিক্স আকারে এটাকে আমরা বলি A · x = b: 

# ম্যাট্রিক্স A (Coefficients) এবং ভেক্টর b (Constants)
A = [[ 2,  1],
     [ 1, -3]]

b = [ 5, -1]

এখানে x = 2 এবং y = 1 বসালে দুটি সমীকরণই হুবহু মিলে যায়। হাজার হাজার ডেটা রো থাকলেও এই একই নিয়ম খাটে।

০৪ SymPy দিয়ে নির্ভুল সমাধান (Symbolic Algebra)

SymPy হলো পাইথনের একটা চমৎকার লাইব্রেরি যা কোনো দশমিক গোলমাল ছাড়াই বীজগণিতীয় সমীকরণ প্রতীকীভাবে (Symbolically) একদম হুবহু সমাধান করতে পারে: 

import sympy as sp

# ১. ভেরিয়েবল ডিফাইন করা
x, y = sp.symbols('x y')

# ২. সমীকরণ তৈরি করা
eq1 = sp.Eq(2*x + y, 5)
eq2 = sp.Eq(x - 3*y, -1)

# ৩. সমাধান করা
solution = sp.solve((eq1, eq2), (x, y))
print(solution)  # আউটপুট: {x: 2, y: 1}
কোথায় কাজে লাগে? যখন আমরা জটিল Loss Function-এর ডেরিভেটিভ বের করতে চাই বা কোনো তাত্ত্বিক সমীকরণের নিখুঁত মান চাই, তখন SymPy অপ্রতিদ্বন্দ্বী।

০৫ NumPy দিয়ে ফাস্ট সমাধান (Vectorized Numerical Solver)

যখন ডেটাসেট বড় হয়, তখন আমাদের প্রয়োজন বিদ্যুৎগতির গণনা। এর জন্য আমরা ব্যবহার করি NumPy-এর লিনিয়ার অ্যালজেব্রা মডিউল np.linalg.solve: 

import numpy as np

# ১. কো-এফিশিয়েন্ট ম্যাট্রিক্স A এবং টার্গেট ভেক্টর b
A = np.array([[2.0,  1.0],
              [1.0, -3.0]])

b = np.array([5.0, -1.0])

# ২. সরাসরি সমাধান
x_solution = np.linalg.solve(A, b)
print("সমাধান:", x_solution)  # [2. 1.]

# ৩. কন্ডিশন নাম্বার (Condition Number) চেক করা
cond = np.linalg.cond(A)
print("Condition Number:", cond)  # 1.45 (যত ছোট, সিস্টেম তত বেশি স্থিতিশীল)
সতর্কতা (Singular Matrix): যদি সমীকরণের দুইটা সারি একই রকম বা পরষ্পর নির্ভরশীল হয় (যেমন 2x + y = 5 এবং 4x + 2y = 10), তবে ম্যাট্রিক্সটির ডিটারমিন্যান্ট শূন্য হয়ে যায়। একে Singular Matrix বলে এবং এর কোনো একক সমাধান থাকে না।

০৬ Normal Equation: সরাসরি Linear Regression সমাধান

মেশিন লার্নিং-এ গ্রেডিয়েন্ট ডিসেন্ট চালিয়ে লুপের পর লুপ না ঘুরে, বীজগণিত ব্যবহার করে এক ক্লিকেই সেরা ওজনের মান (Optimal Weights) বের করার বিখ্যাত সূত্রের নাম Normal Equation:

w = (Xᵀ · X)⁻¹ · Xᵀ · y X = ডেটা ম্যাট্রিক্স, y = আসল টার্গেট ভ্যালু, w = সেরা মডেল ওয়েটস

NumPy-তে এটা কোড করা খুবই সহজ: 

# X এর সাইজ (N, D), y এর সাইজ (N,)
XTX = X.T @ X
XTy = X.T @ y

# সমাধান: (X^T * X) * w = X^T * y
weights = np.linalg.solve(XTX, XTy)

এই একটা লাইনেই আপনার সম্পূর্ণ Linear Regression মডেল ট্রেন হয়ে গেল!

০৭ Regularization (Ridge / L2): সমীকরণ যখন আটকে যায়

বাস্তব ডেটাতে অনেক সময় দুইটা কলাম প্রায় এক রকম হয়ে যায় (Collinear Features)। তখন Xᵀ · X ইনভার্ট করা যায় না বা ওয়েটগুলো অস্বাভাবিক বড় হয়ে মডেল ওভারফিট করে।

সমাধান কী? আমরা সমীকরণের সাথে সামান্য একটু পেনাল্টি বা রেগুলারাইজেশন (λ·I) যোগ করে দিই। একে বলে Ridge Regularization:

w = (Xᵀ · X + λ · I)⁻¹ · Xᵀ · y λ (Lambda) হলো রেগুলারাইজেশন স্ট্রেংথ, I হলো Identity Matrix 
# Ridge সমীকরণ সমাধান
lambda_reg = 0.1
I = np.eye(X.shape[1])  # Identity Matrix

weights_ridge = np.linalg.solve(XTX + lambda_reg * I, XTy)

এর ফলে সমীকরণ কখনোই ক্র্যাশ করে না এবং মডেল অনেক বেশি নিখুঁত ও স্থিতিশীল প্রেডিকশন দেয়।

০৮ Polynomial Basis: বাঁকা ডেটা প্রেডিক্ট করা

বাস্তবের ডেটা সবসময় সোজা লাইনে চলে না—অনেক ডেটা বক্ররেখা (Curved) আকারে থাকে। লিনিয়ার ইকুয়েশন দিয়েই কি বাঁকা লাইন প্রেডিক্ট করা সম্ভব?

হ্যাঁ! ট্রিকটা হলো—ইনপুট x কে স্কয়ার ও কিউব করে বাড়তি কলাম বানিয়ে নেওয়া:

x ➔ [ 1, x, x², x³ ]

মডেলের সমীকরণ তখন দেখতে এমন হয়: y = w₀ + w₁·x + w₂·x²। এটা সমীকরণের দিক থেকে লিনিয়ার কিন্তু গ্রাফের দিক থেকে সুন্দর প্যারাবোলা বা বক্ররেখা! 

# একটি ইনপুট x কে পলিনমিয়াল ম্যাট্রিক্সে রূপান্তর করা
def generate_polynomial_basis(x, degree=2):
    # [1, x, x^2]
    return np.column_stack([x**i for i in range(degree + 1)])

🚀 এবার প্র্যাকটিক্যাল কোডিং করার পালা!

আমরা শিখে ফেললাম কীভাবে SymPy এবং NumPy দিয়ে সমীকরণ সিস্টেম এবং Normal Equation সমাধান করা যায়। এবার ল্যাবে গিয়ে Computational Algebra Engine তৈরি করে নিজের হাতে কোড যাচাই করুন।
