Gradient Descent Algorithm & Convergence Telemetry — গ্র্যাডিয়েন্ট ডিসেন্ট: অপটিমাইজেশন লুপ, লার্নিং রেট ও প্যারামিটার কনভার্জেন্স

মেশিন লার্নিংয়ের হৃদয়—গ্র্যাডিয়েন্ট ডিসেন্ট অ্যালগরিদম স্ক্র্যাচ থেকে কোড করা, লার্নিং রেটের প্রভাব পর্যবেক্ষণ এবং প্রতিটি ইটারেশনে লস কনভার্জেন্স টেলিমেট্রি ট্র্যাকিং।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

গ্র্যাডিয়েন্ট ডিসেন্টের পূর্ণাঙ্গ প্রশিক্ষণ লুপ ও কনভার্জেন্স থিওরি

গ্র্যাডিয়েন্ট ডিসেন্ট (Gradient Descent) হলো মেশিন লার্নিং ও আধুনিক ডিপ লার্নিংয়ের একক সবচেয়ে শক্তিশালী অ্যালগরিদম। এটি একটি পুনরাবৃত্তিমূলক (Iterative) অপটিমাইজেশন প্রক্রিয়া যা প্যারামিটারগুলোকে ধাপে ধাপে সর্বনিম্ন লসের দিকে নিয়ে যায়।

  • প্যারামিটার আপডেট রুল (Update Formula): প্রতিটি ইটারেশন বা স্টেপে ওয়েট আপডেট করা হয় নিচের সমীকরণ দ্বারা:
    w_new = w_old - α * ∇L(w_old)
    এখানে \( lpha \) (আলফা) হলো লার্নিং রেট (Learning Rate)।
  • লার্নিং রেটের গুরুত্ব:
    • লার্নিং রেট খুব বড় হলে: স্টেপ সাইজ অতিরিক্ত বড় হয়ে যায়, ফলে মডেল সঠিক সর্বনিম্ন বিন্দু মিস করে অসীম দূরত্বের দিকে ছিটকে পড়ে (Overshooting / Divergence)।
    • লার্নিং রেট খুব ছোট হলে: মডেল খুব ধীরগতিতে অগ্রসর হয় (Sluggish Convergence), ফলে কম্পিউটেশনাল সময় অযথা অপচয় হয়।
  • স্বয়ংক্রিয় স্টেপ সংকোচন (Natural Step Reduction): ওয়েট যখন সর্বনিম্ন বিন্দুর কাছাকাছি পৌঁছে, তখন গ্র্যাডিয়েন্ট \( abla L \) এর মানও স্বাভাবিকভাবেই শূন্যের কাছাকাছি নেমে আসে। ফলে লার্নিং রেট স্থির থাকলেও আপডেট স্টেপ সাইজ \( lpha \cdot abla L \) স্বয়ংক্রিয়ভাবে ছোট ও সূক্ষ্ম হয়ে যায়!
  • কনভার্জেন্স টেলিমেট্রি (Convergence Telemetry): যখন পরপর দুটি ইটারেশনের লসের পার্থক্য একটি ক্ষুদ্র থ্রেশহোল্ড (যেমন \( \epsilon = 10^{-6} \)) এর নিচে নেমে আসে, তখন অ্যালগরিদম প্রশিক্ষণ সমাপ্ত (Converged) ঘোষণা করে।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

gradient_descent_training_loop.py 
# -------------------------------------------------------------
# Topic 13: Full Gradient Descent Training Loop from Scratch
# -------------------------------------------------------------

def loss_func(w):
    """লস ফাংশন: L(w) = (w - 7.5)^2 + 3.0 (মিনিমাম w = 7.5 এ)"""
    return (w - 7.5)**2 + 3.0

def compute_grad(w):
    """লস ফাংশনের ডেরিভেটিভ: dL/dw = 2*(w - 7.5)"""
    return 2.0 * (w - 7.5)

def run_gradient_descent(initial_w, learning_rate=0.1, max_epochs=40, tolerance=1e-5):
    """
    পূর্ণাঙ্গ গ্র্যাডিয়েন্ট ডিসেন্ট অপটিমাইজেশন লুপ
    """
    w = initial_w
    history = []
    
    print(f"{'Epoch':<8} {'Weight (w)':<14} {'Loss':<12} {'Gradient':<14} {'Step (α*grad)'}")
    print("-" * 65)
    
    for epoch in range(1, max_epochs + 1):
        loss = loss_func(w)
        grad = compute_grad(w)
        step = learning_rate * grad
        
        # টেলিমেট্রি লগিং
        history.append((epoch, w, loss, grad))
        
        # নির্দিষ্ট কয়েকটি গুরুত্বপূর্ণ ইটারেশন প্রিন্ট করা যাক
        if epoch <= 5 or epoch % 5 == 0 or abs(step) < tolerance:
            print(f"{epoch:<8} {w:<14.5f} {loss:<12.5f} {grad:<14.5f} {step:<14.5f}")
            
        # কনভার্জেন্স চেক
        if abs(step) < tolerance:
            print("-" * 65)
            print(f"🎉 CONVERGENCE ACHIEVED at Epoch {epoch}!")
            print(f"Optimal Weight: {w:.5f} (Ground Truth: 7.50000)")
            print(f"Minimum Loss  : {loss:.5f} (Ground Truth: 3.00000)")
            break
            
        # প্যারামিটার আপডেট
        w = w - step
        
    return w, history

# -5.0 থেকে শুরু করে মডেল ট্রেইনিং রান করা যাক
trained_w, log = run_gradient_descent(initial_w=-5.0, learning_rate=0.15, max_epochs=40)

১. run_gradient_descent: আমরা মেশিন লার্নিংয়ের আসল ট্রেইনিং লুপ বানিয়েছি যা প্রাথমিক মান w = -5.0 থেকে শুরু হয়ে লক্ষ্য 7.5 এর দিকে এগিয়েছে।
