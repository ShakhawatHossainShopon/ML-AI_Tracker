১D লস মিনিমাইজার ও অটো-লার্নার (Gradient Descent Optimizer)

একটি ভুল ওজন (w=10) থেকে শুরু করে গ্র্যাডিয়েন্ট ডিসেন্ট চালিয়ে লস ০-তে নামিয়ে আনা।

০১ ধাপ ০১: ইনিশিয়াল লস ও ১টি আপডেট স্টেপ

ফাংশন Cost(w) = w^2। শুরুতে ওজন w = 10 (অনেক ভুল):

Python
def cost(w):
    return w**2

def get_grad(w):
    return 2 * w

w = 10.0
lr = 0.1

grad = get_grad(w)
w = w - lr * grad
print('New Weight after 1 step:', round(w, 2))
print('New Cost after 1 step  :', round(cost(w), 2))
🖥️ Terminal Output
$ python -c "..."
New Weight after 1 step: 8.0
New Cost after 1 step  : 64.0

🔍 কোড ব্রেকডাউন:

w = 10.0 থেকে 8.0: মাত্র ১টি কদমে ওজন ১০ থেকে ৮ এ নেমে এলো!
Cost = 100 থেকে 64: ভুলের পরিমাণ ১০০ থেকে ৬৪ এ নেমে গেছে (৩৬% উন্নতি)!

০২ ধাপ ০২: লুপ চালিয়ে অপটিমাইজেশন (২০টি স্টেপ)

লুপ চালিয়ে ওজন কীভাবে ধাপে ধাপে ০ এর কাছাকাছি পৌঁছায়:

Python
history = []
for epoch in range(1, 21):
    grad = get_grad(w)
    w = w - lr * grad
    if epoch % 5 == 0:
        history.append((epoch, round(w, 4), round(cost(w), 4)))

for ep, val, c in history:
    print(f'Epoch {ep:2d} -> Weight: {val:7.4f} | Cost: {c:7.4f}')
🖥️ Terminal Output
$ python -c "..."
Epoch  5 -> Weight:  2.6214 | Cost:  6.8719
Epoch 10 -> Weight:  0.8590 | Cost:  0.7378
Epoch 15 -> Weight:  0.2815 | Cost:  0.0792
Epoch 20 -> Weight:  0.0922 | Cost:  0.0085

🔍 কোড ব্রেকডাউন:

Epoch 20 Cost = 0.0085: মাত্র ২০ বারে ভুলের পরিমাণ ০ এর কাছাকাছি (০.০০৮৫) চলে এসেছে!
w = 0.0922: মডেল তার নিখুঁত লক্ষ্য ০ তে প্রায় পৌঁছে গেছে।

০৩ ধাপ ০৩: কনভারজেন্স ও ট্রেনিং সমাপ্তি

কখন আমরা বুঝতে পারব মডেল শেখা শেষ করেছে:

Python
is_converged = cost(w) < 0.01
print('Is Model Converged (Cost < 0.01)?:', is_converged)
print('Final Optimized Weight :', round(w, 4))
🖥️ Terminal Output
$ python -c "..."
Is Model Converged (Cost < 0.01)?: True
Final Optimized Weight : 0.0922

🔍 কোড ব্রেকডাউন:

is_converged = True: মডেল সাফল্যের সাথে তার সর্বনিম্ন ভুলের বিন্দুতে পৌঁছে গেছে!

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
def cost(w):
    return w**2

w = 10.0
lr = 0.1
for epoch in range(25):
    grad = 2 * w
    w -= lr * grad
print('Final Weight:', round(w, 6))
print('Final Cost  :', round(cost(w), 6))
🖥️ Full Terminal Run
Final Weight: 0.000378
Final Cost  : 0.000000
🎯 মোবাইলে মনে রাখার সারমর্ম:
• Gradient Descent হলো AI মডেলের ভুল কমানোর চিরন্তন অ্যালগরিদম。
• w = w - (learning_rate * gradient) প্রতিটি নিউরাল নেটওয়ার্কে কোটিবার চলে。
• লস ০ তে পৌঁছালে মডেলের ট্রেনিং সফল হয়।
