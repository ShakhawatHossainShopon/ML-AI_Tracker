Programmer Lab Phase 02 — Topic 04 Pure Python Logic

অনুক্রম ও ধারা: সহজ প্রোগ্রামার গাইড

এখানে কোনো কঠিন গ্রিক অক্ষর বা ম্যাথ থিওরি নেই! একজন প্রোগ্রামার হিসেবে আমরা শুধু কোড লুপ আর লিস্টের মাধ্যমে বুঝবো: একটি লুপ চালিয়ে সংখ্যার তালিকা তৈরি করাই অনুক্রম (Sequence) এবং সেই সংখ্যার মোট যোগফলই হলো ধারা (Series)।

০১ প্রোগ্রামারের চোখে অনুক্রম ও ধারা

একজন প্রোগ্রামারের কাছে এই দুটি শব্দের অর্থ খুবই সোজা:

  • Sequence (অনুক্রম): একটি সাধারণ Python List—যেমন [100, 50, 25, 12, 6]। প্রতি রাউন্ডে একটি নির্দিষ্ট নিয়মে মানগুলো পরিবর্তিত হয়।
  • Series (ধারা): ওই লিস্টের সব সংখ্যার যোগফল—অর্থাৎ sum(list)!
আপনার ফাইলসমূহ:
  • main.py: আপনার রান করার ফাইল। এতে কোনো কমেন্ট ছাড়া একবারে একটি করে সহজ ধাপ দেওয়া হবে।
  • applied.py: সম্পূর্ণ রেফারেন্স সমাধান। প্রতিটি লাইনে সহজ বাংলায় কমেন্ট দেওয়া আছে।

০২ প্রজেক্টের ৩টি সহজ ধাপ

ধাপ ১: ভুলের অনুক্রম (Sequence)

মডেল শেখার সময় প্রথমবার ভুল হয় 100। প্রতি রাউন্ডে লুপ চালিয়ে ভুল অর্ধেক করে একটি লিস্টে রাখলে পাই: [100, 50, 25, 12, 6]।

ধাপ ২: মোট ভুলের যোগফল (Series)

লিস্টের সব সংখ্যা যোগ করলে মোট ভুল পাওয়া যায়: 100 + 50 + 25 + 12 + 6 = 193।

ধাপ ৩: মুভিং এভারেজ (Moving Average)

পাশাপাশি দুটি সংখ্যার গড় বের করে ডেটা মসৃণ করা: (100+50)/2 = 75.0, (50+25)/2 = 37.5 ইত্যাদি।

০৩ রান ও টেস্টের নিয়ম

টার্মিনালে main.py চালিয়ে ধাপটি পরীক্ষা করুন:

python main.py PowerShell / CMD

সম্পূর্ণ কোডের আউটপুট দেখতে চাইলে:

python applied.py PowerShell / CMD
ওয়ার্কফ্লো: আপনি python main.py চালিয়ে আউটপুট দেখার পর চ্যাটে শুধু বলবেন "next" — আমি সাথে সাথে ধাপ ০২ আপডেট করে দেবো!
