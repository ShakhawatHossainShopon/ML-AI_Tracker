Derivatives & Differentiation in Machine Learning — ডেরিভেটিভ ও ডিফারেনশিয়েশন: লস ফাংশনের পরিবর্তনের হার ও ঢাল নির্ণয়

মেশিন লার্নিং মডেলে এরর বা লস পরিবর্তনের সাথে সাথে কীভাবে ওঠানামা করে তা পরিমাপ করতে ডিফারেনশিয়েশন ও ডেরিভেটিভের ভূমিকা এবং পাইথনে নিউমেরিক্যাল গ্র্যাডিয়েন্ট সিমুলেশন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

ডেরিভেটিভ ও পরিবর্তনের হার কেন মেশিন লার্নিংয়ের চালিকাশক্তি?

মেশিন লার্নিং ও কৃত্রিম বুদ্ধিমত্তার মূল উদ্দেশ্য হলো—একটি মডেলকে নিজের ভুল (Loss/Error) থেকে শিখতে বাধ্য করা। মডেল কীভাবে বুঝবে তার করা ভুলটি বাড়ছে নাকি কমছে? এখানেই জন্ম নেয় ডেরিভেটিভ (Derivative) বা অন্তরীকরণ।

  • তাৎক্ষণিক পরিবর্তনের হার (Instantaneous Rate of Change): কোনো ইনপুট ভ্যারিয়েবল (যেমন মডেলের ওয়েট \(w\)) সামান্য একটু পরিবর্তন করলে আউটপুট লস \(L\) ঠিক কতটুকু পরিবর্তন হবে, ডেরিভেটিভ তা নিখুঁতভাবে পরিমাপ করে।
  • স্পর্শকের ঢাল (Slope of the Tangent Line): জ্যামিতিকভাবে ডেরিভেটিভ হলো লস কার্ভের যেকোনো বিন্দুতে আঁকা স্পর্শক রেখার ঢাল। ঢাল পজিটিভ (\(+\)) মানে ডানদিকে গেলে লস বাড়ছে, ঢাল নেগেটিভ (\(-\)) মানে ডানদিকে গেলে লস কমছে, আর ঢাল শূন্য (\(0\)) মানে আমরা চূড়ায় অথবা সর্বনিম্ন উপত্যকায় (Minima) অবস্থান করছি!
  • লিমিটের গাণিতিক রূপ: ক্যালকুলাসের সংজ্ঞানুযায়ী:
    f'(x) = lim (h → 0) [f(x + h) - f(x)] / h
    কম্পিউটার সায়েন্সে অত্যন্ত ক্ষুদ্র একটি মান \(h = 10^{-5}\) ধরে খুব সহজেই আমরা এই নিউমেরিক্যাল ডেরিভেটিভ বের করে ফেলতে পারি।
  • লস ফাংশন মিনিমাইজেশন: যখন মডেল বুঝতে পারে যে ঢাল ঋণাত্মক, তখন সে ওয়েট বাড়ায়; আর যখন দেখে ঢাল ধনাত্মক, তখন সে ওয়েট কমায়। এভাবেই মডেল ভুলের সর্বনিম্ন বিন্দু খুঁজে পায়।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

numerical_derivative_ml.py 
# -------------------------------------------------------------
# Topic 09: Numerical Differentiation for Loss Optimization
# -------------------------------------------------------------

def loss_function(w):
    """
    একটি কোয়াড্রেটিক লস ফাংশন: L(w) = (w - 3.0)^2 + 2.0
    এখানে গাণিতিক সর্বনিম্ন মান ঘটে w = 3.0 তে (যেখানে L = 2.0)।
    """
    return (w - 3.0) ** 2 + 2.0

def compute_numerical_derivative(f, w, h=1e-5):
    """
    প্রথম নীতি (First Principle) অনুযায়ী নিউমেরিক্যাল ঢাল নির্ণয়:
    slope = (f(w + h) - f(w)) / h
    """
    return (f(w + h) - f(w)) / h

def analytical_derivative(w):
    """
    ক্যালকুলাসের রুল অনুযায়ী সঠিক ডেরিভেটিভ:
    d/dw [(w - 3)^2 + 2] = 2*(w - 3)
    """
    return 2.0 * (w - 3.0)

# বিভিন্ন ওয়েট পয়েন্টে ডেরিভেটিভ ও অপটিমাইজেশন ডিরেকশন যাচাই
test_weights = [1.0, 2.5, 3.0, 3.5, 5.0]

print(f"{'Weight (w)':<12} {'Loss L(w)':<12} {'Num Slope':<14} {'Exact Slope':<14} {'Recommended Action'}")
print("-" * 75)

for w in test_weights:
    loss = loss_function(w)
    num_slope = compute_numerical_derivative(loss_function, w)
    exact_slope = analytical_derivative(w)
    
    if num_slope < -0.01:
        action = "Increase w (Move Right ->)"
    elif num_slope > 0.01:
        action = "Decrease w (<- Move Left)"
    else:
        action = "PERFECT OPTIMUM (Slope ≈ 0)"
        
    print(f"{w:<12.1f} {loss:<12.4f} {num_slope:<14.5f} {exact_slope:<14.5f} {action}")

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

১. loss_function(w): আমরা একটি আদর্শ ইউ-আকৃতির (Parabolic) লস ফাংশন তৈরি করেছি যেখানে w = 3.0 হলো আসল সঠিক প্যারামিটার।
২. compute_numerical_derivative: অত্যন্ত সূক্ষ্ম ধাপ h = 1e-5 বাড়িয়ে ফাংশনের আউটপুটের পরিবর্তনকে ধাপের দৈর্ঘ্য দিয়ে ভাগ করে ঢাল নির্ণয় করা হয়েছে।
৩. ঢালের দিক ও একশন: w = 1.0 এ ঢাল -4.0 (নেগেটিভ), তাই লস কমাতে ওয়েট বাড়াতে হবে। w = 5.0 এ ঢাল +4.0 (পজিটিভ), তাই ওয়েট কমাতে হবে। আর w = 3.0 এ ঢাল 0, অর্থাৎ সর্বনিম্ন লস অর্জিত হয়েছে।
