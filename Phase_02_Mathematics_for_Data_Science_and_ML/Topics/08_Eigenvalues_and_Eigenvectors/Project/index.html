ডেটার মূল অক্ষ নির্ণয় ইঞ্জিন (Data Axis Finder)

মোবাইলে পড়ার জন্য কমপ্যাক্ট কোড-বাই-কোড ব্রেকডাউন। কোড রান না করেই ইনপুট, আউটপুট ও লজিক বুঝে নিন।

০০ প্রজেক্টের প্রেক্ষাপট

আইগেনভেক্টর দিয়ে ডেটার মূল তথ্য ধরে রাখা প্রধান অক্ষ (Principal Component) বের করা:

  • ধাপ ০১: np.linalg.eig দিয়ে আইগেনভ্যালু ও আইগেনভেক্টর বের করা।
  • ধাপ ০২: প্রমাণ করা যে ভেক্টরের দিক বদলায়নি (A @ v == lambda * v)।
  • ধাপ ০৩: সবচেয়ে বড় আইগেনভ্যালু দিয়ে ডেটার মূল অক্ষ নির্বাচন করা।

০১ ধাপ ০১: আইগেনভ্যালু ও ভেক্টর হিসাব

Python (Step 1)
import numpy as np

A = np.array([
    [4, 2],
    [1, 3]
])
eigenvalues, eigenvectors = np.linalg.eig(A)

print("Eigenvalues  :", eigenvalues)
print("Eigenvectors :\n", eigenvectors)
🖥️ Terminal Output (Step 1)
Eigenvalues  : [5. 2.]
Eigenvectors :
[[ 0.89442719 -0.70710678]
 [ 0.4472136   0.70710678]]

🔍 কোড ব্রেকডাউন:

eigenvalues = [5.0, 2.0]: ম্যাট্রিক্সটি কোনো ভেক্টরকে ৫ গুণ এবং কোনোটিকে ২ গুণ প্রসারিত করে।
eigenvectors: কলাম ০ হলো ১ম ভেক্টর (স্কেল ৫.০) এবং কলাম ১ হলো ২য় ভেক্টর (স্কেল ২.০)।

০২ ধাপ ০২: প্রমাণ — দিক কখনোই বদলায় না!

Python (Step 2)
v1 = eigenvectors[:, 0]
lambda1 = eigenvalues[0]

transformed_v = A @ v1
scaled_v = lambda1 * v1

print("A @ v1      :", np.round(transformed_v, 4))
print("lambda * v1 :", np.round(scaled_v, 4))
🖥️ Terminal Output (Step 2)
A @ v1      : [4.4721 2.2361]
lambda * v1 : [4.4721 2.2361]

🔍 কোড ব্রেকডাউন:

transformed_v এবং scaled_v হুবহু এক: [4.4721, 2.2361]!
ভেক্টরটি কোনো নতুন কোণে ঘোরে নি, শুধু সোজা আগের দিকেই ঠিক ৫ গুণ লম্বা হয়েছে।

০৩ ধাপ ০৩: ডেটার মূল অক্ষ (Dominant Axis)

Python (Step 3)
dominant_idx = np.argmax(eigenvalues)
dominant_value = eigenvalues[dominant_idx]
dominant_vector = eigenvectors[:, dominant_idx]

print("Dominant Value :", dominant_value)
print("Dominant Axis  :", dominant_vector)
🖥️ Terminal Output (Step 3)
Dominant Value : 5.0
Dominant Axis  : [0.89442719 0.4472136 ]

🔍 কোড ব্রেকডাউন:

np.argmax(eigenvalues): সর্বোচ্চ আইগেনভ্যালু ৫.০ খুঁজে পেয়েছে।
[0.8944, 0.4472] অক্ষটিই হলো ডেটাসেটের সবচেয়ে গুরুত্বপূর্ণ দিক (Principal Component)।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
import numpy as np

A = np.array([[4, 2], [1, 3]])
vals, vecs = np.linalg.eig(A)

v1 = vecs[:, 0]
l1 = vals[0]

print("A @ v1      :", np.round(A @ v1, 4))
print("lambda * v1 :", np.round(l1 * v1, 4))
print("Dominant Axis:", vecs[:, np.argmax(vals)])
🖥️ Terminal Output
A @ v1      : [4.4721 2.2361]
lambda * v1 : [4.4721 2.2361]
Dominant Axis: [0.89442719 0.4472136 ]
🎯 মোবাইলে মনে রাখার সারমর্ম:
• Eigenvector: যে ভেক্টরের দিক কখনো বদলায় না।
• Eigenvalue: ভেক্টরটি কতগুণ লম্বা বা খাটো হলো (যেমন: ৫ গুণ)।
• PCA তে ব্যবহার: বড় আইগেনভ্যালুই ডেটার সবচেয়ে গুরুত্বপূর্ণ ফিচার বা অক্ষ নির্দেশ করে।
