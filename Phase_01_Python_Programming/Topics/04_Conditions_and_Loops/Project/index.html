ব্যাংক লোন অনুমোদন ও ফিল্টারিং ইঞ্জিন (Loan Approval System)

একাধিক আবেদনকারীর ডেটা প্রসেস করে লোন অনুমোদনের সিদ্ধান্ত নেওয়া।

০১ ধাপ ০১: একক আবেদনকারীর শর্ত যাচাই

বয়স ২১+ এবং মাসিক আয় ৫০,০০০+ হলে লোন অনুমোদন:

Python
age = 26
income = 65000
credit_score = 720

if age >= 21 and income >= 50000 and credit_score >= 700:
    status = 'Approved'
else:
    status = 'Rejected'
print('Loan Decision:', status)
🖥️ Terminal Output
$ python -c "..."
Loan Decision: Approved

🔍 কোড ব্রেকডাউন:

and অপারেটর: তিনটি শর্তই সত্য হওয়ায় লোন Approved হয়েছে।

০২ ধাপ ০২: for লুপ দিয়ে ব্যাচ প্রসেসিং

লিস্টে থাকা একাধিক আবেদনকারীর জন্য লুপ চালিয়ে সিদ্ধান্ত বের করা:

Python
applicants = [
    {'name': 'Tanvir', 'income': 70000, 'score': 750},
    {'name': 'Sumi',   'income': 30000, 'score': 650},
    {'name': 'Karim',  'income': 55000, 'score': 710}
]

approved = []
for a in applicants:
    if a['income'] >= 50000 and a['score'] >= 700:
        approved.append(a['name'])
print('Approved Applicants:', approved)
🖥️ Terminal Output
$ python -c "..."
Approved Applicants: ['Tanvir', 'Karim']

🔍 কোড ব্রেকডাউন:

for a in applicants: লিস্টের প্রতিটি ডিকশনারি ধরে শর্ত চেক করেছে।

০৩ ধাপ ০৩: while লুপ ও কোটা লিমিট (break)

কোটা পূরণ হওয়ামাত্রই লুপ বন্ধ করা:

Python
funds = 100000
loan_amount = 40000
count = 0

while funds >= loan_amount:
    funds -= loan_amount
    count += 1
print('Total Loans Disbursed:', count)
print('Remaining Funds     :', funds)
🖥️ Terminal Output
$ python -c "..."
Total Loans Disbursed: 2
Remaining Funds     : 20000

🔍 কোড ব্রেকডাউন:

while funds >= loan_amount: ফান্ড শেষ হওয়ামাত্রই লুপ থেমে গেছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
apps = [{'n':'A', 's':720}, {'n':'B', 's':620}]
print('Approved:', [a['n'] for a in apps if a['s'] >= 700])
🖥️ Full Terminal Run
Approved: ['A']
🎯 মোবাইলে মনে রাখার সারমর্ম:
• if-elif-else দিয়ে শর্ত তৈরি হয়。
• for লুপ ডেটা প্রসেসিংয়ের প্রধান ভিত্তি。
• break দিয়ে কাজ শেষ হওয়ামাত্র লুপ থামানো যায়।
