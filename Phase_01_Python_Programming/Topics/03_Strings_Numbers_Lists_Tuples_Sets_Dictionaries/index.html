Core Data Structures for AI Data Pipelines — মৌলিক ডেটা স্ট্রাকচার: এআই ডেটা পাইপলাইনের ভিত্তি

লিস্ট, টাপল, ডিকশনারি ও সেট—কোন ডেটা স্ট্রাকচারটি কোন এআই অপারেশনে ব্যবহার করবেন তার গভীর ইঞ্জিনিয়ারিং গাইড।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

এআই মডেলে কোন ডেটা স্ট্রাকচার কখন ব্যবহার করবেন?

মেশিন লার্নিং ও ডিপ লার্নিংয়ের প্রতিটি পাইপলাইনে ডেটা প্রসেসিংয়ের গতি নির্ভর করে সঠিক ডেটা স্ট্রাকচার নির্বাচনের ওপর। পাইথনে মিউটেবল (পরিবর্তনযোগ্য) ও ইমিউটেবল (স্থির) ডেটা স্ট্রাকচারের আলাদা আলাদা উদ্দেশ্য রয়েছে:

  • List (মিউটেবল ক্রম): ট্রেনিং ব্যাচে নতুন নতুন স্যাম্পল যোগ করা (.append()) বা ডাইনামিক ফিচার ভেক্টর সংরক্ষণে ব্যবহৃত হয়।
  • Tuple (ইমিউটেবল স্থির ক্রম): টেন্সরের ডাইমেনশন বা শেপ সংরক্ষণে টাপল ব্যবহৃত হয় (যেমন: shape = (32, 3, 224, 224))। যেহেতু এটি পরিবর্তন করা যায় না, তাই অসাবধানতাবশত শেপ বদলে যাওয়ার বাগ হয় না।
  • Dictionary (কি-ভ্যালু পেয়ার): মডেল কনফিগারেশন, মেটাডেটা এবং ক্লাসিফিকেশন লেবেল ম্যাপিংয়ের জন্য অপরিহার্য (যেমন: {"0": "cat", "1": "dog"})। এটি $O(1)$ টাইমে ইনস্ট্যান্ট লুকআপ দেয়।
  • Set (অনন্য উপাদানের সেট): ডেটাসেট থেকে ডুপ্লিকেট সরানো এবং সম্পূর্ণ ডেটাসেটের ইউনিক ক্লাস লেবেল বের করতে সেট ব্যবহৃত হয়।

মেমরি ও পারফরম্যান্স টিপ: যেখানে ডেটা ফিক্সড থাকবে সেখানে লিস্টের বদলে টাপল ব্যবহার করুন; টাপলে মেমরি ওভারহেড কম এবং এক্সিকিউশন দ্রুততর হয়।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

ai_data_structures.py 
# ১. লিস্ট: ডাইনামিক লস হিস্ট্রি
loss_history = [0.85, 0.62, 0.41, 0.28]
loss_history.append(0.19)

# ২. টাপল: টেন্সর ডাইমেনশন শেপ (স্থির ও সুরক্ষিত)
tensor_shape = (64, 3, 224, 224)  # (Batch, Channels, Height, Width)

# ৩. ডিকশনারি: লেবেল ও হাইপারপ্যারামিটার ম্যাপিং
model_config = {
    "architecture": "CNN_V2",
    "epochs": 10,
    "classes": {"0": "Normal", "1": "Pneumonia"}
}

# ৪. সেট: ইউনিক ক্লাসের তালিকা (ডুপ্লিকেট রিমুভ)
raw_labels = ["cat", "dog", "cat", "bird", "dog", "cat"]
unique_classes = set(raw_labels)

print("Updated Loss History :", loss_history)
print(f"Fixed Tensor Shape   : {tensor_shape} (Batch: {tensor_shape[0]})")
print("Target Classes Map   :", model_config["classes"])
print("Unique Discovered Set:", unique_classes)
🖥️ Terminal Output 
Updated Loss History : [0.85, 0.62, 0.41, 0.28, 0.19]
Fixed Tensor Shape   : (64, 3, 224, 224) (Batch: 64)
Target Classes Map   : {'0': 'Normal', '1': 'Pneumonia'}
Unique Discovered Set: {'bird', 'cat', 'dog'}

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

loss_history.append(0.19): লিস্ট মিউটেবল হওয়ায় নতুন ইপকের লস সহজে শেষে যুক্ত হয়েছে।
tensor_shape = (64, 3, 224, 224): টাপল ব্যবহারের ফলে টেন্সরের ডাইমেনশন রানটাইমে পরিবর্তিত হওয়ার কোনো ঝুঁকি নেই।
model_config["classes"]: ডিকশনারি দিয়ে আইডি থেকে ক্লাসের নামে তাত্ক্ষণিক ম্যাপিং করা সম্ভব হয়েছে।
set(raw_labels): সেট স্বয়ংক্রিয়ভাবে সব ডুপ্লিকেট বাদ দিয়ে ইউনিক লেবেল ফিল্টার করেছে।
