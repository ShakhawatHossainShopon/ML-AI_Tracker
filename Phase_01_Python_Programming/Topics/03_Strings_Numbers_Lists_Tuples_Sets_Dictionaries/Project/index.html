Project Breakdown Phase 01 — Topic 03 Mobile View

ই-কমার্স ক্যাটালগ ও কার্ট ম্যানেজার (Cart & Catalog Manager)

লিস্ট, টাপল, সেট ও ডিকশনারি একসাথে ব্যবহার করে একটি শপিং কার্ট সিস্টেম।

০১ ধাপ ০১: ডিকশনারি দিয়ে প্রোডাক্ট ক্যাটালগ ও টাপল দিয়ে কোঅর্ডিনেট

প্রোডাক্টের নাম ও দামের ডিকশনারি এবং ডেলিভারি পয়েন্টের টাপল তৈরি:

Python
catalog = {'laptop': 85000, 'mouse': 1200, 'keyboard': 3500}
delivery_coords = (23.8103, 90.4125) # Dhaka Coordinates (Immutable)
print('Product Catalog:', catalog)
print('Delivery GPS   :', delivery_coords)
🖥️ Terminal Output
$ python -c "..."
Product Catalog: {'laptop': 85000, 'mouse': 1200, 'keyboard': 3500}
Delivery GPS   : (23.8103, 90.4125)

🔍 কোড ব্রেকডাউন:

catalog dict: কি ধরে দাম পাওয়ার দ্রুততম উপায়।
coords tuple: জিপিএস লোকেশন যাতে কোডে ভুলবশত পরিবর্তন না হয়।

০২ ধাপ ০২: লিস্টে কার্ট আইটেম ও সেটে ইউনিক ক্যাটাগরি

কাস্টমারের কার্টে আইটেম যুক্ত করা এবং ডুপ্লিকেট ক্যাটাগরি বাদ দেওয়া:

Python
cart = ['mouse', 'keyboard', 'mouse'] # List allows duplicates
raw_categories = ['tech', 'accessories', 'tech', 'office']
unique_categories = set(raw_categories)
print('Customer Cart    :', cart)
print('Unique Categories:', unique_categories)
🖥️ Terminal Output
$ python -c "..."
Customer Cart    : ['mouse', 'keyboard', 'mouse']
Unique Categories: {'accessories', 'office', 'tech'}

🔍 কোড ব্রেকডাউন:

set(raw_categories): স্বয়ংক্রিয়ভাবে ডুপ্লিকেট বাদ দিয়ে ইউনিক ক্যাটাগরি রেখেছে।

০৩ ধাপ ০৩: মোট বিল হিসাব করা

কার্টের আইটেমগুলো ক্যাটালগ থেকে খুঁজে মোট বিল বের করা:

Python
total_bill = sum(catalog[item] for item in cart)
print('Total Cart Bill:', total_bill, 'BDT')
🖥️ Terminal Output
$ python -c "..."
Total Cart Bill: 5900 BDT

🔍 কোড ব্রেকডাউন:

sum(...): দুটি মাউস (১২০০+১২০০) এবং একটি কিবোর্ড (৩৫০০) = ৫৯০০ টাকা।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
cat = {'mouse': 1200, 'kb': 3500}
cart = ['mouse', 'kb', 'mouse']
total = sum(cat[i] for i in cart)
print('Total Bill:', total)
🖥️ Full Terminal Run
Total Bill: 5900
🎯 মোবাইলে মনে রাখার সারমর্ম:
• লিস্ট = শপিং কার্ট বা ডেটা সারি।
• টাপল = ফিক্সড কনফিগারেশন。
• সেট = ডুপ্লিকেট মোছার ফিল্টার。
• ডিকশনারি = কি-ভ্যালু ডেটাબેস।
