Project Breakdown Phase 01 — Topic 06 Mobile View

হাই-পারফরম্যান্স ডেটা ফিল্টার ও ট্রান্সফরমার (Data Transformer)

কাঁচা ইউজার ও স্কোর ডেটা এক লাইনে ক্লিন এবং ফিল্টার করা।

০১ ধাপ ০১: লিস্ট কমপ্রিহেনশনে ফিল্টারিং

১০০ নম্বরের পরীক্ষায় শুধু পাস করা মার্কস (৫০+) আলাদা করা:

Python
raw_scores = [45, 88, 32, 95, 60, 48, 72]
passed_scores = [s for s in raw_scores if s >= 50]
print('Raw Scores   :', raw_scores)
print('Passed Scores:', passed_scores)
🖥️ Terminal Output
$ python -c "..."
Raw Scores   : [45, 88, 32, 95, 60, 48, 72]
Passed Scores: [88, 95, 60, 72]

🔍 কোড ব্রেকডাউন:

[s for s in ... if s >= 50]: লুপ ও শর্ত এক লাইনেই সম্পন্ন হয়েছে।

০২ ধাপ ০২: ট্রান্সফরমেশন (Normalizing Scores)

সব পাস করা মার্কসকে ১০০ দিয়ে ভাগ করে স্কেল করা (০.০ থেকে ১.০):

Python
normalized = [round(s / 100.0, 2) for s in passed_scores]
print('Normalized Scores:', normalized)
🖥️ Terminal Output
$ python -c "..."
Normalized Scores: [0.88, 0.95, 0.6, 0.72]

🔍 কোড ব্রেকডাউন:

s / 100.0: প্রতিটি উপাদানকে ট্রান্সফর্ম করে নতুন লিস্ট তৈরি করেছে।

০৩ ধাপ ০৩: ডিকশনারি কমপ্রিহেনশন

ইউজার ও ব্যালেন্স ডিকশনারি থেকে শুধু অ্যাক্টিভ ব্যালেন্সের ডিকশনারি বানানো:

Python
users = {'rahim': 500, 'karim': 0, 'sumi': 1200, 'tanvir': 0}
active_users = {k: v for k, v in users.items() if v > 0}
print('Active Users Only:', active_users)
🖥️ Terminal Output
$ python -c "..."
Active Users Only: {'rahim': 500, 'sumi': 1200}

🔍 কোড ব্রেকডাউন:

{k: v for ... if v > 0}: শূন্য ব্যালেন্সের ইউজার বাদ দিয়ে সরাসরি ফিল্টার্ড ডিকশনারি তৈরি হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
nums = [1, 2, 3, 4, 5, 6]
even_sq = [x**2 for x in nums if x % 2 == 0]
print('Even Squares:', even_sq)
🖥️ Full Terminal Run
Even Squares: [4, 16, 36]
🎯 মোবাইলে মনে রাখার সারমর্ম:
• কমপ্রিহেনশন সাধারণ লুপের চেয়ে দ্রুত ও পরিচ্ছন্ন。
• [x for x in list if condition] হলো গোল্ডেন ফরম্যাট。
• ডেটা প্রিপ্রসেসিংয়ে এটি সবচেয়ে বেশি ব্যবহৃত হয়।
