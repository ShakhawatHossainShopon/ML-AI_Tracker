List & Dictionary Comprehensions for High-Speed ETL — কমপ্রিহেনশন: হাই-স্পিড পাইথনিক ডেটা ফিল্টারিং ও ম্যাপিং

সিপিইউ সাইকেল ও মেমরি বাঁচিয়ে এক লাইনে বিশাল ডেটাসেট ফিল্টারিং ও এনএলপি ভোকাবুলারি ডিকশনারি তৈরি।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

কমপ্রিহেনশন কেন ট্র্যাডিশনাল ফর-লুপের চেয়ে সেরা?

ডেটা সায়েন্সে লাখ লাখ রেকর্ড নিয়ে কাজ করার সময় সাধারণ for লুপ দিয়ে বার বার .append() কল করা খুবই ধীরগতির (প্রতি কলে পাইথনের ফাংশন ওভারহেড তৈরি হয়)। কমপ্রিহেনশন ইন্টারনাল সি-লেভেলে অপ্টিমাইজড থাকে, ফলে এটি অনেক দ্রুত রান করে:

  • List Comprehension: এক লাইনে সিনট্যাক্স [expression for item in iterable if condition]। এটি ফিল্টারিং ও রূপান্তর একসাথে সম্পন্ন করে। যেমন: ঋণাত্মক সংখ্যা বা নয়েজ বাদ দেওয়া।
  • Dictionary Comprehension: এনএলপিতে শব্দকে সংখ্যায় রূপান্তর করতে ভোকাবুলারি ইন্ডেক্স তৈরি করা হয়: {word: idx for idx, word in enumerate(words)}। এটি কোডের আকার চারগুণ কমিয়ে দেয়।
  • মেমরি ও রিডেবিলিটি: কমপ্রিহেনশন অত্যন্ত মার্জিত এবং পাইথনিক। ডেটা সায়েন্টিস্টরা সবসময় কমপ্রিহেনশনকে অগ্রাধিকার দেন।

সাবধানতা: কমপ্রিহেনশনের ভেতরে ৩টির বেশি নেস্টেড লজিক লিখবেন না; কোডের রিডেবিলিটি নষ্ট হলে সাধারণ লুপ ব্যবহার করাই ভালো।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

data_comprehensions.py 
# ১. লিস্ট কমপ্রিহেনশন: আউটলায়ার ও নয়েজ ফিল্টারিং
sensor_readings = [12.4, -999.0, 14.8, 15.2, -999.0, 18.5]
# -999.0 হলো সেন্সর এরর ভ্যালু, এটি ফিল্টার আউট করবো
clean_readings = [val for val in sensor_readings if val > 0]

# ২. ডিকশনারি কমপ্রিহেনশন: এনএলপি টোকেন-টু-ইন্ডেক্স ম্যাপিং (Vocab Map)
vocabulary = ["python", "machine", "learning", "deep", "neural", "network"]
word_to_id = {word: idx for idx, word in enumerate(vocabulary)}

print("ক্লিন সেন্সর রিডিংস :", clean_readings)
print("টোকেন-টু-আইডি ম্যাপ :", word_to_id)
print("Token 'neural' ID   :", word_to_id["neural"])
🖥️ Terminal Output 
ক্লিন সেন্সর রিডিংস : [12.4, 14.8, 15.2, 18.5]
টোকেন-টু-আইডি ম্যাপ : {'python': 0, 'machine': 1, 'learning': 2, 'deep': 3, 'neural': 4, 'network': 5}
Token 'neural' ID   : 4

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

[val for val in sensor_readings if val > 0]: মাত্র এক লাইনে ত্রুটিপূর্ণ -৯৯৯ মানগুলো ফিল্টার করে কেবল ভ্যালিড রিডিংস রাখা হয়েছে।
{word: idx for idx, word in enumerate(vocabulary)}: প্রতিটি ইউনিক শব্দকে তার পজিশনাল আইডির সাথে ডিকশনারিতে ম্যাপ করা হয়েছে (NLP Tokenization-এর ভিত্তি)।
word_to_id["neural"]: $O(1)$ টাইমে কাঙ্ক্ষিত টোকেনের আইডি রিট্রিভ করা হয়েছে।
