Project Breakdown Phase 01 — Topic 05 Mobile View

ট্যাক্স ও ডিসকাউন্ট ক্যালকুলেশন ইঞ্জিন (Pricing & Tax Engine)

পুনঃব্যবহারযোগ্য ফাংশন ও ল্যাম্বডা দিয়ে স্বয়ংক্রিয় প্রাইসিং সিস্টেম তৈরি।

০১ ধাপ ০১: সাধারণ ফাংশন ও ডিফল্ট আর্গুমেন্ট

ট্যাক্স সহ পণ্যের দাম হিসাব করার ফাংশন:

Python
def calculate_total(base_price, tax_rate=0.15):
    tax = base_price * tax_rate
    return base_price + tax

print('Total with default 15% tax:', calculate_total(1000))
print('Total with custom 5% tax  :', calculate_total(1000, 0.05))
🖥️ Terminal Output
$ python -c "..."
Total with default 15% tax: 1150.0
Total with custom 5% tax  : 1050.0

🔍 কোড ব্রেকডাউন:

tax_rate=0.15: ডিফল্ট মান থাকায় আর্গুমেন্ট না দিলেও ১৫% ধরে নেয়।

০২ ধাপ ০২: ল্যাম্বডা দিয়ে দ্রুত ছাড় প্রয়োগ

কুপন কোডের জন্য ১ লাইনের ল্যাম্বডা ডিসকাউন্ট ফাংশন:

Python
apply_discount = lambda price, percent: price * (1 - percent / 100)

original = 2000
discounted = apply_discount(original, 20) # 20% discount
print('Original Price  :', original)
print('Discounted Price:', discounted)
🖥️ Terminal Output
$ python -c "..."
Original Price  : 2000
Discounted Price: 1600.0

🔍 কোড ব্রেকডাউন:

lambda price, percent: কোনো def ছাড়া এক লাইনেই ফাংশন তৈরি হয়ে গেছে।

০৩ ধাপ ০৩: ফাংশন কম্পোজিশন (Discount + Tax)

প্রথমে ডিসকাউন্ট তারপর ট্যাক্স হিসাব করে চূড়ান্ত বিল তৈরি:

Python
final_payable = calculate_total(apply_discount(5000, 10), tax_rate=0.10)
print('Final Payable Amount:', final_payable)
🖥️ Terminal Output
$ python -c "..."
Final Payable Amount: 4950.0

🔍 কোড ব্রেকডাউন:

5000 এ ১০% ছাড় = ৪৫০০: ৪৫০০ এর ওপর ১০% ট্যাক্স = ৪৯৫০ টাকা।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
def bill(p, t=0.15): return p * (1 + t)
disc = lambda p, d: p * (1 - d/100)
print('Final:', bill(disc(1000, 20)))
🖥️ Full Terminal Run
Final: 920.0
🎯 মোবাইলে মনে রাখার সারমর্ম:
• def দিয়ে বড় লজিক মডুলার করা হয়。
• lambda দিয়ে ছোট ম্যাপিং সহজে করা যায়。
• ফাংশন রিটার্ন ভ্যালু পরবর্তী ফাংশনের ইনপুট হতে পারে।
