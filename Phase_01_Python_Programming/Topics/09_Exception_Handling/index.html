Robust Exception Handling in Production AI Systems — এক্সেপশন হ্যান্ডলিং: ট্রাই-এক্সেপ্ট ও ডেটা স্ট্রিম রেসিলিয়েন্স

বাস্তব ডেটাসেটের অসংগতি ও মিসিং ভ্যালুর কারণে দীর্ঘমেয়াদী ট্রেনিং ক্র্যাশ হওয়া রোধে ডিফেন্সিভ প্রোগ্রামিং।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

প্রোডাকশন এআই সিস্টেমে এক্সেপশন হ্যান্ডলিং কেন জীবন-মরণ বিষয়?

কল্পনা করুন আপনি ক্লাউডে ৮টি জিপিইউ ভাড়া করে ২৪ ঘণ্টার জন্য একটি ডিপ লার্নিং মডেল ট্রেইন করছেন। ১৬ ঘণ্টার মাথায় ডেটাসেটের একটিমাত্র ফাইলে মিসিং কি (KeyError) বা শূন্য দিয়ে ভাগ (ZeroDivisionError) হওয়ার কারণে পুরো পাইথন স্ক্রিপ্ট ক্র্যাশ করলো! এতে আপনার সময় এবং হাজার হাজার টাকার ক্লাউড বিল নষ্ট হলো। এক্সেপশন হ্যান্ডলিং এই বিপদ থেকে রক্ষা করে:

  • Try-Except ব্লক: ঝুঁকিপূর্ণ অপারেশনগুলোকে try: ব্লকে রাখা হয়। এরর ঘটলে ক্র্যাশ না করে except SpecificError as e: ব্লকে গিয়ে নিরাপদ বিকল্প পথ বেছে নেয়।
  • নির্দিষ্ট এরর ধরা (Catching Specific Exceptions): কখনো খালি except: লিখবেন না। নির্দিষ্ট এরর ধরুন—যেমন ValueError, KeyError, FileNotFoundError।
  • Finally ব্লক: এরর হোক বা না হোক, যে কাজ নিশ্চিত করতেই হবে (যেমন: ডাটাবেস কানেকশন ক্লোজ করা বা জিপিইউ মেমরি ক্লিয়ার করা) তা finally: ব্লকে লেখা হয়।
  • Custom Exception: ডেটা যখন মডেলের বিজনেস লজিক পূরণ করে না (যেমন: ছবির রেজোলিউশন খুব ছোট), তখন raise ValueError("Image dimension mismatch") করা হয়।

ডিফেন্সিভ এআই নীতি: নষ্ট স্যাম্পলকে স্কিপ করে লগ ফাইলে ওয়ার্নিং লিখে রাখুন, কিন্তু ট্রেনিং লুপকে থামতে দেবেন না।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

resilient_data_loader.py 
# ডিফেন্সিভ এআই ডেটালোডার সিমুলেশন
raw_samples = [
    {"id": "S1", "features": [0.5, 0.8], "label": 1},
    {"id": "S2", "features": "corrupted_text", "label": 0},  # ইনভ্যালিড ডেটা
    {"id": "S3", "label": 1},                                # মিসিং ফিচার কি
    {"id": "S4", "features": [0.1, 0.9], "label": 0}
]

valid_batch = []
for sample in raw_samples:
    try:
        sample_id = sample["id"]
        features = sample["features"]
        
        # টাইপ ভ্যালিডেশন
        if not isinstance(features, list):
            raise TypeError(f"Features must be list, got {type(features).__name__}")
            
        valid_batch.append({"id": sample_id, "features": features})
        print(f"✅ স্যাম্পল {sample_id}: সফলভাবে ভ্যালিডেটেড")
        
    except KeyError as e:
        print(f"⚠️ স্কিপড {sample.get('id', 'Unknown')}: মিসিং কি -> {e}")
    except TypeError as e:
        print(f"⚠️ স্কিপড {sample_id}: ডেটা টাইপ ত্রুটি -> {e}")
    finally:
        pass  # রিসোর্স ক্লিনআপ স্টেপ

print(f"\nমোট প্রস্তুতকৃত নির্ভুল স্যাম্পল: {len(valid_batch)}")
🖥️ Terminal Output

⚠️ স্কিপড S2: ডেটা টাইপ ত্রুটি -> Features must be list, got str
⚠️ স্কিপড S3: মিসিং কি -> 'features'
✅ স্যাম্পল S4: সফলভাবে ভ্যালিডেটেড

try-except KeyError: ডিকশনারিতে 'features' কি না পেলে ক্র্যাশ না করে ওয়ার্নিং দিয়ে স্কিপ করেছে।
raise TypeError(...): ফিচার যদি লিস্ট না হয়ে স্ট্রিং হয়, তবে কাস্টম টাইপ এরর রেইজ করা হয়েছে।
