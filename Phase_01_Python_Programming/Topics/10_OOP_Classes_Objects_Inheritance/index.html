OOP: Classes, Objects & Inheritance for Custom Estimators — অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং: এআই মডেল ও এস্টিমেটর ডিজাইন

PyTorch বা Scikit-learn-এর মতো নিজস্ব কাস্টম মডেল ও লেয়ার ডিজাইন করতে অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিংয়ের বাস্তব প্রয়োগ।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

মডার্ন এআই ফ্রেমওয়ার্কগুলো কেন ১০০% অবজেক্ট ওরিয়েন্টেড?

আপনি যখন Scikit-learn-এ model = LinearRegression() লেখেন অথবা PyTorch-এ class NeuralNet(nn.Module): লেখেন, তখন আপনি অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং (OOP) ব্যবহার করছেন। এআই মডেলে স্টেট (ওজন ও বায়াস) এবং বিহেভিয়ার (ফরওয়ার্ড পাস ও প্রেডিকশন) একসাথে এনক্যাপসুলেট করার জন্য OOP ছাড়া আর কোনো বিকল্প নেই:

  • Class & Object: ক্লাস হলো একটি ব্লুপ্রিন্ট (নকশা), আর অবজেক্ট হলো সেই ব্লুপ্রিন্ট থেকে তৈরি সক্রিয় মডেল ইনস্ট্যান্স। যেমন: একটি ক্লাসে fit() ও predict() মেথড থাকে।
  • Constructor (__init__): মডেলের হাইপারপ্যারামিটার (যেমন: লার্নিং রেট বা লেয়ার ডাইমেনশন) ইনিশিয়ালাইজ করতে এবং self.weights মেমরিতে বরাদ্দ করতে __init__ ব্যবহার হয়।
  • Inheritance (উত্তরাধিকার): একটি সাধারণ BaseEstimator ক্লাস থেকে ইনহেরিট করে একাধিক স্পেশালাইজড মডেল (যেমন: LinearModel, LogisticModel) তৈরি করা যায়। এতে কমন কোড বারবার লিখতে হয় না।
  • Polymorphism (বহুরূপিতা): প্রতিটি মডেল ক্লাসে একই নামের predict(X) মেথড থাকে, যার ফলে পাইপলাইনে এক মডেলের জায়গায় আরেক মডেলকে সহজে প্লাগ-ইন করা যায়।

সেলফ (self) কী? self হলো ক্লাসের ভেতরে ওই অবজেক্টটির নিজস্ব রেফারেন্স, যা দিয়ে অবজেক্টটি তার নিজের ওজন (Weights) মনে রাখে।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

custom_estimator.py 
# অবজেক্ট ওরিয়েন্টেড এআই এস্টিমেটর ডিজাইন
class BaseEstimator:
    '''সমস্ত এআই মডেলের সাধারণ প্যারেন্ট ক্লাস'''
    def __init__(self, model_name: str):
        self.model_name = model_name
        self.is_fitted = False

    def get_status(self) -> str:
        return f"{self.model_name} [Fitted: {self.is_fitted}]"

class SimpleLinearRegression(BaseEstimator):
    '''প্যারেন্ট ক্লাস ইনহেরিট করে তৈরি লিনিয়ার মডেল'''
    def __init__(self, slope: float = 2.0, intercept: float = 1.0):
        super().__init__("LinearRegressionModel")
        self.weight = slope
        self.bias = intercept

    def fit(self, x_train: list, y_train: list):
        # ট্রেনিং সম্পন্ন করার ডেমো ফ্ল্যাগ
        self.is_fitted = True
        print(f"[{self.model_name}] ট্রেনিং সম্পন্ন! Weight: {self.weight}, Bias: {self.bias}")

    def predict(self, x_input: float) -> float:
        if not self.is_fitted:
            raise RuntimeError("মডেলটি আগে fit() করতে হবে!")
        return (self.weight * x_input) + self.bias

# মডেল ইনস্ট্যানশিয়েশন ও প্রেডিকশন
model = SimpleLinearRegression(slope=3.5, intercept=2.0)
print("Initial Status :", model.get_status())
model.fit([1, 2, 3], [5.5, 9.0, 12.5])
prediction = model.predict(4.0)
print(f"Prediction for x=4.0 -> y = {prediction:.2f}")

Prediction for x=4.0 -> y = 16.00

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

class BaseEstimator: প্যারেন্ট ক্লাস তৈরি করা হয়েছে যা সব মডেলের সাধারণ স্ট্যাটাস ধারণ করে।
super().__init__(...): চাইল্ড ক্লাসে প্যারেন্ট ক্লাসের কনস্ট্রাক্টর কল করে নাম ইনিশিয়ালাইজ করা হয়েছে।
self.weight, self.bias: অবজেক্টের নিজস্ব অভ্যন্তরীণ মেমরিতে মডেলের প্যারামিটার সংরক্ষণ করা হয়েছে।
model.predict(4.0): অবজেক্ট মেথড কল করে লিনিয়ার ইকুয়েশন ($y = wx + b$) অনুযায়ী প্রেডিকশন ক্যালকুলেট করা হয়েছে।
