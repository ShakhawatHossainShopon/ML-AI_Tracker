তৈরিকৃত মেশিন লার্নিং মডেলকে ওয়েব এপিআইর মাধ্যমে সার্ভ করা এবং ক্লায়েন্ট থেকে ফিচার পাঠিয়ে প্রেডিকশন পাওয়ার সম্পূর্ণ মেকানিজম।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

মডেল বানানোর পর তা দিয়ে কীভাবে সফটওয়্যার চলে?

মডেল ট্রেইন করার পর তা শুধু জুপিটার নোটবুকে রেখে দিলে কোনো ক্লায়েন্ট বা মোবাইল অ্যাপ তা ব্যবহার করতে পারে না। মডেলকে একটি RESTful HTTP API (যেমন: FastAPI বা Flask) দিয়ে ইন্টারনেটে এক্সপোজ করতে হয়:

  • Client-Server Architecture: ক্লায়েন্ট (মোবাইল অ্যাপ বা ব্রাউজার) ফিচার পাঠায়, আর সার্ভার (যেখানে মডেল লোড আছে) প্রেডিকশন হিসাব করে রেসপন্স ফেরত দেয়।
  • HTTP Methods: GET মেথড দিয়ে মডেলের হেলথ বা মেটাডেটা চেক করা হয়। POST মেথড দিয়ে ভারী ফিচার ভেক্টর (যেমন: ছবি বা টেক্সট) সার্ভারে পাঠানো হয়।
  • JSON Payload: মেশিন লার্নিং সার্ভিংয়ের বিশ্বজনীন ভাষা হলো JSON। ক্লায়েন্ট JSON আকারে ইনপুট পাঠায়, মডেল ইনফারেন্স চালিয়ে JSON আকারে ফলাফল দেয়: {"prediction": "fraud", "confidence": 0.98}।
  • HTTP Status Codes: 200 OK (সফল ইনফারেন্স), 400 Bad Request (ভুল ফিচার শেপ), 500 Server Error (মডেল ক্র্যাশ)।

ইনফারেন্স ল্যাটেন্সি: রিয়েল-টাইম এআই অ্যাপ্লিকেশনে নেটওয়ার্ক রিকোয়েস্ট ৫০ মিলি-সেকেন্ডের মধ্যে রেসপন্স দেওয়া অত্যন্ত জরুরি।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

ai_inference_client.py 
import json

# ক্লায়েন্ট থেকে এআই সার্ভারে পাঠানোর সিমুলেটেড রিকোয়েস্ট
class SimulatedAIServer:
    @staticmethod
    def handle_inference(request_json_str: str) -> dict:
        data = json.loads(request_json_str)
        features = data.get("features", [])
        
        # ভ্যালিডেশন
        if len(features) != 3:
            return {"status_code": 400, "error": "ঠিক ৩টি ফিচার ইনপুট প্রত্যাশিত!"}
        
        # সিমুলেটেড লিনিয়ার ডিসিশন বাউন্ডারি
        score = sum(features) / len(features)
        prediction = "High Risk" if score > 0.5 else "Low Risk"
        
        return {
            "status_code": 200,
            "prediction": prediction,
            "confidence_score": round(score, 4)
        }

# ক্লায়েন্ট পেলোড প্রস্তুতি
client_payload = json.dumps({"client_id": "usr_991", "features": [0.75, 0.62, 0.81]})
response = SimulatedAIServer.handle_inference(client_payload)

print(f"HTTP Status  : {response['status_code']}")
print(f"Prediction   : {response['prediction']}")
print(f"Confidence   : {response['confidence_score'] * 100:.2f}%")
🖥️ Terminal Output 
HTTP Status  : 200
Prediction   : High Risk
Confidence   : 72.67%
