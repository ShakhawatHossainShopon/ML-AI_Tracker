আবহাওয়া ও কারেন্সি ক্লায়েন্ট সিমুলেটর (Live API Client)

HTTP রিকোয়েস্ট পাঠিয়ে রেসপন্স রিসিভ করা ও JSON ডেটা প্রসেসিং।

০১ ধাপ ০১: এপিআই রিকোয়েস্ট ও স্ট্যাটাস কোড হ্যান্ডলিং

একটি ডামি এপিআই রেসপন্স প্রসেস করা:

Python
response = {
    'status_code': 200,
    'data': {'city': 'Dhaka', 'temp_c': 28.5, 'humidity': 65}
}

if response['status_code'] == 200:
    w = response['data']
    print(f"Weather in {w['city']}: {w['temp_c']}°C, Humidity: {w['humidity']}%")
else:
    print('Failed to fetch data!')
🖥️ Terminal Output
$ python -c "..."
Weather in Dhaka: 28.5°C, Humidity: 65%

🔍 কোড ব্রেকডাউন:

status_code == 200: সফল রেসপন্স নিশ্চিত হওয়ার পরই ডেটা প্রসেস করা হয়েছে।

০২ ধাপ ০২: POST রিকোয়েস্ট পেলোড ও হেডারের সিমুলেশন

এপিআইতে ডেটা পোস্ট করার কাঠামো:

Python
import json
headers = {'Content-Type': 'application/json', 'Authorization': 'Bearer test_token'}
payload = {'amount': 100, 'currency': 'USD'}

print('Headers:', headers)
print('Payload Sent:', json.dumps(payload))
🖥️ Terminal Output
$ python -c "..."
Headers: {'Content-Type': 'application/json', 'Authorization': 'Bearer test_token'}
Payload Sent: {"amount": 100, "currency": "USD"}

🔍 কোড ব্রেকডাউন:

Authorization: টোকেন দিয়ে অথেনটিকেশন পাঠানো হয়েছে।

০৩ ধাপ ০৩: এপিআই এরর ফলব্যাক

সার্ভার এরর (500) আসলে ক্যাশ ডেটা ব্যবহার করা:

Python
api_status = 500
cached_rate = 118.50 # BDT per USD
if api_status != 200:
    rate = cached_rate
    print(f'Warning: Using cached exchange rate: {rate} BDT')
🖥️ Terminal Output
$ python -c "..."
Warning: Using cached exchange rate: 118.5 BDT

🔍 কোড ব্রেকডাউন:

Fallback: এপিআই ফেইল করলেও অ্যাপ বন্ধ না হয়ে ক্যাশ মান দিয়ে সচল থেকেছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
res = {'status': 200, 'usd_bdt': 118.5}
if res['status'] == 200:
    print('USD to BDT:', res['usd_bdt'])
🖥️ Full Terminal Run
USD to BDT: 118.5
🎯 মোবাইলে মনে রাখার সারমর্ম:
• API সার্ভারের মধ্যে ডেটা আদান-প্রদান করে。
• GET ডেটা আনে, POST ডেটা পাঠায়。
• স্ট্যাটাস কোড ২০০ চেক করা ভালো প্র্যাকটিস।
