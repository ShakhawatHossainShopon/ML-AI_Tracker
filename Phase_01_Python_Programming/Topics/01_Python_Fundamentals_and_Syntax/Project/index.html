02 Task 1: Bitwise Batch Status Flags

Define 4 bitwise flag constants using bit-shift operators (<<):

Flag Constant Bit Shift Syntax Binary Decimal Condition / Trigger
FLAG_VALID 1 << 0 0001 1 Added when training sample passes all checks without errors.
FLAG_CONTAINS_NAN 1 << 1 0010 2 Triggered if any feature value is None, "nan", or mathematically not finite.
FLAG_DIM_MISMATCH 1 << 2 0100 4 Triggered if len(features) != expected_dim.
FLAG_ZERO_WEIGHT 1 << 3 1000 8 Triggered if sample loss weight weight <= 0.0.

03 Task 2: Implement validate_sample(...)

Implement the sample validation function:

def validate_sample(raw_sample: dict, expected_dim: int = 4) -> tuple[dict, int]:

Specifications:

  1. Sample ID: Clean and uppercase sample_id as an immutable string (e.g. "sample_01" → "SAMPLE_01").
  2. Label & Loss Weight:
    • Cast label to int.
    • Cast loss_weight to float rounded to 4 decimal places.
  3. Feature Vector Validation:
    • Check if any value in features is None or equal to string "nan". If so, add FLAG_CONTAINS_NAN.
    • Check if len(features) != expected_dim. If so, add FLAG_DIM_MISMATCH.
    • If features are valid numbers, cast them to float rounded to 4 decimal places.
  4. Weight Check: If loss_weight <= 0.0, add FLAG_ZERO_WEIGHT.
  5. Valid Status: If no error flags were triggered, set status_code = FLAG_VALID.
  6. Return: Return (cleaned_sample_dict, status_code).

04 Task 3: Implement profile_object_memory(...)

Inspect CPython memory properties for tensor/batch objects:

def profile_object_memory(obj: Any, label: str) -> dict:

Required Return Keys:

  • "label": The label string.
  • "type": Object type name: type(obj).__name__.
  • "memory_id_hex": Hex memory address: hex(id(obj)).
  • "ref_count": Adjusted reference count: sys.getrefcount(obj) - 1.
  • "is_mutable": Boolean True for list, dict, set; False for immutable types.
