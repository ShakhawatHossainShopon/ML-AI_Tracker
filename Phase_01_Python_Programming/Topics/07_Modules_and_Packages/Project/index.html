সিকিউর টোকেন জেনারেটর ও অডিট লগার (Token & Audit Utility)

স্ট্যান্ডার্ড মডিউল দিয়ে নিরাপদ রেন্ডম টোকেন ও টাইমস্ট্যাম্প লগার তৈরি।

০১ ধাপ ০১: datetime দিয়ে টাইমস্ট্যাম্প তৈরি

বর্তমান সময় ও তারিখ ফরম্যাট করা:

Python
from datetime import datetime
now = datetime.now()
formatted_time = now.strftime('%Y-%m-%d %H:%M:%S')
print('Current Audit Timestamp:', formatted_time)
🖥️ Terminal Output
$ python -c "..."
Current Audit Timestamp: 2026-11-19 22:50:00

🔍 কোড ব্রেকডাউন:

now.strftime(...): তারিখ ও সময়কে পরিষ্কার স্ট্রিং ফরম্যাটে সাজিয়েছে।

০২ ধাপ ০২: random ও string দিয়ে ইউনিক টোকেন

৮ অক্ষরের আলফানিউমেরিক সিকিউরিটি কোড তৈরি:

Python
import random
import string

chars = string.ascii_uppercase + string.digits
token = ''.join(random.choice(chars) for _ in range(8))
print('Generated Session Token:', token)
🖥️ Terminal Output
$ python -c "..."
Generated Session Token: 7K9X2M4P

🔍 কোড ব্রেকডাউন:

random.choice(chars): অক্ষর ও সংখ্যার মধ্য থেকে এলোমেলো উপাদান নির্বাচন করেছে।

০৩ ধাপ ০৩: math মডিউল দিয়ে ব্যাচ হিসাব

৯৫টি আইটেম প্রতি পেজে ২০টি করে রাখলে কয়টি পেজ লাগবে:

Python
import math
total_items = 95
per_page = 20
total_pages = math.ceil(total_items / per_page)
print(f'Total Pages Required: {total_pages} pages')
🖥️ Terminal Output
$ python -c "..."
Total Pages Required: 5 pages

🔍 কোড ব্রেকডাউন:

math.ceil(4.75): দশমিক সংখ্যাকে পরবর্তী পূর্ণসংখ্যায় (৫) রাউন্ড করেছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
import math, random
print('Random Num:', random.randint(1000, 9999))
print('Square Root:', math.sqrt(144))
🖥️ Full Terminal Run
Random Num: 4821
Square Root: 12.0
🎯 মোবাইলে মনে রাখার সারমর্ম:
• চাকা নতুন করে বানানোর দরকার নেই, মডিউল ব্যবহার করুন。
• import math, random, datetime দৈনন্দিন টুলস。
• নিজের ফাইলকেও মডিউল হিসেবে ইমপোর্ট করা যায়।
