ভেরিয়েবল ও ডেটা টাইপস (Variables & Data Types)

প্রোগ্রামিংয়ের মেমরি বক্স! ইনটিজার, ফ্লোট, স্ট্রিং, বুলিয়ান এবং টাইপ কাস্টিং কীভাবে নিরাপদে ব্যবহার করবেন।

০১ ভেরিয়েবল মানে লেবেলযুক্ত মেমরি বক্স

ভেরিয়েবল হলো কম্পিউটারের মেমরিতে রাখা তথ্যের জন্য একটি লেবেল। পাইথনে কোনো টাইপ আগে থেকে ডিক্লেয়ার করতে হয় না (ডাইনামিক টাইপিং)।

০২ মৌলিক ডেটা টাইপসমূহ

• int: পূর্ণসংখ্যা (age = 25)
• float: দশমিক সংখ্যা (price = 99.50)
• str: টেক্সট ('AI Developer')
• bool: সত্য/মিথ্যা (is_active = True)

০৩ টাইপ কাস্টিং (Type Casting)

ইনপুট বা এপিআই থেকে আসা স্ট্রিং ডেটাকে সংখ্যায় রূপান্তর করা: int('100') বা float('15.5')। টাইপ না মেলালে বড় ধরনের বাগ হতে পারে!
