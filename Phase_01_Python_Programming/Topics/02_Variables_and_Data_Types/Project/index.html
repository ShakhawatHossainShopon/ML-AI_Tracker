ইউজার প্রোফাইল ও স্কোর ভ্যালিডেটর (Profile Type Validator)

স্ট্রিং ইনপুটকে সঠিক ডেটা টাইপে কাস্টিং এবং ভ্যালিডেশন ইঞ্জিন।

০১ ধাপ ০১: ভেরিয়েবল তৈরি ও টাইপ চেক

বিভিন্ন টাইপের ভেরিয়েবল তৈরি করে তাদের টাইপ দেখা:

Python
username = 'rahim_99'
age = 28
wallet_balance = 1250.75
is_premium = True

print('Username :', username, type(username))
print('Balance  :', wallet_balance, type(wallet_balance))
🖥️ Terminal Output
$ python -c "..."
Username : rahim_99 
Balance  : 1250.75

🔍 কোড ব্রেকডাউন:

type(username): স্ট্রিং ডেটা টাইপ শনাক্ত করেছে।
type(wallet_balance): দশমিক সংখ্যা হিসেবে ফ্লোট শনাক্ত করেছে।

০২ ধাপ ০২: টাইপ কাস্টিং (String to Number)

ফর্ম বা এপিআই থেকে আসা স্ট্রিং ডেটাকে সংখ্যায় রূপান্তর করে যোগ করা:

Python
raw_deposit = '500.25'
deposit_amount = float(raw_deposit)
new_balance = wallet_balance + deposit_amount
print('Deposit Added :', deposit_amount)
print('New Balance    :', round(new_balance, 2))
🖥️ Terminal Output
$ python -c "..."
Deposit Added : 500.25
New Balance    : 1751.0

🔍 কোড ব্রেকডাউন:

float(raw_deposit): স্ট্রিং '500.25'-কে সফলভাবে ফ্লোটে রূপান্তর করা হয়েছে।

০৩ ধাপ ০৩: ফরম্যাটেড প্রোফাইল কার্ড (f-string)

সব ডেটা টাইপ একসাথে সুন্দর প্রোফাইল কার্ড আকারে প্রিন্ট করা:

Python
card = f'User: {username} | Age: {age} | Premium: {is_premium} | Balance: ${new_balance:.2f}'
print('Profile Card:', card)
🖥️ Terminal Output
$ python -c "..."
Profile Card: User: rahim_99 | Age: 28 | Premium: True | Balance: $1751.00

🔍 কোড ব্রেকডাউন:

f-string: সব টাইপের ডেটাকে সহজে স্ট্রিংয়ে বসানোর আধুনিক পাইথন সিনট্যাক্স।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
user = 'rahim_99'
age = 28
bal = 1250.75
bal += float('500.25')
print(f'{user} ({age}) - Balance: ${bal:.2f}')
🖥️ Full Terminal Run
rahim_99 (28) - Balance: $1751.00
🎯 মোবাইলে মনে রাখার সারমর্ম:
• পাইথন স্বয়ংক্রিয়ভাবে টাইপ নির্ধারণ করে।
• গাণিতিক কাজের জন্য টাইপ কাস্টিং (int/float) জরুরি。
• f-string দিয়ে সহজে ডেটা ফরম্যাট করা যায়।
