০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

এআই ইঞ্জিনিয়ারিংয়ে ফাইল আই/ও (File I/O) কেন ভিত্তিপ্রস্তর?

যেকোনো মডেল ট্রেনিং শুরুর প্রথম কাজই হলো ডিস্কে থাকা ডেটাসেটকে মেমরিতে লোড করা। পাইথনে ফাইল নিয়ে কাজ করার সময় সবচেয়ে গুরুত্বপূর্ণ নিয়ম হলো with open(...) কনটেক্সট ম্যানেজার ব্যবহার করা। এটি ফাইল পড়া শেষ হলে বা কোনো এরর ঘটলেও স্বয়ংক্রিয়ভাবে ওএস ফাইল হ্যান্ডল ক্লোজ করে মেমরি লিক হওয়া রোধ করে:

  • JSON (JavaScript Object Notation): এআই মডেলের হাইপারপ্যারামিটার (যেমন: লার্নিং রেট, লেয়ার সংখ্যা) এবং ওয়েব এপিআই রেসপন্স সংরক্ষণে json.load() ও json.dump() ব্যবহার করা হয়। এটি সরাসরি পাইথনের ডিকশনারির মতো কাজ করে।
  • CSV (Comma Separated Values): ক্লাসিক্যাল মেশিন লার্নিংয়ের সব টেবুলার ডেটা সিএসভিতে থাকে। পাইথনের বিল্ট-ইন csv.DictReader ব্যবহার করে পান্ডাস ছাড়াও অত্যন্ত দ্রুত প্রতিটি রো পার্স করা যায়।
  • TXT (Raw Corpus): লার্জ ল্যাঙ্গুয়েজ মডেল (LLM) প্রি-ট্রেনিংয়ের জন্য বড় বড় টেক্সট ফাইল লাইন বাই লাইন রিড করে টোকেনাইজারকে দেওয়া হয়।

এনকোডিং টিপ: বাংলা বা স্পেশাল ক্যারেক্টার যুক্ত ডেটা লোড করার সময় সবসময় encoding='utf-8' উল্লেখ করুন, নাহলে এনকোডিং ক্র্যাশ হতে পারে।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

dataset_io_pipeline.py 
import json
import io
import csv

# ১. হাইপারপ্যারামিটার কনফিগ JSON তৈরি ও পার্সিং
config_data = {
    "model_name": "BERT_Sentiment",
    "learning_rate": 0.0003,
    "batch_size": 32,
    "use_gpu": True
}
json_string = json.dumps(config_data, indent=2)
parsed_config = json.loads(json_string)

# ২. মেমরি বাফারে CSV ট্রেনিং ডেটা তৈরি ও পড়া
csv_buffer = io.StringIO()
writer = csv.writer(csv_buffer)
writer.writerow(["Epoch", "Train_Loss", "Val_Accuracy"])
writer.writerow([1, 0.654, 0.72])
writer.writerow([2, 0.412, 0.85])

csv_buffer.seek(0)
reader = csv.DictReader(csv_buffer)
print(f"Loaded Model: {parsed_config['model_name']} (LR: {parsed_config['learning_rate']})")
print("--- Training Metrics CSV ---")
for row in reader:
    print(f"Epoch {row['Epoch']} -> Loss: {row['Train_Loss']} | Acc: {float(row['Val_Accuracy']) * 100:.1f}%")
🖥️ Terminal Output 
Loaded Model: BERT_Sentiment (LR: 0.0003)
--- Training Metrics CSV ---
Epoch 1 -> Loss: 0.654 | Acc: 72.0%
Epoch 2 -> Loss: 0.412 | Acc: 85.0%

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

json.dumps() / json.loads(): মডেল কনফিগারেশনকে জেসন স্ট্রিংয়ে রূপান্তর এবং পুনরায় অবজেক্টে পার্স করা হয়েছে।
csv.DictReader(csv_buffer): সিএসভি ফাইল থেকে প্রতিটি সারিকে ডিকশনারি আকারে পড়া হয়েছে (কলাম নাম কি হিসেবে কাজ করে)।
float(row['Val_Accuracy']): সিএসভি থেকে পাওয়া স্ট্রিং ডেটাকে সংখ্যায় কাস্ট করে শতাংশে রূপান্তর করা হয়েছে।
