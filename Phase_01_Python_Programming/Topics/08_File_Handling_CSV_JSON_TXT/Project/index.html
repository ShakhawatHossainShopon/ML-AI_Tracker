অ্যাপ কনফিগ ও ইউজার অডিট ম্যানেজার (Config & Log Exporter)

JSON কনফিগারেশন তৈরি, টেক্সট ফাইলে লগ সংরক্ষণ ও ডাটা পার্সিং।

০১ ধাপ ০১: JSON ডেটা স্ট্রিংয়ে রূপান্তর ও রিড করা

ডিকশনারিকে JSON ফরম্যাটে রূপান্তর ও রিড করা:

Python
import json

config = {'app_name': 'AITracker', 'version': 1.0, 'debug': True}
json_str = json.dumps(config, indent=2)
print('JSON Encoded String:\n', json_str)

parsed_back = json.loads(json_str)
print('Parsed App Name:', parsed_back['app_name'])
🖥️ Terminal Output
$ python -c "..."
JSON Encoded String:
{
  "app_name": "AITracker",
  "version": 1.0,
  "debug": true
}
Parsed App Name: AITracker

🔍 কোড ব্রেকডাউন:

json.dumps: পাইথন অবজেক্টকে JSON স্ট্রিং বানায়।
json.loads: JSON স্ট্রিংকে পাইথন ডিকশনারি বানায়।

০২ ধাপ ০২: টেক্সট ফাইলে অডিট লগ তৈরি (মেমরি সিমুলেশন)

লগ মেসেজ টেক্সট লাইনে ফরম্যাট করা:

Python
logs = ['[INFO] System started', '[AUTH] User login: admin', '[WARN] Low disk space']
log_content = '\n'.join(logs)
print('Formatted Log File Content:\n' + log_content)
🖥️ Terminal Output
$ python -c "..."
Formatted Log File Content:
[INFO] System started
[AUTH] User login: admin
[WARN] Low disk space

🔍 কোড ব্রেকডাউন:

join(logs): প্রতিটি লগ এন্ট্রিকে নতুন লাইনে যুক্ত করেছে।

০৩ ধাপ ০৩: CSV টেবিল পার্সিং

কমা-সেপারেটেড টেক্সট লাইনকে পাইথন ডিকশনারি লিস্টে রূপান্তর:

Python
csv_data = 'name,role\nRahim,Admin\nKarim,Editor'
lines = csv_data.split('\n')
headers = lines[0].split(',')
rows = [dict(zip(headers, l.split(','))) for l in lines[1:]]
print('Parsed CSV Rows:', rows)
🖥️ Terminal Output
$ python -c "..."
Parsed CSV Rows: [{'name': 'Rahim', 'role': 'Admin'}, {'name': 'Karim', 'role': 'Editor'}]

🔍 কোড ব্রেকডাউন:

zip(headers, ...): কলাম হেডার ও ডেটাকে মিলিয়ে ডিকশনারি বানিয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

full_code.py
import json
d = {'model': 'linear_reg', 'acc': 0.94}
print('JSON:', json.dumps(d))
🖥️ Full Terminal Run
JSON: {"model": "linear_reg", "acc": 0.94}
🎯 মোবাইলে মনে রাখার সারমর্ম:
• ফাইলে কাজ করতে সবসময় with open() ব্যবহার করবেন。
• json.loads / json.dumps ডেটা আদান-প্রদানের সেতু。
• CSV হলো ডেটা সায়েন্সের সবচেয়ে সাধারণ ফাইল ফরম্যাট।
