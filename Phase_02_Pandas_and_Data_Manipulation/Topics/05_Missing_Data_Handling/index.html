Missing Data Handling: isna, dropna & fillna — মিসিং ডেটা হ্যান্ডলিং: isna, dropna ও fillna কৌশল

বাস্তব জগতের অপরিচ্ছন্ন ডেটা হ্যান্ডলিং। NaN ডিটেকশন (isna, notna), স্মার্ট রিমুভাল (dropna thresholds), সেন্ট্রাল টেন্ডেন্সি দিয়ে ইম্পিউটেশন (fillna) এবং টাইম-সিরিজ ইন্টারপোলেশন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

মিসিং ডেটার প্যাটার্ন ও নিরাপদ ইম্পিউটেশন কৌশল

মেশিন লার্নিং অ্যালগরিদমগুলো (যেমন: Scikit-learn লিনিয়ার মডেল, এসভিএম বা নিউরাল নেট) ডেটাসেটে NaN (Not a Number) থাকলে ক্র্যাশ করে।

  • ১. ডিটেকশন ও সামারি:
    df.isna().sum(): প্রতিটি কলামে কতগুলো মিসিং মান রয়েছে তার তালিকা।
    df.isna().mean() * 100: মিসিং মানের শতকরা হার।
  • ২. অপসারণ (Dropping): df.dropna()
    how='any': সারিতে অন্তত একটি ন্যান থাকলে সারি মুছে ফেলে।
    thresh=5: সারিতে অন্তত ৫টি বৈধ নন-নাল মান না থাকলে বাদ দেয়।
    subset=['Target']: কেবল নির্দিষ্ট কলামের মিসিং রো বাদ দেওয়া।
  • ৩. ইম্পিউটেশন (Imputation): df.fillna()
    - সংখ্যাত্মক কলামে: Mean বা Median দিয়ে পূরণ।
    - টাইম-সিরিজ ডেটায়: ffill (Forward fill - আগের দিনের মান ধার করা) বা bfill।
    - কন্টিনিউয়াস ডেটায়: df.interpolate(method='linear') রৈখিক অনুমান।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

pandas_missing_data_demo.py 
import pandas as pd
import numpy as np

# মিসিং ভ্যালুযুক্ত সেন্সর রিডিং
df = pd.DataFrame({
    'Timestamp': pd.date_range('2026-03-01', periods=6, freq='D'),
    'Temperature': [22.0, np.nan, 24.5, np.nan, 26.0, 26.5],
    'Humidity': [45, 48, np.nan, 52, 50, np.nan],
    'Status': ['OK', 'OK', np.nan, 'OK', 'ALERT', 'OK']
})

print("--- Original DataFrame with NaNs ---")
print(df)
print("\nMissing Counts:\n", df.isna().sum())

# ১. ফরওয়ার্ড ফিল (Time-series continuity)
df_ffill = df['Temperature'].ffill()

# ২. লিনিয়ার ইন্টারপোলেশন (মসৃণ তাপমাত্রা ট্রানজিশন)
df_interpolated = df['Temperature'].interpolate(method='linear')

# ৩. মিডিয়ান ও মোড ইম্পিউটেশন
hum_median = df['Humidity'].median()
df['Humidity'] = df['Humidity'].fillna(hum_median)

status_mode = df['Status'].mode()[0]
df['Status'] = df['Status'].fillna(status_mode)

df['Temp_Clean'] = df_interpolated

print("\n--- Cleaned DataFrame (Interpolated Temp, Median Humidity, Mode Status) ---")
print(df[['Timestamp', 'Temp_Clean', 'Humidity', 'Status']])
