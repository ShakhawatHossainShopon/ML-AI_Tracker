GroupBy Operations & Multi-Aggregation — গ্রুপবাই অপারেশন ও বহুবিধ অ্যাগ্রিগেশন (Split-Apply-Combine)

SQL GROUP BY-এর আধুনিক রূপ। Split-Apply-Combine প্যারাডাইম, agg() দিয়ে কাস্টম মাল্টি-ফাংশন অ্যাগ্রিগেশন, transform() দিয়ে গ্রুপ-নরমালাইজেশন এবং filter() মেথড।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

Split-Apply-Combine কৌশল ও গ্রুপ ম্যাথমেটিক্স

GroupBy হলো ডেটা বিশ্লেষণের সবচেয়ে শক্তিশালী কৌশল। এটি ৩টি ধাপে কাজ করে:
১. Split: কোনো নির্দিষ্ট কলামের মানের ভিত্তিতে ডেটাকে টুকরো টুকরো গ্রুপে ভাগ করা।
২. Apply: প্রতিটি গ্রুপের ওপর স্বাধীনভাবে কোনো গাণিতিক ফাংশন (Mean, Sum, Count ইত্যাদি) প্রয়োগ করা।
৩. Combine: সমস্ত গ্রুপের ফলাফল একত্র করে একটি একক ডেটাফ্রেমে উপস্থাপন করা।

  • df.groupby('Category')['Sales'].sum(): বেসিক গ্রুপবাই।
  • df.groupby('Dept').agg({'Salary': ['mean', 'max'], 'Age': 'min'}): একাধিক কলামে ভিন্ন ভিন্ন ফাংশন চালানো।
  • df.groupby('Dept')['Salary'].transform('mean'): অ্যাগ্রিগেশন করার পর মূল ডেটাফ্রেমের সমান দৈর্ঘ্যে মানগুলো ব্রডকাস্ট করে ফেরত দেয় (গ্রুপ সেন্টারিংয়ের জন্য দারুণ)।
  • df.groupby('Category').filter(lambda g: len(g) > 10): ছোট গ্রুপগুলোকে বাদ দেওয়া।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

pandas_groupby_agg_demo.py 
import pandas as pd

# রিটেইল সেলস ডেটাসেট
df = pd.DataFrame({
    'Store': ['Dhaka', 'Dhaka', 'Chittagong', 'Chittagong', 'Sylhet', 'Dhaka'],
    'Category': ['Electronics', 'Grocery', 'Electronics', 'Grocery', 'Grocery', 'Electronics'],
    'Revenue': [12000, 3500, 15000, 4200, 2800, 9500],
    'Discount': [500, 100, 800, 150, 50, 300]
})

# ১. মাল্টি-লেভেল অ্যাগ্রিগেশন: agg()
store_summary = df.groupby('Store').agg(
    Total_Revenue=('Revenue', 'sum'),
    Avg_Revenue=('Revenue', 'mean'),
    Max_Discount=('Discount', 'max'),
    Tx_Count=('Revenue', 'count')
).round(1)

# ২. transform() দিয়ে গ্রুপ পারসেন্টেজ কন্ট্রিবিউশন
# প্রতিটি স্টোরের নিজস্ব টোটালের কত পারসেন্ট প্রতিটি ট্রানজেকশন কভার করেছে
store_totals = df.groupby('Store')['Revenue'].transform('sum')
df['Store_Revenue_Share'] = ((df['Revenue'] / store_totals) * 100).round(2)

print("--- Original Retail Transactions ---")
print(df[['Store', 'Category', 'Revenue', 'Store_Revenue_Share']])
print("\n--- Store-Level Aggregation Summary ---")
print(store_summary)

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• agg(Total_Revenue=('Revenue', 'sum'), ...): আধুনিক Named Aggregation সিনট্যাক্স দিয়ে ক্লিন কলামের নাম তৈরি হয়েছে।
• transform('sum'): মূল ডেটাফ্রেমের প্রতিটি রো-তে সংশ্লিষ্ট স্টোরের মোট রেভিনিউ বসিয়ে শেয়ার পারসেন্টেজ বের করেছে।
