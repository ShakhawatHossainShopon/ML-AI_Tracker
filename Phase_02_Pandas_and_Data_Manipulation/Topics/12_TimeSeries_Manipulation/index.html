Time-Series: Resampling, Rolling & Shifting — টাইম-সিরিজ ম্যানিপুলেশন: Resampling, Rolling ও Shifting

ফাইন্যান্সিয়াল ও স্টক মার্কেট ডেটা মডেলিং। DatetimeIndex সেট করা, ফ্রিকোয়েন্সি রূপান্তর (resample 'D', 'W', 'M'), মুভিং এভারেজ (rolling window) এবং ল্যাগ ফিচার তৈরি (shift, pct_change)।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

টাইম-সিরিজ ম্যাথমেটিক্স ও উইন্ডো অপারেশন

টাইম-সিরিজ ডেটা সাধারণ টেবুলার ডেটার চেয়ে আলাদা, কারণ এতে সময়ের ধারাবাহিকতা ও নির্ভরতা থাকে।

  • ১. DatetimeIndex: তারিখ কলামটিকে সূচক বা Index হিসেবে সেট করলে (df.set_index('Date')) শক্তিশালী টাইম-স্লাইসিং করা সম্ভব হয়: df['2026-03']।
  • ২. Resampling (ফ্রিকোয়েন্সি পরিবর্তন):
    - Downsampling: দৈনিক ডেটাকে সাপ্তাহিক বা মাসিকে রূপান্তর: df.resample('W').mean()
    - Upsampling: দৈনিক ডেটাকে প্রতি ঘণ্টার ডেটায় নেওয়া (ইন্টারপোলেশন সহ)।
  • ৩. Rolling Window (মুভিং এভারেজ):
    বাজারের নয়েজ দূর করে ট্রেন্ড বুঝতে নির্দিষ্ট উইন্ডোর গড় হিসাব:
    df['Close'].rolling(window=7).mean() (৭ দিনের সিম্পল মুভিং এভারেজ - SMA)।
  • ৪. Shifting ও পারসেন্টেজ রিটার্ন:
    - df['Close'].shift(1): মানগুলোকে ১ ধাপ ভবিষ্যতে ঠেলে দেয় (ল্যাগ ফিচার)।
    - df['Close'].pct_change(): \((P_t - P_{t-1}) / P_{t-1}\) বা স্টক রিটার্ন।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

pandas_timeseries_demo.py 
import pandas as pd
import numpy as np

# ১০ দিনের কাল্পনিক স্টক প্রাইস ডেটাসেট
np.random.seed(42)
dates = pd.date_range('2026-03-01', periods=10, freq='D')
stock_prices = [100.0, 102.5, 101.0, 104.0, 108.0, 107.5, 111.0, 115.0, 113.0, 118.0]

df = pd.DataFrame({'Close': stock_prices}, index=dates)

# ১. ৩-দিনের মুভিং এভারেজ (Rolling SMA)
df['SMA_3D'] = df['Close'].rolling(window=3).mean()

# ২. ল্যাগ ফিচার (আগের দিনের দাম)
df['Prev_Close'] = df['Close'].shift(1)

# ৩. দৈনিক রিটার্ন পারসেন্টেজ (pct_change)
df['Daily_Return_Pct'] = (df['Close'].pct_change() * 100).round(2)

# ৪. সাপ্তাহিক রিস্যাম্পলিং (Downsampling to Weekly)
weekly_summary = df['Close'].resample('W').agg(['first', 'last', 'max', 'min'])

print("--- Stock Time-Series Features ---")
print(df.round(2))
print("\n--- Weekly Resampled OHLC Summary ---")
print(weekly_summary)

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• rolling(window=3).mean(): ৩ দিনের উইন্ডো দিয়ে স্বল্পমেয়াদী মার্কেট ভোলাটিলিটি স্মুথ করেছে।
• shift(1): ডেটা লিকেজ ছাড়া সুপারভাইজড ফোরকাস্টিং মডেলের জন্য ল্যাগ ফিচার বানিয়েছে।
