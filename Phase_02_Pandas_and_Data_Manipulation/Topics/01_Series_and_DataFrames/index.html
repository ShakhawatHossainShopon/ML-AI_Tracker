Series & DataFrames Anatomy — সিরিজ ও ডেটাফ্রেম অ্যানাটমি: ইনডেক্স, কলাম ও ডেটাটাইপ

Pandas-এর মৌলিক দুটি ডেটা স্ট্রাকচার। 1D লেবেলযুক্ত pd.Series এবং 2D টেবুলার pd.DataFrame এর অভ্যন্তরীণ গঠন, মেটাডেটা ইন্সপেকশন (info, describe, dtypes) ও মেমোরি কনজাম্পশন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

Pandas ডেটা স্ট্রাকচারের মৌলিক অ্যানাটমি

Pandas হলো ডেটা ম্যানিপুলেশন ও অ্যানালাইসিসের জন্য পাইথনের সবচেয়ে জনপ্রিয় ইন্ডাস্ট্রি-স্ট্যান্ডার্ড লাইব্রেরি। এটি মূলত NumPy-এর ওপর ভিত্তি করে নির্মিত, কিন্তু এতে রয়েছে লেবেলযুক্ত ইনডেক্সিং ও টেবুলার হ্যান্ডলিং সুবিধা।

  • ১. pd.Series: একটি ১D লেবেলযুক্ত সমজাতীয় অ্যারে। এতে উপাত্তের পাশাপাশি একটি স্পষ্ট Index সংযুক্ত থাকে।
    যেমন: একটি নির্দিষ্ট অ্যাসেটের দৈনিক রিটার্ন বা কোনো গ্রাহকের ফিচার ভেক্টর।
  • ২. pd.DataFrame: একটি ২D স্প্রেডশিট বা এসকিউএল টেবিলের মতো স্ট্রাকচার, যা একাধিক সিরিজের সমন্বয়ে গঠিত (যেখানে প্রতিটি কলাম একটি Series)।
  • গুরুত্বপূর্ণ ইন্সপেকশন মেথডস:
    df.shape: সারি ও কলামের মোট সংখ্যা।
    df.dtypes: প্রতিটি কলামের ডেটাটাইপ (int64, float64, object, datetime64)।
    df.info(): মেমোরি ব্যবহার ও নন-নাল ভ্যালুর সারসংক্ষেপ।
    df.describe(): সংখ্যাত্মক কলামগুলোর গড়, স্ট্যান্ডার্ড ডেভিয়েশন, কোয়ার্টাইলসের একপলক পরিসংখ্যান।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

pandas_series_dataframe_demo.py 
import pandas as pd
import numpy as np

# ১. pd.Series তৈরি (কাস্টম ইনডেক্সসহ)
monthly_revenue = pd.Series([45000, 52000, 61000], index=['Jan', 'Feb', 'Mar'], name="Revenue")

# ২. ডিকশনারি থেকে pd.DataFrame তৈরি
data = {
    'Customer_ID': [1001, 1002, 1003, 1004],
    'Age': [25, 34, 45, 29],
    'Annual_Income': [55000.0, 82000.0, 110000.0, 64000.0],
    'Churn': [0, 1, 0, 0]
}
df = pd.DataFrame(data)

print("--- Pandas Series ---")
print(monthly_revenue)
print("\n--- Pandas DataFrame ---")
print(df)
print("\n--- Metadata Summary (info) ---")
print(df.dtypes)
print("\n--- Statistical Summary (describe) ---")
print(df.describe().round(1))

• pd.Series(..., index=['Jan', 'Feb', 'Mar']): স্বয়ংক্রিয় সংখ্যার বদলে অর্থপূর্ণ লেবেল দিয়ে ইনডেক্সিং করা হয়েছে।
