Reading & Writing CSV, Excel & JSON — ফাইল রিডিং ও এক্সপোর্ট: CSV, Excel ও JSON হ্যান্ডলিং

বিশাল ডেটাসেট হ্যান্ডলিংয়ের প্রোডাকশন কৌশল। pd.read_csv এর সাথে chunksize, parse_dates, usecols এবং হাই-পারফরম্যান্স JSON ও Excel রিডিং ও রাইটিং।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

ইনপুট/আউটপুট (I/O) অপ্টিমাইজেশন ও চাঙ্ক প্রসেসিং

বাস্তব জীবনে ফাইল লোডিং কেবল pd.read_csv('file.csv') লিখলেই চলে না; গিগাবাইট সাইজের ডেটায় মেমোরি ক্র্যাশ ঠেকাতে সঠিক প্যারামিটার ব্যবহার করতে হয়।

  • usecols=['colA', 'colB']: অপ্রয়োজনীয় কলাম বাদ দিয়ে কেবল কাঙ্ক্ষিত কলাম লোড করে র‍্যাম ৮০% পর্যন্ত সাশ্রয় করে।
  • dtype={'User_ID': 'int32', 'Score': 'float32'}: টাইপ ইনফারেন্স ওভারহেড দূর করে এবং মেমোরি অপ্টিমাইজ করে।
  • parse_dates=['Date_Col']: স্ট্রিং তারিখকে স্বয়ংক্রিয়ভাবে datetime64 এ রূপান্তর করে।
  • chunksize=10000: পুরো ফাইল একসাথে লোড না করে ব্যাচ আকারে ইটারেট করার সুযোগ দেয় (বিগ ডেটার জন্য জীবনরক্ষাকারী মেথড)।
  • df.to_csv('out.csv', index=False): ইনডেক্স ডুপ্লিকেশন ছাড়া ক্লিন ফাইল এক্সপোর্ট।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

pandas_io_pipeline.py 
import pandas as pd
import io

# একটি স্যাম্পল CSV স্ট্রিং ডেটা (ফাইল সিমুলেশন)
csv_raw = """Transaction_ID,Date,Amount,Status
TX101,2026-03-01,150.50,Success
TX102,2026-03-01,2300.00,Success
TX103,2026-03-02,45.00,Failed
TX104,2026-03-03,890.25,Success
"""

# অপ্টিমাইজড রিডিং: parse_dates এবং usecols ব্যবহার
df = pd.read_csv(
    io.StringIO(csv_raw),
    usecols=['Date', 'Amount', 'Status'],
    parse_dates=['Date'],
    dtype={'Amount': 'float32', 'Status': 'category'}
)

print("--- Loaded Optimized DataFrame ---")
print(df)
print("\n--- Column Data Types ---")
print(df.dtypes)
print("\nMemory Usage per column:")
print(df.memory_usage(deep=True))

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• parse_dates=['Date']: স্ট্রিং টেক্সটকে ন্যানোসেকেন্ড প্রিসিশনের datetime অবজেক্টে পরিণত করেছে।
• Status: 'category': বারবার আসা স্ট্রিংগুলোকে ক্যাটেগরিক্যাল পূর্ণসংখ্যায় রূপান্তর করে মেমোরি ৯০% কমিয়েছে।
