Project Breakdown Phase 03 — Topic 03 Mobile View

ক্রিপ্টো অ্যাসেট ভোলাটিলিটি ও রিস্ক স্কোরার (Crypto Asset Volatility & Risk Scorer)

দুটি ডিজিটাল অ্যাসেটের দৈনিক ওঠানামার ভ্যারিয়েন্স ও স্ট্যান্ডার্ড ডেভিয়েশন পরিমাপ করে ঝুঁকি স্কোর নির্ধারণ।

০১ ধাপ ০১: অ্যাসেট রিটার্ন ও গড় হিসেব

দুটি অ্যাসেটের ৭ দিনের লাভ/ক্ষতির গড় হিসাব করা:

step1_returns.py 
returns_a = [3.0, 3.2, 2.8, 3.1, 2.9, 3.0, 3.0]
returns_b = [-10.0, 20.0, -5.0, 15.0, -8.0, 12.0, -3.0]

mean_a = sum(returns_a) / len(returns_a)
mean_b = sum(returns_b) / len(returns_b)

print(f"Asset A Average Return: {mean_a:.2f}%")
print(f"Asset B Average Return: {mean_b:.2f}%")
🖥️ Terminal Output 
Asset A Average Return: 3.00%
Asset B Average Return: 3.00%

🔍 কোড ব্রেকডাউন:

উভয় অ্যাসেটেরই গড় দৈনিক রিটার্ন ঠিক ৩.০০%।

০২ ধাপ ০২: ভ্যারিয়েন্স ও পরিমিত ব্যবধান

ব্যাসেলের কারেকশন (N-1) দিয়ে স্যাম্পল ভ্যারিয়েন্স নির্ণয়:

step2_variance.py 
n = len(returns_a)
var_a = sum((x - mean_a)**2 for x in returns_a) / (n - 1)
sd_a = var_a ** 0.5

var_b = sum((x - mean_b)**2 for x in returns_b) / (n - 1)
sd_b = var_b ** 0.5

print(f"Asset A -> Var: {var_a:.4f} | StdDev: {sd_a:.2f}%")
print(f"Asset B -> Var: {var_b:.4f} | StdDev: {sd_b:.2f}%")
🖥️ Terminal Output 
Asset A -> Var: 0.0167 | StdDev: 0.13%
Asset B -> Var: 147.6667 | StdDev: 12.15%

🔍 কোড ব্রেকডাউন:

Asset B এর স্ট্যান্ডার্ড ডেভিয়েশন ১২.১৫%, যা Asset A (০.১৩%) এর তুলনায় প্রায় ১০০ গুণ বেশি ঝুঁকিপূর্ণ!

০৩ ধাপ ০৩: অটোমেটেড রিস্ক রেটিং

স্ট্যান্ডার্ড ডেভিয়েশনের ওপর ভিত্তি করে ঝুঁকি ক্যাটাগরাইজেশন:

step3_risk_level.py 
def rate_risk(sd):
    if sd < 1.0: return "LOW RISK (Conservative)"
    if sd < 5.0: return "MODERATE RISK"
    return "HIGH RISK (Speculative)"

print("Asset A Rating:", rate_risk(sd_a))
print("Asset B Rating:", rate_risk(sd_b))
🖥️ Terminal Output 
Asset A Rating: LOW RISK (Conservative)
Asset B Rating: HIGH RISK (Speculative)

🔍 কোড ব্রেকডাউন:

অ্যালগরিদমিক ট্রেডিং বট এই স্কোরের ভিত্তিতে পোর্টফোলিওতে সম্পদ বরাদ্দ করে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_volatility.py 
returns_a = [3.0, 3.2, 2.8, 3.1, 2.9, 3.0, 3.0]
returns_b = [-10.0, 20.0, -5.0, 15.0, -8.0, 12.0, -3.0]
n = len(returns_a)
sd_a = (sum((x - 3.0)**2 for x in returns_a) / (n - 1)) ** 0.5
sd_b = (sum((x - 3.0)**2 for x in returns_b) / (n - 1)) ** 0.5
print(f"Asset A Risk: {sd_a:.2f}% | Asset B Risk: {sd_b:.2f}%")
🖥️ Full Terminal Run 
Asset A Risk: 0.13% | Asset B Risk: 12.15%
🎯 মোবাইলে মনে রাখার সারমর্ম:
• গড় একা ঝুঁকি প্রকাশ করতে পারে না।
• ভ্যারিয়েন্স বিচ্যুতির বর্গের গড় নির্দেশ করে।
• স্ট্যান্ডার্ড ডেভিয়েশন মূল এককে ফিরে এসে বাস্তব ঝুঁকি পরিমাপ করে।
