P-Values and Statistical Significance — পি-ভ্যালু ও পরিসংখ্যানিক তাৎপর্য: আলফা থ্রেশহোল্ড ও ডিসিশন মেকিং

p < 0.05 এর আসল গাণিতিক অর্থ কী? ফলাফল কি কাকতালীয় নাকি বাস্তব? পি-ভ্যালু হিসাব এবং আলফা থ্রেশহোল্ডের মাধ্যমে চূড়ান্ত বৈজ্ঞানিক সিদ্ধান্ত।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

পি-ভ্যালু (P-Value): আধুনিক বিজ্ঞানের সবচেয়ে বিতর্কিত ও শক্তিশালী পরিমাপ

হাইপোথিসিস টেস্টিংয়ের রায় ঘোষণার চূড়ান্ত স্কেল হলো পি-ভ্যালু (P-Value)। এটি কোনো দাবি সত্য হওয়ার সম্ভাবনা নয়, বরং নাল হাইপোথিসিস সত্য হলে বর্তমান প্রাপ্ত স্যাম্পলের মতো বা তার চেয়েও চরম ফলাফল নিছক ভাগ্যের জোরে ঘটার সম্ভাবনা।

  • পি-ভ্যালুর আনুষ্ঠানিক সংজ্ঞা:
    P-value = P(Data as extreme as observed | H0 is True)
  • গোল্ডেন রুল: 'If p is low, H0 must go!':
    • p ≤ α (সাধারণত 0.05): ফলাফলটি পরিসংখ্যানগতভাবে তাৎপর্যপূর্ণ (Statistically Significant)। নাল হাইপোথিসিস বাতিল (Reject H0) করে নতুন দাবি গ্রহণ করা হয়।
    • p > α (0.05 এর বেশি): ফলাফলটি নিছক কাকতালীয় হতে পারে। নাল হাইপোথিসিস বাতিল করার পর্যাপ্ত প্রমাণ নেই (Fail to Reject H0)।
  • সাধারণ ভুল ধারণা:
    ভুল: 'p = 0.03 মানে আমাদের মডেল ৯৭% সত্য।'
    সঠিক: 'যদি মডেলের কোনো আসল উন্নতি নাও হতো, তবুও নিছক ভাগ্যের ফেরে এমন ভালো ফলাফল পাওয়ার সম্ভাবনা ছিল মাত্র ৩%।'
  • এআই এক্সপেরিমেন্টেশন: ড্রপআউট রেট পরিবর্তন বা নতুন হাইপারপ্যারামিটার সত্যিই লস কমাচ্ছে কিনা তা পি-ভ্যালুর মাধ্যমে ক্রস-চেক করা হয়।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

p_value_significance_engine.py 
# -------------------------------------------------------------
# Topic 14: P-Value Calculation and Statistical Significance
# -------------------------------------------------------------

import math

def normal_cdf(z):
    """স্ট্যান্ডার্ড নরমাল কিউমুলেটিভ ডেনসিটি ফাংশন (CDF)"""
    return 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))

def calculate_two_tailed_p_value(z_score):
    """দ্বিমুখী (Two-Tailed) z-টেস্টের p-value নির্ণয়"""
    abs_z = abs(z_score)
    # লেজের দিকের সম্ভাবনা (Tail area)
    tail_prob = 1.0 - normal_cdf(abs_z)
    return 2.0 * tail_prob

test_scenarios = [
    ("Minor Random Fluctuation", 0.65),
    ("Moderate Effect", 1.96),
    ("Noticeable Significant Gain", 2.58),
    ("Massive Algorithmic Breakthrough", 4.20)
]

alpha = 0.05

print(f"{'Experiment Name':<32} {'Z-Score':<10} {'P-Value':<12} {'Result (α=0.05)'}")
print("-" * 75)

for name, z in test_scenarios:
    p_val = calculate_two_tailed_p_value(z)
    if p_val <= alpha:
        verdict = f"SIGNIFICANT (p <= {alpha})"
    else:
        verdict = f"NOT Significant (p > {alpha})"
        
    print(f"{name:<32} {z:<10.2f} {p_val:<12.5f} {verdict}")

print("-" * 75)
print("Key Takeaway : When Z=4.20, p=0.00003, meaning there is only a 0.003% chance this happened by luck!")
