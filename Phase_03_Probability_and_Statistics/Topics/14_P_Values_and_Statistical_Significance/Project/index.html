পি-ভ্যালু ও তাৎপর্য সিদ্ধান্ত ম্যাট্রিক্স (P-Value & Significance Decision Matrix)

বিভিন্ন এক্সপেরিমেন্টের Z-স্কোর থেকে নিখুঁত দ্বিমুখী পি-ভ্যালু ক্যালকুলেশন এবং আলফা থ্রেশহোল্ড কম্প্যারিজম।

০১ ধাপ ০১: এরর ফাংশন ও নরমাল CDF

গণিতের বিখ্যাত erf() দিয়ে নরমাল ইন্টিগ্রাল তৈরি করা:

step1_cdf.py 
import math

def normal_cdf(z):
    return 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))

print("Cumulative area at Z = 0.0 :", round(normal_cdf(0.0), 4))
print("Cumulative area at Z = 1.96:", round(normal_cdf(1.96), 4))
🖥️ Terminal Output 
Cumulative area at Z = 0.0 : 0.5
Cumulative area at Z = 1.96: 0.975

🔍 কোড ব্রেকডাউন:

Z = ১.৯৬ এ কিউমুলেটিভ সম্ভাবনা ৯৭.৫%, অর্থাৎ উপরের লেজে বাকি থাকে মাত্র ২.৫%।

০২ ধাপ ০২: দ্বিমুখী P-Value সূত্র

উভয় প্রান্তের লেজের সম্ভাবনা যোগ করে পি-ভ্যালু বের করা:

step2_p_calc.py 
def get_p_value(z):
    tail = 1.0 - normal_cdf(abs(z))
    return 2.0 * tail

print("Z = 1.00 -> P-Value:", round(get_p_value(1.00), 5))
print("Z = 1.96 -> P-Value:", round(get_p_value(1.96), 5))
print("Z = 2.58 -> P-Value:", round(get_p_value(2.58), 5))
🖥️ Terminal Output 
Z = 1.00 -> P-Value: 0.31731
Z = 1.96 -> P-Value: 0.05
Z = 2.58 -> P-Value: 0.00988

🔍 কোড ব্রেকডাউন:

Z = ১.৯৬ তে ঠিক p = ০.০৫ অর্জিত হয়েছে যা আলফা সহনশীল সীমার সমান।

০৩ ধাপ ০৩: সিদ্ধান্ত ম্যাট্রিক্স অটোমেশন

p < 0.05 রুল অনুযায়ী স্বয়ংক্রিয় বৈজ্ঞানিক রায়:

step3_decision_matrix.py 
alpha = 0.05
experiments = [("Model V1", 1.25), ("Model V2", 2.15), ("Model V3", 3.45)]

for name, z in experiments:
    p = get_p_value(z)
    status = "STATISTICALLY SIGNIFICANT" if p <= alpha else "FAIL (Random Noise)"
    print(f"{name} (Z={z:.2f}) -> p={p:.5f} | {status}")
🖥️ Terminal Output 
Model V1 (Z=1.25) -> p=0.21130 | FAIL (Random Noise)
Model V2 (Z=2.15) -> p=0.03156 | STATISTICALLY SIGNIFICANT
Model V3 (Z=3.45) -> p=0.00056 | STATISTICALLY SIGNIFICANT

🔍 কোড ব্রেকডাউন:

Model V2 এবং V3 উভয়ই আলফা সীমানা উত্তীর্ণ হয়ে প্রোডাকশন ক্যান্ডিডেট হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_p_value_engine.py 
import math
def p_val(z): return 2.0 * (1.0 - 0.5*(1.0 + math.erf(abs(z)/math.sqrt(2.0))))
for z in [0.5, 1.96, 2.58, 3.5]:
    p = p_val(z)
    print(f"Z={z:4.2f} | p={p:.5f} | {'SIGNIFICANT' if p <= 0.05 else 'NOT SIGNIFICANT'}")

Z=0.50 | p=0.61708 | NOT SIGNIFICANT
Z=1.96 | p=0.05000 | SIGNIFICANT
Z=2.58 | p=0.00988 | SIGNIFICANT
Z=3.50 | p=0.00047 | SIGNIFICANT
🎯 মোবাইলে মনে রাখার সারমর্ম:
• পি-ভ্যালু নির্দেশ করে ফলাফল কাকতালীয়ভাবে ঘটার সম্ভাবনা কতটুকু।
• p ≤ 0.05 হলে নাল হাইপোথিসিস বাতিল করা হয়।
• পি-ভ্যালু যত ছোট, প্রমাণের শক্তি তত বেশি।
