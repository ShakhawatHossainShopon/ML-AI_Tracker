Hypothesis Testing (Null vs Alternative) — অনুমান যাচাই: নাল হাইপোথিসিস বনাম অল্টারনেটিভ ও এরর টাইপস

কোনো পরিবর্তন কি আসলেই কার্যকর নাকি তা নিছক কাকতালীয় ঘটনা? নাল ও অল্টারনেটিভ হাইপোথিসিস প্রণয়ন এবং টাইপ-১ ও টাইপ-২ ভুলের বৈজ্ঞানিক নিয়ন্ত্রণ।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

হাইপোথিসিস টেস্টিং: বিজ্ঞানের আদালত কক্ষ

আদালতের নিয়মে যেমন একজন ব্যক্তি 'প্রমাণ না হওয়া পর্যন্ত নির্দোষ', বিজ্ঞানের জগতেও যেকোনো নতুন দাবি প্রমাণ না হওয়া পর্যন্ত ধরে নেওয়া হয় 'কোনো নতুন প্রভাব নেই'। এই সিদ্ধান্ত গ্রহণের বৈজ্ঞানিক ফ্রেমওয়ার্কই হলো হাইপোথিসিস টেস্টিং (Hypothesis Testing)।

  • নাল হাইপোথিসিস (Null Hypothesis - H0): স্থিতাবস্থা বা কোনো পরিবর্তন না হওয়ার দাবি। যেমন: 'নতুন এআই অ্যালগরিদম পুরনো অ্যালগরিদমের চেয়ে ভালো নয়' (\( \mu_{new} = \mu_{old} \))।
  • অল্টারনেটিভ হাইপোথিসিস (Alternative Hypothesis - H1 বা Ha): গবেষকের নতুন দাবি। যেমন: 'নতুন এআই অ্যালগরিদম উল্লেখযোগ্যভাবে উন্নত' (\( \mu_{new} > \mu_{old} \))।
  • টেস্ট স্ট্যাটিস্টিক (Test Statistic - t বা z): স্যাম্পল ডেটা নাল হাইপোথিসিসের দাবি থেকে কতটা আদর্শ বিচ্যুতির দূরত্বে রয়েছে তা পরিমাপ:
    t = (x̄ - μ_0) / (s / sqrt(n))
  • সিদ্ধান্ত গ্রহণের দুই প্রকার ভুল:
    • টাইপ-১ এরর (False Positive - α): নির্দোষ ব্যক্তিকে সাজা দেওয়া (সত্যিকারের H0 কে ভুলভাবে বাতিল করা)। সাধারণত এর সহনশীল সীমা ধরা হয় \(lpha = 0.05\) (৫%)।
    • টাইপ-২ এরর (False Negative - β): আসল অপরাধীকে ছেড়ে দেওয়া (ভুল H0 কে বাতিল করতে ব্যর্থ হওয়া)।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

hypothesis_testing_lab.py 
# -------------------------------------------------------------
# Topic 13: One-Sample Student's t-Test Hypothesis Engine
# -------------------------------------------------------------

import math

def perform_one_sample_ttest(sample_data, null_mean, alpha=0.05):
    n = len(sample_data)
    mean_val = sum(sample_data) / n
    variance = sum((x - mean_val) ** 2 for x in sample_data) / (n - 1)
    std_dev = math.sqrt(variance)
    standard_error = std_dev / math.sqrt(n)
    
    # t-statistic গণনা: (x̄ - μ0) / SE
    t_stat = (mean_val - null_mean) / standard_error
    degrees_of_freedom = n - 1
    
    # df=29 এবং alpha=0.05 এর জন্য সংকটকালীন মান (Critical t-value)
    # সাধারণ স্ট্যান্ডার্ড টেবিল মান:
    critical_t = 2.045 # two-tailed at df=29
    
    reject_null = abs(t_stat) > critical_t
    
    return {
        "n": n,
        "sample_mean": mean_val,
        "null_mean": null_mean,
        "t_statistic": t_stat,
        "critical_t": critical_t,
        "reject_null": reject_null,
        "decision": "REJECT H0 (Statistically Significant!)" if reject_null else "FAIL TO REJECT H0 (Not Enough Evidence)"
    }

# বর্তমান বেসলাইন মডেলের গড় প্রতিক্রিয়া সময় ছিল 120ms
# অপটিমাইজেশনের পর ৩০টি টেস্ট রিকোয়েস্টের প্রতিক্রিয়া সময় (ms)
optimized_latencies = [
    115, 112, 118, 109, 114, 111, 116, 113, 110, 117,
    114, 112, 115, 111, 113, 116, 108, 114, 112, 115,
    113, 110, 117, 112, 114, 111, 115, 113, 109, 112
]

res = perform_one_sample_ttest(optimized_latencies, null_mean=120.0, alpha=0.05)

print("=== AI Model Speed Optimization Hypothesis Test ===")
print(f"H0 (Null)        : μ = 120.0 ms (No real speed improvement)")
print(f"H1 (Alternative) : μ < 120.0 ms (Model is genuinely faster)")
print("-" * 65)
print(f"Sample Size (n)  : {res['n']} runs | Sample Mean: {res['sample_mean']:.2f} ms")
print(f"t-Statistic      : {res['t_statistic']:.4f}")
print(f"Critical t-Value : ±{res['critical_t']:.3f} (Significance Level α = 0.05)")
print(f"Statistical Test : |{res['t_statistic']:.2f}| > {res['critical_t']:.2f} -> {res['decision']}")
print("Engineering Action: Deploy optimized model to production! Speedup is statistically proven.")
