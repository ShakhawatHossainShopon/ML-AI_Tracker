মাল্টি-ডিস্ট্রিবিউশন মডেলিং ল্যাব (Multi-Distribution Modeling Lab)

কল সেন্টার কিউ ট্রাফিক (পয়সোঁ), মার্কেটিং কনভার্সন (বাইনোমিয়াল) ও রেসপন্স টাইমের (নরমাল) তুলনামূলক সিমুলেশন।

০১ ধাপ ০১: বাইনোমিয়াল সেলস কনভার্সন

১৫ জন ক্লায়েন্টকে পিচ করলে ৩ জন কেনার সম্ভাবনা:

step1_binomial.py 
import math

def binom(n, k, p):
    return math.comb(n, k) * (p**k) * ((1-p)**(n-k))

n, p = 15, 0.20 # ২০% কনভার্সন রেট
prob_3 = binom(n, 3, p)
print(f"P(Exactly 3 buyers out of 15): {prob_3*100:.2f}%")
🖥️ Terminal Output 
P(Exactly 3 buyers out of 15): 25.01%

🔍 কোড ব্রেকডাউন:

১৫ জনের মধ্যে ঠিক ৩ জন কেনার সম্ভাবনাই সর্বোচ্চ (২৫.০১%)।

০২ ধাপ ০২: পয়সোঁ সার্ভার ট্রাফিক

মিনিটে গড়ে ৪টি রিকোয়েস্ট এলে ঠিক ৪টি বা ৬টি আসার সম্ভাবনা:

step2_poisson.py 
def poisson(lam, k):
    return (lam**k * math.exp(-lam)) / math.factorial(k)

lam = 4.0
print(f"P(4 requests/min) : {poisson(lam, 4)*100:.2f}%")
print(f"P(6 requests/min) : {poisson(lam, 6)*100:.2f}%")
print(f"P(10 requests/min): {poisson(lam, 10)*100:.2f}% (Spike Alert!)")
🖥️ Terminal Output 
P(4 requests/min) : 19.54%
P(6 requests/min) : 10.42%
P(10 requests/min): 0.53% (Spike Alert!)

🔍 কোড ব্রেকডাউন:

১০টি রিকোয়েস্ট আসার সম্ভাবনা মাত্র ০.৫৩%, যা সার্ভারে আকস্মিক লোড স্পাইক নির্দেশ করে।

০৩ ধাপ ০৩: নরমাল ডিস্ট্রিবিউশন ও Z-স্কোর

μ = 100, σ = 15 এর বেল কার্ভে ২-সিগমা সীমানা পরীক্ষা:

step3_normal.py 
mu, sigma = 100, 15
val = 135 # ২.৩৩ সিগমা দূরে
z = (val - mu) / sigma
print(f"Value: {val} | Z-Score: {z:+.2f}σ")
print(f"Is within 2-sigma (95% range)? : {abs(z) <= 2.0}")
🖥️ Terminal Output 
Value: 135 | Z-Score: +2.33σ
Is within 2-sigma (95% range)? : False

🔍 কোড ব্রেকডাউন:

মানটি ৯৫% কনফিডেন্স রেঞ্জের বাইরে চলে যাওয়ায় এটি একটি পরিষ্কার আউটলায়ার।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_distributions_lab.py 
import math
print("Binomial P(3 in 15, p=0.2):", round(math.comb(15, 3)*(0.2**3)*(0.8**12)*100, 2), "%")
print("Poisson P(4, λ=4)        :", round(((4**4)*math.exp(-4))/math.factorial(4)*100, 2), "%")

Binomial P(3 in 15, p=0.2): 25.01 %
Poisson P(4, λ=4)        : 19.54 %

• পয়সোঁ ডিস্ট্রিবিউশন সময়ের ব্যবধানে ঘটনার পুনরাবৃত্তি মডেল করে।
• নরমাল ডিস্ট্রিবিউশন বাস্তব প্রকৃতির স্বাভাবিক অবিচ্ছিন্ন মান পরিমাপ করে।
