Z-Score and Standardization — জেড-স্কোর ও স্ট্যান্ডার্ডাইজেশন: নরমাল স্কেলিং ও আউটলায়ার ডিটেকশন

ভিন্ন ভিন্ন স্কেলের ফিচারগুলোকে শূন্য গড় ও একক ভ্যারিয়েন্সে রূপান্তর (StandardScaler) এবং ৩-সিগমা বিধিতে অ্যানোমালি ও আউটলায়ার শনাক্তকরণ।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

জেড-স্কোর (Z-Score) কেন মেশিন লার্নিং ফিচার ইঞ্জিনিয়ারিংয়ের মেরুদণ্ড?

বাস্তব ডেটাসেটে বিভিন্ন ফিচারের একক ও স্কেল সম্পূর্ণ ভিন্ন থাকে। যেমন: রোগীর বয়স (১৮ থেকে ৮০ বছর) বনাম বাৎসরিক আয় (২০,০০০ থেকে ২,০০,০০০ ডলার)। সরাসরি এই কাঁচা ডেটা লিনিয়ার রিগ্রেশন, কে-মিন্স বা নিউরাল নেটওয়ার্কে দিলে মডেল বড় সংখ্যার ফিচারকে অতিরিক্ত প্রাধান্য দিয়ে পক্ষপাতদুষ্ট হয়ে পড়ে। এই সমস্যার একক সমাধান হলো জেড-স্কোর স্ট্যান্ডার্ডাইজেশন (Standardization)।

  • জেড-স্কোরের গাণিতিক সমীকরণ:
    z = (x - μ) / σ
    এখানে \(x\) হলো মূল উপাত্ত, \(\mu\) হলো গড় (Mean), এবং \(\sigma\) হলো স্ট্যান্ডার্ড ডেভিয়েশন।
  • Z-স্কোরের জ্যামিতিক তাৎপর্য:
    • \(z = 0\): উপাত্তটি ঠিক গড়ের সমান।
    • \(z > 0\) (যেমন \(+1.5\)): উপাত্তটি গড় থেকে ১.৫ একক পরিমিত ব্যবধান উপরে অবস্থিত।
    • \(z < 0\) (যেমন \(-2.0\)): উপাত্তটি গড় থেকে ২.০ একক পরিমিত ব্যবধান নিচে অবস্থিত।
  • স্ট্যান্ডার্ড নরমাল ডিস্ট্রিবিউশন \(N(0, 1)\): Z-স্কোরে রূপান্তরিত ডেটাসেটের গড় সবসময় শূন্য (\(\mu = 0\)) এবং স্ট্যান্ডার্ড ডেভিয়েশন সবসময় এক (\(\sigma = 1\)) হয়ে যায়।
  • ৩-সিগমা আউটলায়ার ফিল্টারিং রুল (Outlier Detection): স্বাভাবিক গাউসিয়ান বিন্যাসে ৯৯.৭৩% উপাত্ত \([-3.0, +3.0]\) সীমার মধ্যে অবস্থান করে। যদি কোনো ডেটা পয়েন্টের Z-স্কোর \(|z| > 3.0\) হয়, তবে তা চরম অস্বাভাবিক বা ত্রুটিপূর্ণ আউটলায়ার হিসেবে গণ্য হয়।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

z_score_standardization_engine.py 
# -------------------------------------------------------------
# Topic 17: Z-Score Standardization & 3-Sigma Anomaly Detector
# -------------------------------------------------------------

import math

def calculate_z_scores(data):
    n = len(data)
    mean_val = sum(data) / n
    variance = sum((x - mean_val) ** 2 for x in data) / n
    std_dev = math.sqrt(variance)
    
    standardized = []
    outliers = []
    
    for x in data:
        z = (x - mean_val) / std_dev
        standardized.append(z)
        if abs(z) > 3.0:
            outliers.append((x, z))
            
    return mean_val, std_dev, standardized, outliers

# ক্লাউড সার্ভার মেমরি ব্যবহার (RAM Usage in MB) - ১টি চরম মেমরি লিক অ্যানোমালি সহ
server_ram_mb = [
    2048, 2060, 2040, 2055, 2070, 2050, 2045, 2065, 2052, 2048,
    2058, 2062, 2042, 2050, 2055, 2068, 2046, 2054, 2050, 8950 # 8950 MB is anomalous!
]

mean, sd, z_scores, anomalies = calculate_z_scores(server_ram_mb)

print("=== Server RAM Telemetry Standardization Report ===")
print(f"Sample Count       : {len(server_ram_mb)} logs")
print(f"Raw Mean (μ)       : {mean:.2f} MB")
print(f"Raw Std Dev (σ)    : {sd:.2f} MB")
print("-" * 65)
print(f"{'Raw RAM (MB)':<16} {'Z-Score':<14} {'Assessment'}")
print("-" * 65)

for x, z in zip(server_ram_mb[-5:], z_scores[-5:]):
    flag = "🚨 CRITICAL OUTLIER (|z| > 3.0)" if abs(z) > 3.0 else "Normal Traffic (|z| < 3.0)"
    print(f"{x:<16} {z:<+14.3f} {flag}")

print("-" * 65)
print(f"Detected Anomalies : {len(anomalies)} point(s) -> {anomalies}")
print("Action Taken       : Automated Alert sent to DevOps! Memory Leak quarantined.")
