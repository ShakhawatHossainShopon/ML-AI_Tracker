Project Breakdown Phase 03 — Topic 04 Mobile View

এপিআই ল্যাটেন্সি p95/p99 ও IQR আউটলায়ার ফিল্টার (API Latency p95/p99 & IQR Outlier Filter)

ক্লাউড মাইক্রোসার্ভিসের রেসপন্স ল্যাটেন্সি থেকে p95, p99 বের করা এবং IQR ফর্মুলায় অস্বাভাবিক স্লো রিকোয়েস্ট অপসারণ।

০১ ধাপ ০১: ডেটা সাজানো ও পার্সেন্টাইল বের করা

সার্ভার রেসপন্স টাইম সাজিয়ে p50, p95 ও p99 নির্ধারণ:

step1_percentiles.py 
def get_percentile(sorted_list, p):
    n = len(sorted_list)
    idx = int((n - 1) * (p / 100.0))
    return sorted_list[idx]

latencies = [110, 115, 118, 120, 122, 125, 128, 130, 135, 140, 450, 950]
latencies.sort()

print("p50 (Median) :", get_percentile(latencies, 50), "ms")
print("p95 (SRE)    :", get_percentile(latencies, 95), "ms")
print("p99 (Peak)   :", get_percentile(latencies, 99), "ms")
🖥️ Terminal Output 
p50 (Median) : 125 ms
p95 (SRE)    : 450 ms
p99 (Peak)   : 450 ms

🔍 কোড ব্রেকডাউন:

পজিশনাল ইনডেক্সিং দিয়ে ৯৫% ইউজারের সর্বোচ্চ সীমা নির্ণয় করা হয়েছে।

০২ ধাপ ০২: IQR ও আউটলায়ার সীমানা

Q1 ও Q3 এর দূরত্বের ১.৫ গুণ নিয়ে বাউন্ডারি নির্ধারণ:

step2_iqr.py 
q1 = get_percentile(latencies, 25)
q3 = get_percentile(latencies, 75)
iqr = q3 - q1
lower_bound = q1 - 1.5 * iqr
upper_bound = q3 + 1.5 * iqr

print(f"Q1: {q1}ms | Q3: {q3}ms | IQR: {iqr}ms")
print(f"Valid Threshold: [{lower_bound}ms to {upper_bound}ms]")
🖥️ Terminal Output 
Q1: 118ms | Q3: 135ms | IQR: 17ms
Valid Threshold: [92.5ms to 160.5ms]

🔍 কোড ব্রেকডাউন:

১৬০.৫ মিলিসেকেন্ডের বেশি যেকোনো রিকোয়েস্টকে স্বয়ংক্রিয় আউটলায়ার গণ্য করা হবে।

০৩ ধাপ ০৩: স্বয়ংক্রিয় আউটলায়ার রিমুভাল

ডেটাসেট ফিল্টার করে পরিষ্কার উপাত্ত তৈরি করা:

step3_filter.py 
clean = [x for x in latencies if lower_bound <= x <= upper_bound]
outliers = [x for x in latencies if x < lower_bound or x > upper_bound]

print("Detected Outliers :", outliers)
print("Cleaned Dataset   :", clean)
print(f"Mean Before Clean : {sum(latencies)/len(latencies):.1f} ms")
print(f"Mean After Clean  : {sum(clean)/len(clean):.1f} ms")
🖥️ Terminal Output 
Detected Outliers : [450, 950]
Cleaned Dataset   : [110, 115, 118, 120, 122, 125, 128, 130, 135, 140]
Mean Before Clean : 245.2 ms
Mean After Clean  : 124.3 ms

🔍 কোড ব্রেকডাউন:

অস্বাভাবিক দুটি রিকোয়েস্ট বাদ দিতেই গড় ২৪৫ms থেকে স্বাভাবিক ১২৪ms এ নেমে এসেছে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_iqr_pipeline.py 
l = sorted([110, 115, 118, 120, 122, 125, 128, 130, 135, 140, 450, 950])
q1, q3 = l[int(len(l)*0.25)], l[int(len(l)*0.75)]
iqr = q3 - q1
clean = [x for x in l if q1 - 1.5*iqr <= x <= q3 + 1.5*iqr]
print(f"Cleaned {len(l) - len(clean)} outliers. Clean Mean: {sum(clean)/len(clean):.1f}ms")
🖥️ Full Terminal Run 
Cleaned 2 outliers. Clean Mean: 124.3ms
🎯 মোবাইলে মনে রাখার সারমর্ম:
• পার্সেন্টাইল অবস্থানের ভিত্তিতে উপাত্তের শতকরা মান জানায়।
• p95 ও p99 সাইট রিলায়েবিলিটি মাপার আন্তর্জাতিক মানদণ্ড।
• Q1 - 1.5*IQR ও Q3 + 1.5*IQR আউটলায়ার শনাক্তের স্বর্ণসূত্র।
