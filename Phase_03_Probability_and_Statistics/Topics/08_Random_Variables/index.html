Discrete and Continuous Random Variables — দৈব চলক: ডিসক্রিট ও কন্টিনিউয়াস ভ্যারিয়েবল এবং প্রত্যাশিত মান

বাস্তব জগতের অনিশ্চিত ঘটনাগুলোকে গাণিতিক চলকে রূপান্তর, প্রত্যাশিত মান (Expected Value) এবং ভ্যারিয়েন্স হিসাবের আর্কিটেকচার।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

র‍্যান্ডম ভ্যারিয়েবল ও প্রত্যাশিত মান (Expected Value)

সম্ভাবনার জগতে বাস্তব ফলাফলগুলো সবসময় সংখ্যায় থাকে না (যেমন: বৃষ্টি হওয়া বা না হওয়া, পাস বা ফেল)। কোনো দৈব পরীক্ষার ফলাফলকে যখন একটি বাস্তব সংখ্যায় ম্যাপ করা হয়, তখন সেই ফাংশনটিকে র‍্যান্ডম ভ্যারিয়েবল (Random Variable - X) বলে।

  • ডিসক্রিট র‍্যান্ডম ভ্যারিয়েবল (Discrete Random Variable): যে চলকের মান নির্দিষ্ট ও গণনাযোগ্য (Countable)।
    উদাহরণ: একটি ওয়েবসাইটে প্রতি মিনিটে নতুন ব্যবহারকারী আসার সংখ্যা (০, ১, ২, ৩...)। একে সংজ্ঞায়িত করা হয় প্রোবাবিলিটি মাস ফাংশন (PMF) দিয়ে: \( P(X = x) \)।
  • কন্টিনিউয়াস র‍্যান্ডম ভ্যারিয়েবল (Continuous Random Variable): যে চলক যেকোনো অবিচ্ছিন্ন বাস্তব মান গ্রহণ করতে পারে।
    উদাহরণ: সার্ভারের এক্সিকিউশন টাইম (০.২৫৪ সেকেন্ড) বা কাস্টমারের ওজন। একে সংজ্ঞায়িত করা হয় প্রোবাবিলিটি ডেনসিটি ফাংশন (PDF) দিয়ে।
  • প্রত্যাশিত মান (Expected Value - E[X] বা μ): দীর্ঘমেয়াদে কোনো প্রক্রিয়ার গড় সম্ভাব্য ফলাফল।
    E[X] = ∑ [x * P(X = x)]
    এটি গেম থিওরি ও ট্রেডিংয়ে সিদ্ধান্তের লাভজনকতা মাপার প্রধানতম মাপকাঠি।
  • র‍্যান্ডম ভ্যারিয়েবলের ভ্যারিয়েন্স: চলকটির মান তার গড় থেকে কতটা বিচ্যুত হতে পারে:
    Var(X) = E[(X - μ)^2] = E[X^2] - (E[X])^2

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

random_variable_expected_value.py 
# -------------------------------------------------------------
# Topic 08: Discrete Random Variable & Expected Value Analyzer
# -------------------------------------------------------------

def analyze_random_variable(outcomes, probabilities):
    # ভ্যালিডেশন: সকল সম্ভাবনার যোগফল অবশ্যই ১.০ হতে হবে
    total_prob = sum(probabilities)
    if abs(total_prob - 1.0) > 1e-5:
        raise ValueError("Probabilities must sum to 1.0!")
        
    # ১. প্রত্যাশিত মান E[X] = sum(x * P(x))
    expected_value = sum(x * p for x, p in zip(outcomes, probabilities))
    
    # ২. E[X^2] = sum(x^2 * P(x))
    expected_x2 = sum((x ** 2) * p for x, p in zip(outcomes, probabilities))
    
    # ৩. ভ্যারিয়েন্স ও স্ট্যান্ডার্ড ডেভিয়েশন
    variance = expected_x2 - (expected_value ** 2)
    std_dev = variance ** 0.5
    
    return expected_value, variance, std_dev

# একটি ক্লাউড এআই স্টার্টআপের ৩টি সম্ভাব্য আর্থিক দৃশ্যপট (Profit in $k)
# দৃশ্যপট ১: বড় ক্লায়েন্ট পেলে লাভ +$500k (সম্ভাবনা 20%)
# দৃশ্যপট ২: স্বাভাবিক গতিতে চললে লাভ +$80k (সম্ভাবনা 50%)
# দৃশ্যপট ৩: সার্ভার খরচ ও লোকসান -$150k (সম্ভাবনা 30%)

outcomes = [500, 80, -150]
probabilities = [0.20, 0.50, 0.30]

ev, var, sd = analyze_random_variable(outcomes, probabilities)

print("=== Cloud Startup Financial Risk Simulation ===")
for x, p in zip(outcomes, probabilities):
    print(f"Scenario Outcome: ${x:+4d}k  | Probability: {p * 100:.1f}%")
print("-" * 55)
print(f"Expected Value (E[X]) : ${ev:+.2f}k (Long-term Average Profit)")
print(f"Risk Variance (Var[X]): {var:.2f}")
print(f"Standard Deviation    : ${sd:.2f}k (Uncertainty Volatility)")
print(f"Decision Assessment   : {'PROFITABLE VENTURE (EV > 0)' if ev > 0 else 'UNPROFITABLE'}")
