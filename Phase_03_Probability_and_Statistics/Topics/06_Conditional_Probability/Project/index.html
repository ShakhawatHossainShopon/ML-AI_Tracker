Project Breakdown Phase 03 — Topic 06 Mobile View

ইউজার আচরণভিত্তিক শর্তাধীন সম্ভাবনা লিফ্ট ইঞ্জিন (User Behavior Conditional Lift Engine)

কোনো ইউজার ভিডিও টিউটোরিয়াল দেখলে তার প্রিমিয়াম সাবস্ক্রিপশন নেওয়ার সম্ভাবনা কত গুণ বৃদ্ধি পায় তার পরিমাপ।

০১ ধাপ ০১: যৌথ সম্ভাবনা টেবিল তৈরি

প্ল্যাটফর্মের ৫০,০০০ ইউজারের ভিডিও দেখা ও সাবস্ক্রিপশন ম্যাট্রিক্স:

step1_matrix.py 
total_users = 50000
watched_video = 15000
subscribed = 5000
watched_and_subscribed = 3500

p_sub = subscribed / total_users
p_vid = watched_video / total_users
p_both = watched_and_subscribed / total_users

print(f"P(Subscribed)    : {p_sub*100:.1f}%")
print(f"P(Watched Video) : {p_vid*100:.1f}%")
print(f"P(Both Events)   : {p_both*100:.1f}%")
🖥️ Terminal Output 
P(Subscribed)    : 10.0%
P(Watched Video) : 30.0%
P(Both Events)   : 7.0%

🔍 কোড ব্রেকডাউন:

মোট জনগোষ্ঠীর মাত্র ১০% মানুষ সাবস্ক্রিপশন কেনে।

০২ ধাপ ০২: শর্তাধীন সম্ভাবনা P(Sub | Video)

ভিডিও দেখা হয়েছে জানার পর সাবস্ক্রিপশনের সম্ভাবনা আপডেট:

step2_conditional.py 
p_sub_given_vid = p_both / p_vid
lift = p_sub_given_vid / p_sub

print(f"P(Subscribed | Watched Video): {p_sub_given_vid*100:.2f}%")
print(f"Conversion Lift Multiplier    : {lift:.2f}x Increase!")
🖥️ Terminal Output 
P(Subscribed | Watched Video): 23.33%
Conversion Lift Multiplier    : 2.33x Increase!

🔍 কোড ব্রেকডাউন:

ভিডিও দেখার পর কনভার্সন রেট ১০% থেকে লাফিয়ে ২৩.৩৩% (২.৩৩ গুণ বেশি) হয়ে গেছে।

০৩ ধাপ ০৩: ইন্ডিপেন্ডেন্স টেস্ট লজিক

ইভেন্ট দুটি স্বাধীন নাকি নির্ভরশীল তা প্রোগ্রামাটিক্যালি পরীক্ষা:

step3_test.py 
diff = abs(p_sub_given_vid - p_sub)
if diff > 0.01:
    print(f"Dependent Events! Difference is {diff*100:.1f}%.")
    print("Action: Show video tutorials aggressively on onboarding!")
else:
    print("Independent Events. Video has no effect.")
🖥️ Terminal Output 
Dependent Events! Difference is 13.3%.
Action: Show video tutorials aggressively on onboarding!

🔍 কোড ব্রেকডাউন:

প্রোডাক্ট ম্যানেজার এই ম্যাট্রিক্স দেখেই অনবোর্ডিং ফানেলে পরিবর্তন আনেন।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_conditional_lift.py 
total = 50000
p_sub = 5000 / total
p_vid = 15000 / total
p_both = 3500 / total
p_cond = p_both / p_vid
print(f"Base: {p_sub*100:.1f}% -> Conditional: {p_cond*100:.1f}% (Lift: {p_cond/p_sub:.2f}x)")
🖥️ Full Terminal Run 
Base: 10.0% -> Conditional: 23.3% (Lift: 2.33x)
🎯 মোবাইলে মনে রাখার সারমর্ম:
• পূর্বশর্ত সম্ভাবনাকে উল্লেখযোগ্যভাবে প্রভাবিত করে।
• P(A|B) = P(A∩B) / P(B)।
• লিফ্ট গুণক নির্ণয় করে ব্যবসায়িক সিদ্ধান্তের আরওআই (ROI) পরিমাপ করা হয়।
