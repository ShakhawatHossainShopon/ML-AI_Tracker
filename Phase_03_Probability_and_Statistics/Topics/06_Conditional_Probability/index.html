Conditional Probability & Independent Events — শর্তাধীন সম্ভাবনা: পূর্বশর্তযুক্ত ঘটনা ও ইন্ডিপেন্ডেন্স টেস্ট

পূর্ববর্তী তথ্যের আলোতে কোনো ইভেন্টের সম্ভাবনা আপডেট করা এবং দুটি ভ্যারিয়েবল পরস্পর স্বাধীন নাকি নির্ভরশীল তা নির্ধারণের ফ্রেমওয়ার্ক।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

শর্তাধীন সম্ভাবনা (Conditional Probability) কেন এআইয়ের মূল মস্তিষ্ক?

বাস্তব জীবনে ঘটনাগুলো বিচ্ছিন্নভাবে ঘটে না। আকাশে মেঘ থাকা অবস্থায় বৃষ্টি হওয়ার সম্ভাবনা এবং মেঘহীন রোদের দিনে বৃষ্টি হওয়ার সম্ভাবনা এক নয়! কোনো একটি ঘটনা \( B \) ঘটে গেছে জানার পর অপর ঘটনা \( A \) ঘটার যে সম্ভাবনা তৈরি হয়, তাকে শর্তাধীন সম্ভাবনা (Conditional Probability) বলে।

  • শর্তাধীন সম্ভাবনার সমীকরণ:
    P(A | B) = P(A ∩ B) / P(B) [যেখানে P(B) > 0]
    এখানে \( P(A | B) \) এর অর্থ হলো: 'ঘটনা B ঘটার সাপেক্ষে ঘটনা A ঘটার সম্ভাবনা'।
  • স্বাধীন ঘটনা (Independent Events): যদি একটি ঘটনা ঘটা বা না-ঘটা অপর ঘটনার সম্ভাবনাকে বিন্দুমাত্র প্রভাবিত না করে, তবে তারা স্বাধীন:
    P(A | B) = P(A) অথবা P(A ∩ B) = P(A) * P(B)
  • নির্ভরশীল ঘটনা (Dependent Events): যদি \( P(A | B) e P(A) \) হয়, তবে ভ্যারিয়েবল দুটি একটি অপরটির সাথে যুক্ত।
  • মেশিন লার্নিং ব্যবহার: রিকমেন্ডেশন সিস্টেমে 'ইউজার ইতিমধ্যে ল্যাপটপ কিনেছে' জানা থাকলে তার মাউস বা কীবোর্ড কেনার সম্ভাবনা \( P( ext{Mouse} | ext{Laptop}) \) সাধারণ যেকোনো ভিজিটরের চেয়ে বহু গুণ বেশি হয়ে যায়!

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

conditional_prob_engine.py 
# -------------------------------------------------------------
# Topic 06: Conditional Probability & Independence Tester
# -------------------------------------------------------------

# একটি ই-কমার্স প্ল্যাটফর্মের ১০০,০০০ ইউজারের ব্রাউজিং ও পারচেজ ডেটা
total_users = 100000

# ঘটনা A = প্রোডাক্ট কিনেছে (Purchased)
# ঘটনা B = রিভিউ পড়েছে (Read Reviews)
users_read_reviews = 30000
users_purchased_total = 12000
users_read_reviews_and_purchased = 9000

# ১. সাধারণ সম্ভাবনাসমূহ (Unconditional / Prior)
p_purchase = users_purchased_total / total_users
p_reviews = users_read_reviews / total_users
p_both = users_read_reviews_and_purchased / total_users

# ২. শর্তাধীন সম্ভাবনা: P(Purchase | Read Reviews)
p_purchase_given_reviews = p_both / p_reviews

# ৩. শর্তাধীন সম্ভাবনা: P(Read Reviews | Purchased)
p_reviews_given_purchase = p_both / p_purchase

# ৪. ইন্ডিপেন্ডেন্স টেস্ট
is_independent = abs(p_purchase_given_reviews - p_purchase) < 1e-4

print("=== E-Commerce Conversion Probability Analysis ===")
print(f"Overall Purchase Probability P(Purchase)        : {p_purchase * 100:.2f}%")
print(f"User Reads Reviews P(Reviews)                   : {p_reviews * 100:.2f}%")
print(f"Joint Event P(Purchase ∩ Reviews)               : {p_both * 100:.2f}%")
print("-" * 65)
print(f"Conditional: P(Purchase | Read Reviews)         : {p_purchase_given_reviews * 100:.2f}%")
print(f"Lift Multiplier                                 : {p_purchase_given_reviews / p_purchase:.2f}x Boost!")
print(f"Are Events Independent?                         : {'YES' if is_independent else 'NO (Strongly Dependent)'}")
print("Strategic Conclusion : Users who read reviews are 2.5x more likely to purchase! Optimize review UI.")

১. সাধারণ কনভার্সন (১২%): যেকোনো র্যান্ডম ভিজিটরের কেনার সম্ভাবনা মাত্র ১২%।
২. শর্তসাপেক্ষ উল্লম্ফন (৩০%): একজন ইউজার রিভিউ পড়েছে জানার পর তার কেনার সম্ভাবনা লাফিয়ে ৩০% এ উন্নীত হয় (২.৫ গুণ বেশি!)।
৩. ডিপেনডেন্সি নিশ্চিতকরণ: যেহেতু P(Purchase | Reviews) ≠ P(Purchase), তাই রিভিউ পড়া এবং কেনাকাটা করা শক্তিশালীভাবে পরস্পর নির্ভরশীল ঘটনা।
