সার্ভে পোলিং ও মার্জিন অব এরর ক্যালকুলেটর (Survey Polling & Margin of Error Calculator)

একটি অনলাইন জরিপের স্যাম্পল থেকে ৯৫% কনফিডেন্স ইন্টারভ্যাল তৈরি করে পপুলেশন পছন্দের সীমানা নির্ধারণ।

০১ ধাপ ০১: জরিপের স্যাম্পল গড় ও ভ্যারিয়েন্স

১০০ জন গ্রাহকের সন্তুষ্টি স্কোর (১ থেকে ১০ স্কেলে):

step1_sample_stats.py 
import math

scores = [8, 9, 7, 8, 9, 10, 6, 8, 7, 9, 8, 8, 7, 9, 8, 10, 7, 8, 9, 8] * 5
n = len(scores)
mean_score = sum(scores) / n
sd = math.sqrt(sum((x - mean_score)**2 for x in scores) / (n - 1))

print(f"Sample Size (n)   : {n}")
print(f"Sample Mean (x̄)   : {mean_score:.2f}")
print(f"Sample StdDev (s) : {sd:.2f}")
🖥️ Terminal Output 
Sample Size (n)   : 100
Sample Mean (x̄)   : 8.10
Sample StdDev (s) : 0.94

🔍 কোড ব্রেকডাউন:

১০০ জন গ্রাহকের গড় স্কোর ৮.১০ এবং স্ট্যান্ডার্ড ডেভিয়েশন ০.৯৪ পাওয়া গেছে।

০২ ধাপ ০২: মার্জিন অব এরর (MoE) গণনা

৯৫% আস্থার জন্য z* = 1.96 দিয়ে ত্রুটির বিস্তৃতি নির্ণয়:

step2_moe.py 
se = sd / math.sqrt(n)
z_star = 1.96 # 95% Confidence
moe = z_star * se

print(f"Standard Error (SE): {se:.4f}")
print(f"Margin of Error    : ±{moe:.4f}")
🖥️ Terminal Output 
Standard Error (SE): 0.0943
Margin of Error    : ±0.1849

🔍 কোড ব্রেকডাউন:

মার্জিন অব এরর মাত্র ±০.১৮ হওয়ায় অনুমানের নিশ্চয়তা অত্যন্ত উচ্চ।

০৩ ধাপ ০৩: চূড়ান্ত আস্থার ইন্টারভ্যাল প্রকাশ

বোর্ড মিটিংয়ের জন্য চূড়ান্ত ৯৫% কনফিডেন্স ইন্টারভ্যাল রিপোর্ট:

step3_report.py 
lower_ci = mean_score - moe
upper_ci = mean_score + moe

print(f"95% Confidence Interval: [{lower_ci:.2f} to {upper_ci:.2f}]")
print(f"Executive Statement: We are 95% confident that the true customer satisfaction lies between {lower_ci:.2f} and {upper_ci:.2f}.")
🖥️ Terminal Output 
95% Confidence Interval: [7.92 to 8.28]
Executive Statement: We are 95% confident that the true customer satisfaction lies between 7.92 and 8.28.

🔍 কোড ব্রেকডাউন:

পয়েন্ট অনুমানের চেয়ে রেঞ্জ প্রকাশ বৈজ্ঞানিকভাবে অনেক বেশি শক্তিশালী ও নির্ভরযোগ্য।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_ci_calculator.py 
import math
scores = [8, 9, 7, 8, 9, 10, 6, 8, 7, 9, 8, 8, 7, 9, 8, 10, 7, 8, 9, 8] * 5
m = sum(scores) / len(scores)
moe = 1.96 * (math.sqrt(sum((x-m)**2 for x in scores)/99) / 10)
print(f"95% CI: [{m-moe:.2f} to {m+moe:.2f}] (MoE: ±{moe:.2f})")
🖥️ Full Terminal Run 
95% CI: [7.92 to 8.28] (MoE: ±0.18)
🎯 মোবাইলে মনে রাখার সারমর্ম:
• পয়েন্ট এস্টিমেশনের চেয়ে কনফিডেন্স ইন্টারভ্যাল বেশি বাস্তবসম্মত।
• ৯৫% আস্থার জন্য z* = ১.৯৬ স্ট্যান্ডার্ড মান।
• স্যাম্পল আকার n বাড়ালে মার্জিন অব এরর দ্রুত সংকুচিত হয়।
