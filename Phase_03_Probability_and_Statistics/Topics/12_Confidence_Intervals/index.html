Confidence Intervals & Margin of Error — আস্থার ব্যবধান: জনসংখ্যার গড় অনুমানে কনফিডেন্স ইন্টারভ্যাল ও মার্জিন অব এরর

একটিমাত্র পয়েন্ট অনুমানের চেয়ে রেঞ্জ বা সীমানা অনুমান কেন বহুগুণ বেশি বৈজ্ঞানিক। ৯৫% ও ৯৯% কনফিডেন্স ইন্টারভ্যাল তৈরির বাস্তব পাইথন ইঞ্জিন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

পয়েন্ট এস্টিমেশন বনাম ইন্টারভ্যাল এস্টিমেশন

যদি বলা হয় 'আমাদের নতুন এআই মডেলের এক্যুরেসি ৮৮%', এটি একটি পয়েন্ট এস্টিমেট (Point Estimate)। কিন্তু নতুন বাস্তব ডেটায় এটি ৮২% থেকে ৯৪% এর মধ্যে যেকোনো কিছু হতে পারে! বিজ্ঞানে কোনো একক সংখ্যা দিয়ে অনুমান না করে একটি আস্থার সীমা বা কনফিডেন্স ইন্টারভ্যাল (Confidence Interval - CI) প্রকাশ করা হয়।

  • কনফিডেন্স ইন্টারভ্যাল কী?: এমন একটি সীমানা \([Lower, Upper]\) যা দাবি করে—আমরা যদি ১০০ বার আলাদা আলাদা স্যাম্পল নিয়ে এই ইন্টারভ্যাল তৈরি করি, তবে তার ৯৫টিতেই আসল পপুলেশন প্যারামিটার অন্তর্ভুক্ত থাকবে।
  • ৯৫% কনফিডেন্স ইন্টারভ্যাল সমীকরণ:
    CI = x̄ ± Margin of Error = x̄ ± (z* * (s / sqrt(n)))
    যেখানে ৯৫% আস্থার জন্য সংকটকালীন মান \(z^* = 1.96\), এবং ৯৯% আস্থার জন্য \(z^* = 2.576\)।
  • মার্জিন অব এরর (Margin of Error - MoE): আমাদের অনুমানের সর্বোচ্চ সম্ভাব্য ত্রুটি বা অনিশ্চয়তার বিস্তৃতি।
    MoE = z* * (s / sqrt(n))
  • স্যাম্পল সাইজ ও ইন্টারভ্যাল উইডথ: স্যাম্পল সাইজ \(n\) যত বড় হয়, ইন্টারভ্যালের চওড়া তত ছোট ও সূক্ষ্ম হয়। অর্থাৎ যত বেশি ডেটা সংগ্রহ করা যাবে, আমাদের এআই প্রেডিকশনের নিশ্চয়তা তত বাড়বে!

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

confidence_interval_calculator.py 
# -------------------------------------------------------------
# Topic 12: 95% and 99% Confidence Interval Calculator
# -------------------------------------------------------------

import math

def compute_confidence_interval(data, confidence_level=0.95):
    n = len(data)
    mean_val = sum(data) / n
    variance = sum((x - mean_val) ** 2 for x in data) / (n - 1)
    std_dev = math.sqrt(variance)
    standard_error = std_dev / math.sqrt(n)
    
    # সাধারণ গুরুত্বপূর্ণ z* মান
    z_scores = {
        0.90: 1.645,
        0.95: 1.960,
        0.99: 2.576
    }
    z_star = z_scores.get(confidence_level, 1.960)
    
    margin_of_error = z_star * standard_error
    lower_bound = mean_val - margin_of_error
    upper_bound = mean_val + margin_of_error
    
    return mean_val, margin_of_error, (lower_bound, upper_bound), standard_error

sample_tokens_per_sec = [
    42.1, 45.3, 39.8, 44.0, 46.5, 41.2, 43.8, 47.1, 40.5, 42.9,
    44.6, 43.1, 41.9, 45.8, 46.0, 42.4, 43.7, 44.2, 41.5, 45.0,
    43.3, 42.8, 44.9, 46.2, 40.1, 43.5, 45.1, 42.0, 44.7, 43.9,
    41.8, 45.5, 42.6, 44.1, 43.4, 46.8, 41.0, 43.6, 44.8, 42.3,
    45.7, 43.0, 42.5, 44.4, 41.7, 46.1, 43.2, 42.7, 45.2, 43.8
]

mean, moe95, (low95, high95), se = compute_confidence_interval(sample_tokens_per_sec, 0.95)
_, moe99, (low99, high99), _ = compute_confidence_interval(sample_tokens_per_sec, 0.99)

print("=== LLM Throughput Confidence Interval Report ===")
print(f"Sample Size (n)       : {len(sample_tokens_per_sec)} benchmark runs")
print(f"Sample Mean (x̄)       : {mean:.2f} tokens/sec")
print(f"Standard Error (SE)   : {se:.3f}")
print("-" * 60)
print(f"95% Confidence Level  : [{low95:.2f} to {high95:.2f}] tokens/sec  (MoE: ±{moe95:.2f})")
print(f"99% Confidence Level  : [{low99:.2f} to {high99:.2f}] tokens/sec  (MoE: ±{moe99:.2f})")
