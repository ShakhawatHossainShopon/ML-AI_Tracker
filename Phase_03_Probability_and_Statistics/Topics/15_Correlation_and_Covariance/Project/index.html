Project Breakdown Phase 03 — Topic 15 Mobile View

মার্কেটিং বাজেট বনাম আয় পিয়ারসন ম্যাট্রিক্স (Marketing Ad Spend vs Revenue Pearson Matrix)

বিজ্ঞাপন খরচ ও বিক্রয় আয়ের কোভ্যারিয়েন্স এবং পিয়ারসন কোরিলেশন সহগ (r) হিসাব করে ফিচার সিলেকশন।

০১ ধাপ ০১: কোভ্যারিয়েন্স গণনা

উভয় চলকের কেন্দ্র থেকে বিচ্যুতির যৌথ গুণফলের গড়:

step1_cov.py 
ads = [10, 20, 30, 40, 50]
rev = [22, 41, 62, 79, 102]
n = len(ads)

m_ads = sum(ads) / n
m_rev = sum(rev) / n

cov = sum((x - m_ads)*(y - m_rev) for x, y in zip(ads, rev)) / (n - 1)
print(f"Mean Ads: ${m_ads}k | Mean Rev: ${m_rev}k")
print(f"Sample Covariance: {cov:.2f}")
🖥️ Terminal Output 
Mean Ads: $30.0k | Mean Rev: $61.2k
Sample Covariance: 497.50

🔍 কোড ব্রেকডাউন:

কোভ্যারিয়েন্স ধনাত্মক ৪৯৭.৫০ হওয়ায় বোঝা যাচ্ছে একটি বাড়লে অন্যটিও বাড়ে।

০২ ধাপ ০২: পিয়ারসন কোরিলেশন (r) নরমালাইজেশন

কোভ্যারিয়েন্সকে উভয়ের স্ট্যান্ডার্ড ডেভিয়েশন দিয়ে ভাগ করে স্কেল-মুক্ত মান (-১ থেকে +১):

step2_pearson_r.py 
import math

sd_ads = math.sqrt(sum((x - m_ads)**2 for x in ads) / (n - 1))
sd_rev = math.sqrt(sum((y - m_rev)**2 for y in rev) / (n - 1))

r = cov / (sd_ads * sd_rev)
print(f"StdDev Ads: {sd_ads:.2f} | StdDev Rev: {sd_rev:.2f}")
print(f"Pearson Correlation (r): {r:+.4f}")
🖥️ Terminal Output 
StdDev Ads: 15.81 | StdDev Rev: 31.50
Pearson Correlation (r): +0.9990

🔍 কোড ব্রেকডাউন:

r = +0.9990 প্রায় নিখুঁত ১.০ এর সমান, যা প্রচণ্ড শক্তিশালী লিনিয়ার সম্পর্ক নির্দেশ করে।

০৩ ধাপ ০৩: ফিচার সিলেকশন সিদ্ধান্ত

কোরিলেশন থ্রেশহোল্ডের ওপর ভিত্তি করে এমএল ফিচার রাখা বা বাতিল করা:

step3_feature_filter.py 
if abs(r) > 0.70:
    action = "KEEP FEATURE (Strong Linear Predictor for ML Model)"
elif abs(r) > 0.30:
    action = "MODERATE (Consider Non-linear interactions)"
else:
    action = "DROP FEATURE (Weak / Irrelevant)"

print("Feature Assessment:", action)
🖥️ Terminal Output 
Feature Assessment: KEEP FEATURE (Strong Linear Predictor for ML Model)

🔍 কোড ব্রেকডাউন:

উচ্চ কোরিলেশন থাকায় বিজ্ঞাপন খরচ লিনিয়ার রিগ্রেশন মডেলে শীর্ষ ফিচার হিসেবে নির্বাচিত হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_pearson_calc.py 
import math
x, y = [10, 20, 30, 40, 50], [22, 41, 62, 79, 102]
mx, my = sum(x)/5, sum(y)/5
cov = sum((a-mx)*(b-my) for a,b in zip(x,y))/4
r = cov / (math.sqrt(sum((a-mx)**2 for a in x)/4) * math.sqrt(sum((b-my)**2 for b in y)/4))
print(f"Covariance: {cov:.2f} | Pearson r: {r:+.4f}")
🖥️ Full Terminal Run 
Covariance: 497.50 | Pearson r: +0.9990
🎯 মোবাইলে মনে রাখার সারমর্ম:
• কোভ্যারিয়েন্স সম্পর্কের দিক নির্দেশ করে কিন্তু স্কেলের ওপর নির্ভরশীল।
• পিয়ারসন r মান সবসময় -১ থেকে +১ এর মধ্যে সীমাবদ্ধ থাকে।
• কোরিলেশন মানেই কার্যকারণ (Causation) নয়।
