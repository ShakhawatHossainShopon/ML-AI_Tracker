Correlation and Covariance — সহভেদাঙ্ক ও সহসম্পর্ক: ভ্যারিয়েবলের পারস্পরিক সম্পর্কের শক্তি ও দিক

বিজ্ঞানের সবচেয়ে বিখ্যাত সতর্কবার্তা: 'কোরিলেশন মানেই কার্যকারণ (Causation) নয়'। পিয়ারসন কোরিলেশন কোএফিশিয়েন্ট ও ফিচার সিলেকশন ইঞ্জিন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

সহভেদাঙ্ক (Covariance) বনাম সহসম্পর্ক (Correlation)

মেশিন লার্নিং ফিচার ইঞ্জিনিয়ারিংয়ের মূল রহস্য হলো—কোন ফিচারগুলো টার্গেট ভ্যারিয়েবলের সাথে গভীরভাবে সম্পর্কিত তা খুঁজে বের করা। এই সম্পর্কের দিক ও তীব্রতা পরিমাপ করে কোভ্যারিয়েন্স ও কোরিলেশন।

  • সহভেদাঙ্ক (Covariance - Cov(X, Y)): দুটি চলক একসাথে কীভাবে পরিবর্তিত হয় তার পরিমাপ।
    Cov(X, Y) = [∑ (x_i - mean_x) * (y_i - mean_y)] / (n - 1)
    দুর্বলতা: কোভ্যারিয়েন্সের মান স্কেল বা এককের ওপর নির্ভরশীল (ডলার বা সেন্টে হিসাব করলে মান হাজার গুণ বদলে যায়), তাই দুটি ভিন্ন ফিচারের সম্পর্ক তুলনা করা কঠিন।
  • পিয়ারসন সহসম্পর্ক সহগ (Pearson Correlation Coefficient - r): কোভ্যারিয়েন্সকে উভয়ের স্ট্যান্ডার্ড ডেভিয়েশন দিয়ে ভাগ করে স্কেল-মুক্ত (Standardized) রূপ দেওয়া:
    r = Cov(X, Y) / (s_x * s_y)
    যেখানে এর মান সবসময় \(-1.0 \le r \le +1.0\) এর মধ্যে সীমাবদ্ধ থাকে:
    • \(r = +1.0\): নিখুঁত ধনাত্মক লিনিয়ার সম্পর্ক (একটি বাড়লে অন্যটিও অবধারিতভাবে বাড়ে)।
    • \(r = -1.0\): নিখুঁত ঋণাত্মক লিনিয়ার সম্পর্ক (একটি বাড়লে অন্যটি নিশ্চিতভাবে কমে)।
    • \(r = 0.0\): কোনো লিনিয়ার সম্পর্ক নেই।
  • 'Correlation Does NOT Imply Causation': উদাহরণস্বরূপ, গ্রীষ্মকালে আইসক্রিম বিক্রি বাড়লে সমুদ্রে ডুবে মৃত্যুর সংখ্যাও বাড়ে। তাদের মধ্যে উচ্চ কোরিলেশন (\(r > 0.8\)) আছে, কিন্তু আইসক্রিম খাওয়ার কারণে কেউ ডুবে মরে না! আসল কারণ হলো গ্রীষ্মের প্রচণ্ড গরম (Confounding Variable)।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

correlation_covariance_engine.py 
# -------------------------------------------------------------
# Topic 15: Covariance & Pearson Correlation Matrix Engine
# -------------------------------------------------------------

import math

def calculate_covariance_and_correlation(x, y):
    n = len(x)
    mean_x = sum(x) / n
    mean_y = sum(y) / n
    
    # কোভ্যারিয়েন্স ক্যালকুলেশন
    cov = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y)) / (n - 1)
    
    # স্ট্যান্ডার্ড ডেভিয়েশন
    var_x = sum((xi - mean_x) ** 2 for xi in x) / (n - 1)
    var_y = sum((yi - mean_y) ** 2 for yi in y) / (n - 1)
    std_x = math.sqrt(var_x)
    std_y = math.sqrt(var_y)
    
    # পিয়ারসন r
    r = cov / (std_x * std_y)
    return cov, r

# একটি ই-কমার্স স্টোরের ডেটা: বিজ্ঞাপন খরচ (হাজার $) বনাম বিক্রি (হাজার $)
ad_spend = [10.0, 15.0, 20.0, 25.0, 30.0, 35.0, 40.0, 50.0]
revenue  = [25.0, 32.0, 41.0, 50.0, 58.0, 69.0, 78.0, 95.0]

# তৃতীয় ভ্যারিয়েবল: সার্ভার পিং রেট (ms) যার সাথে বিক্রির কোনো বাস্তব সম্পর্ক নেই
ping_ms  = [120, 115, 125, 118, 122, 119, 121, 117]

cov_ad_rev, r_ad_rev = calculate_covariance_and_correlation(ad_spend, revenue)
cov_ping_rev, r_ping_rev = calculate_covariance_and_correlation(ping_ms, revenue)

print("=== Feature Correlation & Relationship Analysis ===")
print(f"Ad Spend vs Revenue      -> Cov: {cov_ad_rev:8.2f} | Pearson r: {r_ad_rev:+.4f} (Very Strong Positive)")
print(f"Server Ping vs Revenue   -> Cov: {cov_ping_rev:8.2f} | Pearson r: {r_ping_rev:+.4f} (No Meaningful Linear Relation)")
print("-" * 65)
print(f"Feature Selection Choice : Keep 'Ad Spend' (r = {r_ad_rev:.2f}), Drop 'Server Ping' from linear model!")
print("Causality Notice         : High r proves a linear relationship, but domain expertise is required to confirm causation.")
