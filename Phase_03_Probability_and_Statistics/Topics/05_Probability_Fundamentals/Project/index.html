মন্টি কার্লো প্রবাবিলিটি সিমুলেটর (Monte Carlo Probability Simulator)

কম্পিউটারে লক্ষাধিক দৈব পরীক্ষা চালিয়ে গাণিতিক সম্ভাবনার যোগ সূত্র ও পূরক সূত্রের বাস্তব প্রমাণ।

০১ ধাপ ০১: একক ঘটনার সম্ভাবনা গণনা

একটি ছক্কায় জোড় সংখ্যা ওঠার অনুকূল ফলাফলের অনুপাত:

step1_single_event.py 
sample_space = {1, 2, 3, 4, 5, 6}
even_event = {2, 4, 6}
p_even = len(even_event) / len(sample_space)
print(f"Sample Space Size: {len(sample_space)}")
print(f"P(Even Number)   : {p_even:.4f}")
🖥️ Terminal Output 
Sample Space Size: 6
P(Even Number)   : 0.5000

🔍 কোড ব্রেকডাউন:

অনুকূল সংখ্যা ৩ এবং মোট ৬ হওয়ায় তাত্ত্বিক মান ঠিক ০.৫।

০২ ধাপ ০২: মন্টি কার্লো সিমুলেশন রান

১০০,০০০ বার ছক্কা নিক্ষেপ করে বাস্তব পরীক্ষামূলক সম্ভাবনা পরিমাপ:

step2_simulation.py 
import random
trials = 100000
count_even = sum(1 for _ in range(trials) if random.randint(1, 6) % 2 == 0)
sim_prob = count_even / trials
print(f"Simulated Probability: {sim_prob:.4f}")
print(f"Difference from Math : {abs(sim_prob - 0.5):.5f}")
🖥️ Terminal Output 
Simulated Probability: 0.5008
Difference from Math : 0.00080

🔍 কোড ব্রেকডাউন:

ল অব লার্জ নাম্বার্স অনুযায়ী ট্রায়াল বাড়ালে পরীক্ষামূলক মান তাত্ত্বিক মানের সমান হয়ে যায়।

০৩ ধাপ ০৩: যোগ বিধি (Union Rule) যাচাই

P(A ∪ B) = P(A) + P(B) - P(A ∩ B) এর বাস্তব পরীক্ষা:

step3_union.py 
# Event A: জোড় সংখ্যা (2, 4, 6)
# Event B: চার বা তার বেশি (4, 5, 6)
a = {2, 4, 6}
b = {4, 5, 6}
s = {1, 2, 3, 4, 5, 6}

p_a = len(a) / len(s)
p_b = len(b) / len(s)
p_inter = len(a & b) / len(s)
p_union = p_a + p_b - p_inter

print(f"P(A): {p_a:.3f} | P(B): {p_b:.3f} | P(A∩B): {p_inter:.3f}")
print(f"P(A ∪ B) Formula: {p_union:.3f} (Exact Set: {len(a | b)/len(s):.3f})")
🖥️ Terminal Output 
P(A): 0.500 | P(B): 0.500 | P(A∩B): 0.333
P(A ∪ B) Formula: 0.667 (Exact Set: 0.667)

🔍 কোড ব্রেকডাউন:

সেট অপারেশন ও গাণিতিক যোগ বিধির ফলাফল হুবহু চার-ষষ্ঠাংশ (০.৬৬৭) মিলেছে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_monte_carlo.py 
import random
n = 100000
rolls = [random.randint(1, 6) for _ in range(n)]
p_even = sum(1 for r in rolls if r % 2 == 0) / n
print(f"Monte Carlo Simulated P(Even) across {n:,} rolls: {p_even:.4f}")
🖥️ Full Terminal Run 
Monte Carlo Simulated P(Even) across 100,000 rolls: 0.4998
🎯 মোবাইলে মনে রাখার সারমর্ম:
• সম্ভাবনার মান সবসময় ০ থেকে ১ এর মধ্যে থাকে।
• ট্রায়াল সংখ্যা যত বড় হয়, সিমুলেশন তত বেশি নিখুঁত সত্যে পৌঁছায়।
• যোগ করার সময় যৌথ সম্ভাবনা বাদ দিয়ে ডাবল কাউন্টিং এড়াতে হয়।
