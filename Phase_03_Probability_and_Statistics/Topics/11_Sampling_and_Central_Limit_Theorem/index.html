Sampling Techniques & Central Limit Theorem (CLT) — নমুনায়ন ও সেন্ট্রাল লিমিট থিওরেম: যেকোনো বিন্যাস থেকে নরমাল গড়ের রূপান্তর

পরিসংখ্যানের সবচেয়ে অলৌকিক ও শক্তিশালী উপপাদ্য। মূল পপুলেশন যত অস্বাভাবিক বা স্কিউড হোক না কেন, পর্যাপ্ত নমুনার গড় সবসময় নরমাল ডিস্ট্রিবিউশনে পরিণত হয়।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

সেন্ট্রাল লিমিট থিওরেম (CLT): স্ট্যাটিস্টিক্যাল ইনফ্যারেন্সের ভিত্তিপ্রস্তর

বাস্তব জীবনে পুরো দেশের ১৮ কোটি মানুষের বা গুগলের কোটি কোটি ব্যবহারকারীর প্রত্যেকের ডেটা নেওয়া অসম্ভব। আমাদের স্যাম্পলিং (Sampling) এর ওপর নির্ভর করতে হয়। কিন্তু স্যাম্পল কি পুরো পপুলেশনের সঠিক প্রতিনিধিত্ব করতে পারে? এই প্রশ্নের সমাধান দেয় সেন্ট্রাল লিমিট থিওরেম (CLT)।

  • CLT উপপাদ্য: মূল পপুলেশন যে ডিস্ট্রিবিউশনই মেনে চলুক না কেন (ইউনিফর্ম, এক্সপোনেনশিয়াল, চরম স্কিউড বা বাইমোডাল), যদি সেখান থেকে পর্যাপ্ত বড় আকারের (\(n \ge 30\)) র‍্যান্ডম স্যাম্পল বারবার নেওয়া হয়, তবে স্যাম্পল গড়গুলোর ডিস্ট্রিবিউশন (Sampling Distribution of the Mean) সবসময় একটি স্বাভাবিক বা নরমাল ডিস্ট্রিবিউশন তৈরি করবে!
  • স্যাম্পলিং গড়ের বৈশিষ্ট্য:
    • স্যাম্পল গড়গুলোর গড় মূল পপুলেশন গড়ের সমান হবে: \( \mu_{ar{x}} = \mu \)।
    • স্যাম্পলিং ডিস্ট্রিবিউশনের স্ট্যান্ডার্ড ডেভিয়েশন বা স্ট্যান্ডার্ড এরর (Standard Error - SE):
      SE = σ / sqrt(n)
      অর্থাৎ স্যাম্পলের আকার \(n\) যত বড় হবে, অনুমানের অনিশ্চয়তা বা এরর তত দ্রুত সংকুচিত হবে!
  • মেশিন লার্নিং ব্যবহার: ক্রস-ভ্যালিডেশন, বুটস্ট্র্যাপিং (Random Forest / Bagging) এবং ডিপ লার্নিংয়ের মিনি-ব্যাচ গ্রেডিয়েন্ট ডিসেন্ট সবই CLT এর গাণিতিক নিশ্চয়তার ওপর নির্ভরশীল।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

central_limit_theorem_sim.py 
# -------------------------------------------------------------
# Topic 11: Monte Carlo Simulation of Central Limit Theorem
# -------------------------------------------------------------

import random
import math

def simulate_clt(population, sample_size=40, num_samples=10000):
    sample_means = []
    for _ in range(num_samples):
        # র‍্যান্ডম স্যাম্পলিং
        sample = random.choices(population, k=sample_size)
        sample_mean = sum(sample) / sample_size
        sample_means.append(sample_mean)
        
    pop_mean = sum(population) / len(population)
    pop_var = sum((x - pop_mean) ** 2 for x in population) / len(population)
    pop_sd = math.sqrt(pop_var)
    
    means_mean = sum(sample_means) / num_samples
    means_var = sum((x - means_mean) ** 2 for x in sample_means) / num_samples
    means_sd = math.sqrt(means_var)
    theoretical_se = pop_sd / math.sqrt(sample_size)
    
    return pop_mean, pop_sd, means_mean, means_sd, theoretical_se

# একটি চরম অসম/স্কিউড পপুলেশন: ৮০% মানুষ ১ পায়, ২০% মানুষ ৫০ পায় (চরম নন-নরমাল!)
population = [1.0] * 8000 + [50.0] * 2000

pop_mean, pop_sd, sim_mean, sim_se, theory_se = simulate_clt(population, sample_size=50, num_samples=10000)

print("=== Central Limit Theorem (CLT) Monte Carlo Validation ===")
print(f"True Population Mean (μ)         : {pop_mean:.4f}")
print(f"True Population Std Dev (σ)      : {pop_sd:.4f} (Heavy Skewed)")
print("-" * 65)
print(f"Sample Size (n)                  : 50 (Repeated 10,000 times)")
print(f"Mean of Sample Means (μ_x̄)       : {sim_mean:.4f} (Matches μ!)")
print(f"Empirical Standard Error (SE)    : {sim_se:.4f}")
print(f"Theoretical Standard Error (σ/√n): {theory_se:.4f}")
print(f"Prediction Accuracy              : {100.0 - abs(sim_se - theory_se)/theory_se*100:.2f}% Match!")
print("CLT Magic : A severely non-normal dataset generated a perfect Gaussian distribution of means!")
