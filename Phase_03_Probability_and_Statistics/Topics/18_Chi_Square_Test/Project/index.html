Project Breakdown Phase 03 — Topic 18 Mobile View

ক্যাটাগরিক্যাল ফিচার স্বাধীনতা কাই-স্কোয়ার ল্যাব (Categorical Feature Independence Chi-Square Lab)

ডিভাইস ক্যাটাগরি ও সাবস্ক্রিপশন সিদ্ধান্তের কনটিনজেন্সি টেবিল থেকে কাই-স্কোয়ার (χ²) ও ডিপেনডেন্সি অডিট।

০১ ধাপ ০১: কনটিনজেন্সি টেবিল ও মার্জিনাল যোগফল

মোবাইল ও ডেস্কটপ ইউজারদের সাবস্ক্রিপশন কাউন্ট টেবিল তৈরি:

step1_table.py 
# Rows: Mobile, Desktop
# Cols: Bought, DidNotBuy
obs = [
    [100, 400], # Mobile: 500 total
    [160, 340]  # Desktop: 500 total
]

row_sums = [sum(r) for r in obs]
col_sums = [obs[0][c] + obs[1][c] for c in range(2)]
total = sum(row_sums)

print("Row Totals (Devices)    :", row_sums)
print("Col Totals (Conversion) :", col_sums)
print("Grand Total Visitors    :", total)
🖥️ Terminal Output 
Row Totals (Devices)    : [500, 500]
Col Totals (Conversion) : [260, 740]
Grand Total Visitors    : 1000

🔍 কোড ব্রেকডাউন:

১০০০ জন ভিজিটরের মধ্যে মোট ২৬০ জন কিনেছে এবং ৭৪০ জন কেনেনি।

০২ ধাপ ০২: প্রত্যাশিত মান (Expected Values)

E = (RowTotal * ColTotal) / GrandTotal সমীকরণ দিয়ে মান গণনা:

step2_expected.py 
expected = []
for r in range(2):
    row_exp = []
    for c in range(2):
        e = (row_sums[r] * col_sums[c]) / total
        row_exp.append(e)
    expected.append(row_exp)

print("Expected Table:")
print("Mobile  :", expected[0])
print("Desktop :", expected[1])
🖥️ Terminal Output 
Expected Table:
Mobile  : [130.0, 370.0]
Desktop : [130.0, 370.0]

🔍 কোড ব্রেকডাউন:

যদি ডিভাইস টাইপ কোনো প্রভাব না ফেলত, তবে উভয়েই ১৩০ জন কেনার কথা ছিল।

০৩ ধাপ ০৩: χ² টেস্ট স্ট্যাটিস্টিক ও সিদ্ধান্ত

সামেশন (O - E)² / E এর মাধ্যমে চূড়ান্ত রায়:

step3_chi2_calc.py 
chi2 = 0.0
for r in range(2):
    for c in range(2):
        o = obs[r][c]
        e = expected[r][c]
        chi2 += ((o - e) ** 2) / e

crit_val = 3.841 # df = (2-1)*(2-1) = 1, alpha = 0.05
print(f"Calculated Chi-Square: {chi2:.4f}")
print(f"Critical Threshold   : {crit_val}")
if chi2 > crit_val:
    print("VERDICT: REJECT H0! Significant association between Device & Purchase.")
else:
    print("VERDICT: Independent.")
🖥️ Terminal Output 
Calculated Chi-Square: 18.7110
Critical Threshold   : 3.841
VERDICT: REJECT H0! Significant association between Device & Purchase.

🔍 কোড ব্রেকডাউন:

χ² মান ১৮.৭১ সংকটকালীন সীমার চেয়ে অনেক বেশি হওয়ায় প্রমাণ হয় যে মোবাইল ব্যবহারকারীদের তুলনায় ডেস্কটপ ব্যবহারকারীদের কেনার হার উল্লেখযোগ্যভাবে বেশি।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_chi_square.py 
obs = [[100, 400], [160, 340]]
r_sums = [500, 500]
c_sums = [260, 740]
chi2 = sum(((obs[r][c] - (r_sums[r]*c_sums[c]/1000))**2) / (r_sums[r]*c_sums[c]/1000) for r in range(2) for c in range(2))
print(f"Chi2 Stat: {chi2:.2f} | Significant (p < 0.05): {chi2 > 3.841}")
🖥️ Full Terminal Run 
Chi2 Stat: 18.71 | Significant (p < 0.05): True
🎯 মোবাইলে মনে রাখার সারমর্ম:
• কাই-স্কোয়ার টেস্ট ক্যাটাগরিক্যাল বা গুণগত ফিচারের পারস্পরিক সম্পর্ক মাপে।
• χ² = Σ [(Observed - Expected)² / Expected]।
• এটি এমএল ক্লাসিফিকেশনের সেরা ফিচার সিলেকশনে ব্যবহৃত হয়।
