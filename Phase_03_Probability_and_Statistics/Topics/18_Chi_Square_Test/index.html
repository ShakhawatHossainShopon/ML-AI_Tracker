Chi-Square Test (Goodness of Fit & Independence) — কাই-স্কোয়ার টেস্ট: ক্যাটাগরিক্যাল স্বাধীনতা ও গুডনেস অব ফিট পরীক্ষা

গুণগত বা ক্যাটাগরিকাল ডেটায় দুটি বৈশিষ্ট্যের মধ্যে সম্পর্ক রয়েছে নাকি তারা পরস্পর স্বাধীন—কনটিনজেন্সি টেবিল ও কাই-স্কোয়ার (χ²) বিশ্লেষণ।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

কাই-স্কোয়ার (Chi-Square) টেস্ট কেন ডেটা সায়েন্সে অপরিহার্য?

সংখ্যাসূচক (Continuous) ডেটায় আমরা t-টেস্ট বা ANOVA ব্যবহার করি, কিন্তু ক্যাটাগরিক্যাল ডেটার ক্ষেত্রে (যেমন: গ্রাহকের ডিভাইস টাইপ বনাম কেনাকাটার সিদ্ধান্ত) কীভাবে বুঝব যে তাদের মধ্যে কোনো তাৎপর্যপূর্ণ সম্পর্ক আছে নাকি এটি নিছক কাকতালীয়? এর উত্তর দেয় কাই-স্কোয়ার টেস্ট (\(\chi^2\) Test)।

  • কাই-স্কোয়ার টেস্টের প্রধান দুই প্রকার:
    1. গুডনেস অব ফিট (Goodness of Fit Test): সংগৃহীত স্যাম্পল ডেটা কোনো তাত্ত্বিক প্রত্যাশিত বিন্যাস মেনে চলে কিনা তা পরীক্ষা করা।
    2. টেস্ট অব ইন্ডিপেন্ডেন্স (Test of Independence): দুটি ক্যাটাগরিক্যাল চলক (Variables) একে অপরের ওপর নির্ভরশীল নাকি সম্পূর্ণ স্বাধীন তা যাচাই করা।
  • কাই-স্কোয়ার সমীকরণ:
    χ^2 = ∑ [ (O - E)^2 / E ]
    যেখানে \(O\) হলো Observed Frequency (বাস্তব পর্যবেক্ষণ) এবং \(E\) হলো Expected Frequency (প্রত্যাশিত ফ্রিকোয়েন্সি)।
  • প্রত্যাশিত মান নির্ণয় (Contingency Table):
    E = (Row Total * Column Total) / Grand Total
  • ডিগ্রি অব ফ্রিডম (Degrees of Freedom):
    df = (Rows - 1) * (Columns - 1)
  • সিদ্ধান্ত গ্রহণ: যদি পর্যবেক্ষিত ও প্রত্যাশিত মানের পার্থক্য খুব বড় হয়, তবে \(\chi^2\) এর মান বৃদ্ধি পায়। \(\chi^2\) মান সংকটকালীন সীমার চেয়ে বড় হলে এবং \(p \le 0.05\) হলে নাল হাইপোথিসিস বাতিল করে প্রমাণ হয় যে চলক দুটি পরস্পর নির্ভরশীল!

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

chi_square_independence_test.py 
# -------------------------------------------------------------
# Topic 18: Chi-Square Test of Independence from Scratch
# -------------------------------------------------------------

import math

def run_chi_square_independence(observed_matrix):
    """
    observed_matrix: 2D লিস্ট [সারি][কলাম]
    """
    n_rows = len(observed_matrix)
    n_cols = len(observed_matrix[0])
    
    row_totals = [sum(row) for row in observed_matrix]
    col_totals = [sum(observed_matrix[r][c] for r in range(n_rows)) for c in range(n_cols)]
    grand_total = sum(row_totals)
    
    chi2_stat = 0.0
    expected_matrix = []
    
    for r in range(n_rows):
        exp_row = []
        for c in range(n_cols):
            exp_val = (row_totals[r] * col_totals[c]) / grand_total
            exp_row.append(exp_val)
            obs_val = observed_matrix[r][c]
            chi2_stat += ((obs_val - exp_val) ** 2) / exp_val
        expected_matrix.append(exp_row)
        
    df = (n_rows - 1) * (n_cols - 1)
    
    # df=1 এবং alpha=0.05 এর জন্য ক্রিটিক্যাল মান = 3.841
    # df=2 হলে 5.991
    critical_value = 3.841 if df == 1 else 5.991
    is_significant = chi2_stat > critical_value
    
    return chi2_stat, df, critical_value, is_significant, expected_matrix

# একটি ই-কমার্স কনটিনজেন্সি টেবিল:
# ডিভাইস টাইপ (Mobile vs Desktop) বনাম সাবস্ক্রিপশন (Purchased vs Did Not Purchase)
#             Purchased    Did Not Buy
# Mobile:       120            380        (Total 500)
# Desktop:      180            320        (Total 500)
observed = [
    [120, 380], # Mobile
    [180, 320]  # Desktop
]

chi2, df, crit, sig, expected = run_chi_square_independence(observed)

print("=== Chi-Square Test of Independence (Device vs Conversion) ===")
print("Observed Frequencies  : Mobile [120, 380] | Desktop [180, 320]")
print(f"Expected Frequencies  : Mobile [{expected[0][0]:.1f}, {expected[0][1]:.1f}] | Desktop [{expected[1][0]:.1f}, {expected[1][1]:.1f}]")
print("-" * 65)
print(f"Degrees of Freedom (df): {df} (1 row factor x 1 col factor)")
print(f"Chi-Square Stat (χ²)   : {chi2:.4f}")
print(f"Critical Value (α=0.05): {crit:.3f}")
print(f"Statistical Decision   : {'REJECT H0 (Dependent Relationship!)' if sig else 'FAIL TO REJECT H0 (Independent)'}")
print("-" * 65)
print("Product Conclusion    : Purchase behavior depends significantly on device! Desktop has higher conversion.")

৩. কাই-স্কোয়ার স্ট্যাট (১৭.১৪): টেস্ট স্ট্যাটিস্টিক ১৭.১৪ সংকটকালীন সীমা ৩.৮৪১ এর চেয়ে অনেক বড়! ফলে H0 সম্পূর্ণ বাতিল হয়ে প্রমাণিত হয়েছে যে ডিভাইস টাইপ রূপান্তরের সাথে গভীরভাবে জড়িত।
