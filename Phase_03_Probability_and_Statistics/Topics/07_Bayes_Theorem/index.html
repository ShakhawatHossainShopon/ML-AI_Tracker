Bayes' Theorem & Prior-to-Posterior Updating — বেইজ থিওরেম: নতুন প্রমাণের ভিত্তিতে বিশ্বাসের আপডেট ও প্রায়র-পোস্টেরিয়র

মেডিকেল টেস্ট পজিটিভ হলেই কি আপনি ১০০% আক্রান্ত? বেইজ থিওরেমের মাধ্যমে পূর্ব বিশ্বাস (Prior) কে নতুন প্রমাণের (Evidence) ভিত্তিতে পোস্টেরিয়রে রূপান্তর।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

বেইজ থিওরেমের জাদুকরী দর্শন ও স্প্যাম ফিল্টারিং

বেইজ থিওরেম (Bayes' Theorem) হলো এআই এবং যুক্তিশাস্ত্রের একক সবচেয়ে প্রভাবশালী সমীকরণ। এটি আমাদের শেখায় কীভাবে নতুন কোনো প্রমাণ (Evidence) পাওয়ার পর আমাদের পূর্ববর্তী ধারণাকে (Prior Belief) আপডেট করে নতুন সত্য (Posterior Probability) খুঁজে পেতে হয়।

  • বেইজ থিওরেমের সমীকরণ:
    P(A | B) = [P(B | A) * P(A)] / P(B)
  • চারটি স্তম্ভের সংজ্ঞা:
    • P(A) - প্রায়র (Prior Probability): নতুন কোনো প্রমাণ দেখার আগে ঘটনা A ঘটার প্রাথমিক সম্ভাবনা।
    • P(B | A) - লাইকলিহুড (Likelihood): ঘটনা A সত্য হলে প্রমাণ B দেখার সম্ভাবনা কতটুকু।
    • P(B) - মার্জিনাল এভিডেন্স (Evidence): যেকোনো অবস্থাতেই প্রমাণ B ঘটার মোট সম্ভাবনা: \( P(B) = P(B|A)P(A) + P(B| eg A)P( eg A) \)।
    • P(A | B) - পোস্টেরিয়র (Posterior Probability): প্রমাণ B পাওয়ার পর ঘটনা A সত্য হওয়ার আপডেটেড চূড়ান্ত সম্ভাবনা!
  • মেডিকেল প্যারাডক্স (Medical Screening Paradox): কোনো বিরল রোগের টেস্ট ৯৯% নির্ভুল হলেও টেস্ট পজিটিভ এলে রোগীর রোগ থাকার আসল সম্ভাবনা অনেক সময় ১০% এরও কম হতে পারে! কারণ রোগটি সমাজে অত্যন্ত বিরল (Low Prior)।
  • স্প্যাম ক্লাসিফায়ার (Naive Bayes): ইমেইলে 'Free Lottery Winner' শব্দগুলো দেখা দিলে ইমেইলটি স্প্যাম হওয়ার পোস্টেরিয়র সম্ভাবনা হিসাব করা।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

bayes_medical_diagnostic.py 
# -------------------------------------------------------------
# Topic 07: Bayes' Theorem Rare Disease Diagnostic Engine
# -------------------------------------------------------------

def calculate_bayes_posterior(prior_disease, sensitivity, false_positive_rate):
    """
    prior_disease: P(D) = সমাজে রোগটি থাকার হার
    sensitivity: P(Positive | D) = রোগী আক্রান্ত হলে টেস্ট পজিটিভ আসার সম্ভাবনা
    false_positive_rate: P(Positive | Healthy) = সুস্থ মানুষের ক্ষেত্রে ভুল টেস্ট পজিটিভ
    """
    prior_healthy = 1.0 - prior_disease
    
    # মোট পজিটিভ আসার সম্ভাবনা P(Positive) = P(Pos|D)*P(D) + P(Pos|H)*P(H)
    p_evidence = (sensitivity * prior_disease) + (false_positive_rate * prior_healthy)
    
    # বেইজ ফর্মুলা: P(D | Positive) = [P(Positive | D) * P(D)] / P(Evidence)
    posterior_disease = (sensitivity * prior_disease) / p_evidence
    
    return posterior_disease, p_evidence

# একটি বিরল রোগ সমাজে প্রতি ১০০০ জনে ১ জনের হয় (০.১%)
prior = 0.001
# টেস্ট ৯৯% নিখুঁত (রোগ থাকলে ৯৯% পজিটিভ দেখাবে)
sensitivity = 0.99
# সুস্থ ব্যক্তির ক্ষেত্রে টেস্ট ৫% মিথ্যা পজিটিভ (False Alarm) দেয়
false_alarm = 0.05

posterior, total_pos_rate = calculate_bayes_posterior(prior, sensitivity, false_alarm)

print("=== Bayes' Theorem Medical Diagnostic Paradox ===")
print(f"Base Disease Rate (Prior)            : {prior * 100:.2f}% (Rare: 1 in 1000)")
print(f"Test Accuracy / Sensitivity           : {sensitivity * 100:.2f}%")
print(f"False Positive Rate                   : {false_alarm * 100:.2f}%")
print("-" * 65)
print(f"Total Population Testing Positive     : {total_pos_rate * 100:.2f}%")
print(f"Actual Chance of Disease If Positive  : {posterior * 100:.2f}%  <-- (বিস্ময়কর পোস্টেরিয়র!)")
print(f"Healthy Despite Positive Test        : {(1.0 - posterior) * 100:.2f}%")
print("Logical Insight : Because the disease is so rare, 98% of positive tests are actually False Alarms!")
