Project Breakdown Phase 03 — Topic 01 Mobile View

ই-কমার্স ট্রানজ্যাকশন ডেটা প্রোফাইলার (E-Commerce Transaction Profiler)

কাঁচা লেনদেন ডেটাসেট থেকে গড়, মধ্যক, বিস্তার ও রেঞ্জ গণনার মাধ্যমে ক্লায়েন্ট খরচ প্যাটার্ন প্রোফাইলিং।

০১ ধাপ ০১: কাঁচা লেনদেন ডেটা ও গড় (Mean) নির্ণয়

১০ জন ক্রেতার অর্ডারের মান (USD) নিয়ে তাদের স্বাভাবিক গড় খরচ হিসাব করা:

step1_mean.py 
orders = [45.0, 120.0, 85.0, 310.0, 60.0, 110.0, 95.0, 750.0, 40.0, 105.0]
n = len(orders)
mean_order = sum(orders) / n
print(f"Total Orders: {n}")
print(f"Mean Order Value: ${mean_order:.2f}")
🖥️ Terminal Output 
Total Orders: 10
Mean Order Value: $172.00

🔍 কোড ব্রেকডাউন:

sum(orders) / n: সামগ্রিক যোগফল ১৭২০ কে ১০ দিয়ে ভাগ করে গড় ১৭২ ডলার পাওয়া গেছে।

০২ ধাপ ০২: সাজানো ডেটা থেকে মধ্যক (Median) নির্ধারণ

আউটলায়ারের প্রভাব মুক্ত হতে উপাত্ত সাজিয়ে মাঝখানের বিন্দু বের করা:

step2_median.py 
sorted_orders = sorted(orders)
mid = n // 2
median_order = (sorted_orders[mid - 1] + sorted_orders[mid]) / 2.0
print("Sorted Orders:", sorted_orders)
print(f"Median Order Value: ${median_order:.2f}")
🖥️ Terminal Output 
Sorted Orders: [40.0, 45.0, 60.0, 85.0, 95.0, 105.0, 110.0, 120.0, 310.0, 750.0]
Median Order Value: $100.00

🔍 কোড ব্রেকডাউন:

Median = $100.00: ৯৫ ও ১০৫ এর গড় ১০০ ডলার। অর্ধেকের বেশি ক্রেতা ১০০ ডলারের নিচে খরচ করেছেন, অথচ গড় দেখাচ্ছিল ১৭২ ডলার!

০৩ ধাপ ০৩: বিস্তৃতি ও স্ট্যান্ডার্ড ডেভিয়েশন

ক্রেতাদের খরচের ব্যবধান ও অস্থিরতা পরিমাপ করা:

step3_spread.py 
variance = sum((x - mean_order)**2 for x in orders) / (n - 1)
std_dev = variance ** 0.5
price_range = max(orders) - min(orders)
print(f"Variance: {variance:.2f}")
print(f"Std Dev : ${std_dev:.2f}")
print(f"Range   : ${price_range:.2f}")
🖥️ Terminal Output 
Variance: 48906.67
Std Dev : $221.15
Range   : $710.00

🔍 কোড ব্রেকডাউন:

Std Dev ($221.15): গড়ের চেয়েও বেশি স্ট্যান্ডার্ড ডেভিয়েশন প্রমাণ করে ক্রেতাদের ব্যয়ের মধ্যে চরম বৈষম্য রয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_profiler.py 
orders = [45.0, 120.0, 85.0, 310.0, 60.0, 110.0, 95.0, 750.0, 40.0, 105.0]
n = len(orders)
mean_v = sum(orders) / n
s_orders = sorted(orders)
med_v = (s_orders[n//2 - 1] + s_orders[n//2]) / 2.0
sd_v = (sum((x - mean_v)**2 for x in orders) / (n - 1)) ** 0.5

print(f"Mean: ${mean_v:.1f} | Median: ${med_v:.1f} | StdDev: ${sd_v:.1f}")
🖥️ Full Terminal Run 
Mean: $172.0 | Median: $100.0 | StdDev: $221.1
🎯 মোবাইলে মনে রাখার সারমর্ম:
• বর্ণনামূলক পরিসংখ্যান কাঁচা ডেটাকে দ্রুত বোঝার উপযোগী সামারিতে রূপান্তর করে।
• আউটলায়ার থাকলে গড় বিকৃত হয়, কিন্তু মধ্যক বিশ্বস্ত থাকে।
• স্ট্যান্ডার্ড ডেভিয়েশন ডেটার ভেতরকার অস্থিরতা নির্দেশ করে।
