End-to-End A/B Testing in Data Science — এ/বি টেস্টিং: বাস্তব প্রোডাক্ট এক্সপেরিমেন্টেশন, কনভার্সন রেট ও সিগনিফিকেন্স

গুগল, মেটা ও অ্যামাজনের সকল প্রোডাক্ট সিদ্ধান্তের নেপথ্য শক্তি। কন্ট্রোল বনাম ভ্যারিয়েন্ট গ্রুপের লাইভ ট্রাফিকের কনভার্সন রেট ও ২-প্রোপোরশন জেড-টেস্ট।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

এ/বি টেস্টিং: বৈজ্ঞানিক প্রোডাক্ট অপটিমাইজেশনের চূড়ান্ত হাতিয়ার

এ/বি টেস্টিং (A/B Testing) হলো র‍্যান্ডমাইজড নিয়ন্ত্রিত পরীক্ষার (Randomized Controlled Trial) আধুনিক ডিজিটাল রূপ। এটি নির্ধারণ করে ব্যবহারকারীদের কাছে দুটি ভ্যারিয়েন্টের মধ্যে কোনটি বেশি কার্যকর।

  • কন্ট্রোল বনাম ভ্যারিয়েন্ট গ্রুপ:
    • গ্রুপ A (Control): বর্তমান বিদ্যমান ডিজাইন বা অ্যালগরিদম।
    • গ্রুপ B (Variant / Treatment): নতুন পরিবর্তিত ফিচার বা অ্যালগরিদম।
    লাইভ ইউজার ট্রাফিককে র‍্যান্ডমভাবে ৫০/৫০ অনুপাতে বিভক্ত করে এই দুই গ্রুপে পাঠানো হয় যেন কোনো সিলেকশন বায়াস না থাকে।
  • মূল মেট্রিক (Primary Metric): ক্লিক-থ্রু রেট (CTR), সাইন-আপ কনভার্সন বা কেনাকাটার হার (\(p_A\) এবং \(p_B\))।
  • ২-স্যাম্পল প্রোপোরশন জেড-টেস্ট (Two-Proportion Z-Test):
    Pooled Proportion (p_pool) = (x_A + x_B) / (n_A + n_B)
    Standard Error (SE) = sqrt[ p_pool * (1 - p_pool) * (1/n_A + 1/n_B) ]
    Z = (p_B - p_A) / SE
  • ব্যবসায়িক সিদ্ধান্ত: যদি \(p \le 0.05\) হয় এবং কনভার্সন বৃদ্ধি (Uplift) ধনাত্মক হয়, তবে কোম্পানি পুরো ১০০% ট্রাফিকের জন্য গ্রুপ B রোল-আউট করার গ্রিন সিগন্যাল দেয়!

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

ab_testing_production_pipeline.py 
# -------------------------------------------------------------
# Topic 16: Full End-to-End A/B Testing Experiment Engine
# -------------------------------------------------------------

import math

def normal_cdf(z):
    return 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))

def run_ab_test(visitors_a, conversions_a, visitors_b, conversions_b, alpha=0.05):
    # ১. কনভার্সন রেট
    p_a = conversions_a / visitors_a
    p_b = conversions_b / visitors_b
    uplift = (p_b - p_a) / p_a * 100.0
    
    # ২. পুলড প্রোপোরশন ও স্ট্যান্ডার্ড এরর
    p_pool = (conversions_a + conversions_b) / (visitors_a + visitors_b)
    se_pool = math.sqrt(p_pool * (1.0 - p_pool) * (1.0 / visitors_a + 1.0 / visitors_b))
    
    # ৩. জেড-টেস্ট স্ট্যাটিস্টিক ও পি-ভ্যালু
    z_score = (p_b - p_a) / se_pool
    tail_prob = 1.0 - normal_cdf(abs(z_score))
    p_value = 2.0 * tail_prob
    
    # ৪. পরিসংখ্যানিক সিদ্ধান্ত
    is_significant = p_value <= alpha
    
    return {
        "p_a": p_a,
        "p_b": p_b,
        "uplift": uplift,
        "z_score": z_score,
        "p_value": p_value,
        "is_significant": is_significant,
        "recommendation": "DEPLOY VARIANT B (Statistically Significant Lift!)" if is_significant and uplift > 0 else "KEEP CONTROL A (No Significant Difference)"
    }

# একটি SaaS ল্যান্ডিং পেজের কল-টু-অ্যাকশন (CTA) বাটন টেস্ট
# গ্রুপ A (নীল বাটন): ১২,৫০০ ভিজিটরের মধ্যে ৮৫০ জন সাবস্ক্রাইব করেছে
# গ্রুপ B (সবুজ বাটন): ১২,৫০০ ভিজিটরের মধ্যে ৯৯৫ জন সাবস্ক্রাইব করেছে

results = run_ab_test(visitors_a=12500, conversions_a=850, 
                      visitors_b=12500, conversions_b=995, alpha=0.05)

print("=== Landing Page A/B Testing Statistical Report ===")
print(f"Control (A) Conversion Rate   : {results['p_a'] * 100:.2f}% (850 / 12,500)")
print(f"Variant (B) Conversion Rate   : {results['p_b'] * 100:.2f}% (995 / 12,500)")
print(f"Relative Conversion Uplift    : +{results['uplift']:.2f}% Increase!")
print("-" * 65)
print(f"Z-Score                       : {results['z_score']:+.4f}")
print(f"P-Value                       : {results['p_value']:.5f} (Threshold α = 0.05)")
print(f"Statistical Significance      : {'CONFIRMED (p < 0.05)' if results['is_significant'] else 'NOT CONFIRMED'}")
print(f"Executive Decision            : {results['recommendation']}")
