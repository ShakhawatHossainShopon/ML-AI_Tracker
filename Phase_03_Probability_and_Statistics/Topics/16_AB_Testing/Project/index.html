Project Breakdown Phase 03 — Topic 16 Mobile View

লাইভ ল্যান্ডিং পেজ এ/বি কনভার্সন অপটিমাইজার (Live Landing Page A/B Conversion Engine)

১০,০০০ ইউজারের ওপর নতুন সাইন-আপ বাটনের এ/বি টেস্ট রান, পুলড প্রোপোরশন জেড-টেস্ট ও রোলআউট সিদ্ধান্ত।

০১ ধাপ ০১: ট্রাফিক ও কনভার্সন মেট্রিক্স

কন্ট্রোল (গ্রুপ A) বনাম ভ্যারিয়েন্ট (গ্রুপ B) এর কনভার্সন রেট:

step1_rates.py 
n_a, conv_a = 10000, 720
n_b, conv_b = 10000, 850

p_a = conv_a / n_a
p_b = conv_b / n_b
uplift = (p_b - p_a) / p_a * 100

print(f"Control (A) Rate : {p_a*100:.2f}% ({conv_a}/{n_a})")
print(f"Variant (B) Rate : {p_b*100:.2f}% ({conv_b}/{n_b})")
print(f"Relative Uplift  : +{uplift:.2f}%")
🖥️ Terminal Output 
Control (A) Rate : 7.20% (720/10000)
Variant (B) Rate : 8.50% (850/10000)
Relative Uplift  : +18.06%

🔍 কোড ব্রেকডাউন:

গ্রুপ B তে কনভার্সন রেট ১৮.০৬% বেশি দেখা গেছে।

০২ ধাপ ০২: পুলড Z-টেস্ট ও স্ট্যান্ডার্ড এরর

উভয় স্যাম্পলের যৌথ স্ট্যান্ডার্ড এরর হিসাব করে Z-স্কোর বের করা:

step2_z_test.py 
import math

p_pool = (conv_a + conv_b) / (n_a + n_b)
se_pool = math.sqrt(p_pool * (1.0 - p_pool) * (1.0/n_a + 1.0/n_b))
z_score = (p_b - p_a) / se_pool

print(f"Pooled Proportion: {p_pool:.4f}")
print(f"Pooled SE        : {se_pool:.5f}")
print(f"Z-Score          : {z_score:+.4f}")
🖥️ Terminal Output 
Pooled Proportion: 0.0785
Pooled SE        : 0.00380
Z-Score          : +3.4187

🔍 কোড ব্রেকডাউন:

Z-স্কোর +৩.৪২ এসেছে, যা ১.৯৬ এর চেয়ে অনেক বেশি।

০৩ ধাপ ০৩: পি-ভ্যালু ও চূড়ান্ত রোলআউট

p < 0.05 নিশ্চিত করে পুরো ট্রাফিকের জন্য সাইট আপডেট:

step3_rollout.py 
tail = 1.0 - 0.5 * (1.0 + math.erf(abs(z_score) / math.sqrt(2.0)))
p_val = 2.0 * tail

print(f"P-Value : {p_val:.6f} (Threshold: 0.05)")
if p_val <= 0.05:
    print("WINNER  : Variant B (Statistically Proven Lift!)")
    print("ACTION  : 100% Traffic Rollout Authorized by Data Team!")
else:
    print("RESULT  : Inconclusive. Keep Control A.")
🖥️ Terminal Output 
P-Value : 0.000629 (Threshold: 0.05)
WINNER  : Variant B (Statistically Proven Lift!)
ACTION  : 100% Traffic Rollout Authorized by Data Team!

🔍 কোড ব্রেকডাউন:

পি-ভ্যালু ০.০০৬% হওয়ায় এটি কোনোভাবেই দৈব দুর্ঘটনা নয়। পুরো সাইটে ভ্যারিয়েন্ট B চালুর নির্দেশ দেওয়া হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

full_ab_tester.py 
import math
p1, p2 = 720/10000, 850/10000
pool = (720 + 850) / 20000
se = math.sqrt(pool * (1-pool) * (2/10000))
z = (p2 - p1) / se
p_v = 2.0 * (1.0 - 0.5 * (1.0 + math.erf(z/math.sqrt(2))))
print(f"Uplift: +{(p2-p1)/p1*100:.1f}% | Z: {z:.2f} | p-val: {p_v:.5f} -> Deploy Variant B!")
🖥️ Full Terminal Run 
Uplift: +18.1% | Z: 3.42 | p-val: 0.00063 -> Deploy Variant B!

• পুলড প্রোপোরশন ও Z-টেস্ট কনভার্সন পার্থক্যের তাৎপর্য নির্ণয় করে।
• p < 0.05 পেলেই কেবল ১০০% ট্রাফিক রোলআউটের সবুজ সংকেত দেওয়া হয়।
