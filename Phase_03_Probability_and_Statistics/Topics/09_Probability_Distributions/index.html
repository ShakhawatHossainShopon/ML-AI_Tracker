Phase 03: Topic 09 Mobile View

Probability Distributions (PMF, PDF, CDF) — সম্ভাব্যতা বিন্যাস: PMF, PDF ও CDF এর গাণিতিক আর্কিটেকচার

কোনো প্রক্রিয়ার সকল সম্ভাব্য ফলাফলের সামগ্রিক মানচিত্র। ডিসক্রিট ও কন্টিনিউয়াস ডেটায় প্রোবাবিলিটি ডেনসিটি ও ক্রমযোজিত সম্ভাবনা (CDF) মডেলিং।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

সম্ভাব্যতা বিন্যাস: ডেটার আচরণ বোঝার মূল গাণিতিক লেন্স

বাস্তব জগতের ডেটা কীভাবে বিন্যস্ত থাকে তা বুঝতে হলে সম্ভাব্যতা বিন্যাস (Probability Distribution) জানা আবশ্যক। এটি মূলত একটি গাণিতিক ফাংশন যা র‍্যান্ডম ভ্যারিয়েবলের প্রতিটি মানের ঘটার সম্ভাবনা নির্ধারণ করে।

  • PMF (Probability Mass Function): ডিসক্রিট চলকের ক্ষেত্রে সুনির্দিষ্ট একটি বিন্দু \(x\) ঘটার সঠিক সম্ভাবনা: \( P(X = x) \)।
    শর্ত: সকল সম্ভাবনার যোগফল \( \sum P(X = x) = 1.0 \)।
  • PDF (Probability Density Function): কন্টিনিউয়াস চলকের ক্ষেত্রে একক বিন্দুর সম্ভাবনা শূন্য, তাই এটি একটি নির্দিষ্ট ব্যবধানে সম্ভাবনার ঘনত্ব নির্দেশ করে:
    P(a ≤ X ≤ b) = ∫ [a to b] f(x) dx
  • CDF (Cumulative Distribution Function): চলকটির মান কোনো নির্দিষ্ট সংখ্যা \(x\) এর চেয়ে কম বা সমান হওয়ার ক্রমযোজিত সম্ভাবনা:
    F(x) = P(X ≤ x)
    CDF সবসময় ০ থেকে শুরু হয়ে মনোটোনিক্যালি ১-এ গিয়ে পৌঁছায়।
  • মেশিন লার্নিং ব্যবহার: জেনারেটিভ এআই (যেমন VAE, GAN ও Diffusion Models) ডেটার এই সুপ্ত প্রোবাবিলিটি ডিস্ট্রিবিউশনটিকেই শিখতে চেষ্টা করে যেন নতুন বাস্তবসম্মত ডেটা জেনারেট করা যায়।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

distributions_pmf_cdf.py 
# -------------------------------------------------------------
# Topic 09: Empirical PMF and CDF Distribution Builder
# -------------------------------------------------------------

def build_empirical_distribution(data):
    """প্রদত্ত ডেটাসেট থেকে ডিসক্রিট PMF এবং CDF ক্যালকুলেশন"""
    n = len(data)
    from collections import Counter
    counts = Counter(data)
    unique_sorted = sorted(counts.keys())
    
    pmf = {}
    cdf = {}
    cumulative = 0.0
    
    for val in unique_sorted:
        prob = counts[val] / n
        pmf[val] = prob
        cumulative += prob
        cdf[val] = cumulative
        
    return unique_sorted, pmf, cdf

# একটি মোবাইল অ্যাপে ইউজারের দৈনিক লগইন সংখ্যা (Login Frequency)
user_logins = [1, 2, 1, 3, 2, 1, 4, 2, 1, 2, 3, 5, 1, 2, 1, 2, 3, 1, 2, 4]

values, pmf, cdf = build_empirical_distribution(user_logins)

print(f"{'Logins (x)':<12} {'PMF P(X=x)':<14} {'CDF P(X<=x)':<14} {'Visual Histogram'}")
print("-" * 55)

for val in values:
    p = pmf[val]
    c = cdf[val]
    bar = "█" * int(p * 30)
    print(f"{val:<12} {p:<14.4f} {c:<14.4f} {bar}")

print("-" * 55)
print(f"Prob(Logins <= 2) : {cdf[2] * 100:.1f}% (CDF gives cumulative threshold)")
print(f"Prob(Logins > 3)  : {(1.0 - cdf[3]) * 100:.1f}% (Survival / Exceedance probability)")

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

১. PMF মানচিত্র: ৩৫% ইউজার দিনে ১ বার এবং ৩৫% ইউজার ২ বার লগইন করেন। মোট ৭০% ইউজার হালকা ব্রাউজার।
২. CDF ক্রমযোজন: CDF প্রতিটি ধাপে সম্ভাবনা পুঞ্জীভূত করে ঠিক ১.০ তে গিয়ে পৌঁছেছে। ফলে P(X <= 3) = 0.85 দেখে আমরা এক দেখাতেই ৮৫% ইউজারের সীমা পেয়ে যাচ্ছি।
৩. থ্রেশহোল্ডিং ও পার্সেন্টাইল: CDF এর বিপরীত ফাংশন (Quantile Function) ব্যবহার করেই এআই অ্যানোমালি ও বট ইউজার শনাক্ত করে।
