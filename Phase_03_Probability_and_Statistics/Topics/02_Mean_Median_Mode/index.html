Measures of Central Tendency (Mean, Median, Mode) — কেন্দ্রীয় প্রবণতার পরিমাপ: গড়, মধ্যক ও প্রচুরকের ব্যবহারিক দর্শন

বাস্তব ডেটায় আউটলায়ারের উপস্থিতিতে গড় কেন বিভ্রান্তিকর হতে পারে এবং ক্যাটাগরিকাল ও নিউমেরিক্যাল ডেটায় মধ্যক ও প্রচুরকের সঠিক নির্বাচন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

গড়, মধ্যক ও প্রচুরক: এআই মডেলে কোনটি কখন ব্যবহার করবেন?

কেন্দ্রীয় প্রবণতা (Central Tendency) ডেটাসেটের এমন একটি সংখ্যাসূচক মান যা সমগ্র ডেটার বৈশিষ্ট্যকে একটিমাত্র প্রতিনিধিস্বরূপ বিন্দুতে প্রকাশ করে।

  • গড় (Arithmetic Mean): সকল উপাত্তের যোগফলকে মোট সংখ্যা দিয়ে ভাগ। এটি ডেটার প্রতিটি বিন্দুর ওপর সংবেদনশীল।
    Mean = (∑ x_i) / N
    দুর্বলতা: চরম অস্বাভাবিক মান বা আউটলায়ার (Outliers) গড়ের মানকে মারাত্মকভাবে বিকৃত করে ফেলে।
  • মধ্যক (Median): উপাত্তগুলোকে ছোট থেকে বড় ক্রমে সাজালে ঠিক মাঝখানের মান।
    শক্তি: আউটলায়ারের বিপরীতে অত্যন্ত শক্তিশালী (Robust)। যেমন বিল গেটস কোনো সাধারণ চায়ের দোকানে প্রবেশ করলে উপস্থিত সকলের গড় আয় কোটি টাকা হয়ে যাবে, কিন্তু মধ্যক আয় প্রায় অপরিবর্তিত থাকবে!
  • প্রচুরক (Mode): ডেটাসেটে যে মানটি সবচেয়ে বেশিবার পুনরাবৃত্ত হয়েছে। ক্যাটাগরিক্যাল ডেটা (যেমন: সবচেয়ে বিক্রিত জুতার সাইজ বা গাড়ির মডেল) বিশ্লেষণে প্রচুরকই একমাত্র সঠিক পরিমাপ।
  • মেশিন লার্নিং ইমপিউটেশন (Missing Value Imputation): মিসিং ডেটা পূরণে সিমেট্রিক ডেটায় গড়, স্কিউড বা আউটলায়ারযুক্ত ডেটায় মধ্যক এবং ক্যাটাগরিক্যাল ডেটায় প্রচুরক ব্যবহার করা হয়।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

central_tendency_lab.py 
# -------------------------------------------------------------
# Topic 02: Central Tendency & Outlier Robustness Simulator
# -------------------------------------------------------------

from collections import Counter

def calculate_mean(values):
    return sum(values) / len(values)

def calculate_median(values):
    s = sorted(values)
    n = len(s)
    mid = n // 2
    return s[mid] if n % 2 != 0 else (s[mid - 1] + s[mid]) / 2.0

def calculate_mode(values):
    counts = Counter(values)
    max_freq = max(counts.values())
    modes = [val for val, freq in counts.items() if freq == max_freq]
    return modes

# একটি সফটওয়্যার কোম্পানির কর্মীদের মাসিক বেতন (হাজার টাকায়)
regular_salaries = [40, 45, 50, 48, 52, 45, 42, 55, 45, 58]

# একজন সিইও যোগ দিলেন যার বেতন ৫০০ হাজার টাকা (আউটলায়ার!)
skewed_salaries = regular_salaries + [500]

print("=== Regular Salaries (10 Engineers) ===")
print(f"Mean Salary   : {calculate_mean(regular_salaries):.2f}k BDT")
print(f"Median Salary : {calculate_median(regular_salaries):.2f}k BDT")
print(f"Mode Salary   : {calculate_mode(regular_salaries)}k BDT (Most common)")

print("
=== After CEO Joined (Extreme Outlier: 500k) ===")
print(f"New Mean      : {calculate_mean(skewed_salaries):.2f}k BDT  <-- (বিশাল বিভ্রান্তিকর উল্লম্ফন!)")
print(f"New Median    : {calculate_median(skewed_salaries):.2f}k BDT  <-- (অত্যন্ত স্থিতিশীল ও বাস্তবসম্মত)")
print(f"Mean Shifted By: +{calculate_mean(skewed_salaries) - calculate_mean(regular_salaries):.2f}k BDT")
print(f"Median Shifted : +{calculate_median(skewed_salaries) - calculate_median(regular_salaries):.2f}k BDT")
