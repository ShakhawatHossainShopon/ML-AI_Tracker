Indexing, Slicing & Boolean Masking — ইনডেক্সিং, স্লাইসিং ও বুলিয়ান মাস্কিং

বহুমাত্রিক অ্যারে থেকে সুনির্দিষ্ট সাবসেট এক্সট্র্যাক্ট করা। [start:stop:step], কন্ডিশনাল বুলিয়ান ফিল্টারিং এবং ফ্যান্সি ইনডেক্সিংয়ের মাধ্যমে লাইটনিং-ফাস্ট ডেটা স্লাইসিং।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

১D ও ২D স্লাইসিং এবং বুলিয়ান মাস্কিং মেকানিক্স

NumPy অ্যারে থেকে ডেটা নির্বাচন ও ফিল্টারিং পাইথন লুপের চেয়ে শতগুণ দ্রুতগতিতে কাজ করে।

  • বেসিক স্লাইসিং: arr[start:stop:step]
    ২D ম্যাট্রিক্সে: arr[row_slice, col_slice]
    যেমন: arr[:, 0] মানে সকল সারির প্রথম কলাম।
  • বুলিয়ান মাস্কিং (Conditional Masking):
    তুলনামূলক অপারেটর প্রয়োগ করলে ট্রু/ফলসের একটি বুলিয়ান অ্যারে তৈরি হয়:
    mask = arr > 50
    তারপর arr[mask] দিলে শুধুমাত্র শর্ত পূরণকারী উপাদানগুলো ফেরত আসে। ডেটা ক্লিনিংয়ে এটি অত্যন্ত শক্তিশালী।
  • ফ্যান্সি ইনডেক্সিং (Fancy Indexing):
    ইনডেক্সের একটি পূর্ণাঙ্গ লিস্ট বা অ্যারে পাঠিয়ে নির্দিষ্ট অর্ডার অনুযায়ী উপাত্ত তুলে আনা:
    arr[[0, 2, 4]] -> ০, ২ ও ৪ নম্বর ইনডেক্সের ভ্যালু।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

indexing_slicing_masking.py 
import numpy as np

# ৫টি পণ্যের ৪ দিনের সেলস ম্যাট্রিক্স (সারি: পণ্য, কলাম: দিন)
sales = np.array([
    [12, 15, 18, 20],
    [5,  8,  4,  10],
    [30, 45, 50, 42],
    [10, 12, 11, 14],
    [2,  3,  1,  4]
])

# ১. বেসিক স্লাইসিং: প্রথম ৩টি পণ্যের শেষ ২ দিনের সেলস
subset = sales[0:3, 2:4]

# ২. কলাম এক্সট্র্যাক্ট: শুধুমাত্র ৩য় দিনের সেলস (কলাম ইনডেক্স ২)
day_3_sales = sales[:, 2]

# ৩. বুলিয়ান মাস্কিং: যে সব সেলস ২০ এর চেয়ে বড় বা সমান
high_sales_mask = sales >= 20
high_sales = sales[high_sales_mask]

# ৪. ফ্যান্সি ইনডেক্সিং: পণ্য ১ ও পণ্য ৩ এর সেলস
selected_products = sales[[0, 2], :]

print("Full Sales Matrix (5x4):\n", sales)
print("\nSubset (Rows 0-2, Cols 2-3):\n", subset)
print("\nDay 3 Sales (All Products):", day_3_sales)
print("\nSales >= 20 (Filtered Values):", high_sales)
print("\nSelected Products (Product 0 and 2):\n", selected_products)

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• sales[0:3, 2:4]: প্রথম প্যারামিটারে রো স্লাইস এবং দ্বিতীয় প্যারামিটারে কলাম স্লাইস নেওয়া হয়েছে।
• sales >= 20: সম্পূর্ণ ম্যাট্রিক্সে বুলিয়ান ট্রু/ফলস মাস্ক তৈরি করে যা কন্ডিশনাল কোয়েরির ভিত্তি।
