সার্বজনীন গণিত ফাংশন: ufuncs, exp, log ও clip প্রজেক্ট ল্যাব (Universal Functions (ufuncs) & Math Lab)

মেশিন লার্নিং অ্যাক্টিভেশন ও লস ক্যালকুলেশনে ব্যবহৃত ফাস্ট ম্যাথমেটিক্যাল ফাংশন। np.exp, np.log, np.sqrt, np.clip এবং নিউমেরিক্যাল স্টেবিলিটি টেকনিক।

01 ধাপ ০১: আন-নরমালাইজড স্কোর ভেক্টর তৈরি

৩টি ক্লাসের জন্য নিউরাল নেটওয়ার্ক লজিটস ভেক্টর ডিফাইন করা।

step_01.py 
import numpy as np
z = np.array([2.0, 1.0, 0.1])
print("Logits:", z)

02 ধাপ ০২: স্টেবল সফটম্যাক্স তৈরি

ম্যাক্স বিয়োগ করে exp(z - max(z)) এর অনুপাত নেওয়া।

step_02.py 
exp_z = np.exp(z - np.max(z))
softmax_probs = exp_z / np.sum(exp_z)
print("Softmax Probabilities:", np.round(softmax_probs, 4))

03 ধাপ ০৩: নেগেটিভ লগ-লাইকলিহুড লস

টার্গেট ক্লাস ০ এর জন্য -log(prob[0]) হিসাব করা।

step_03.py 
loss = -np.log(softmax_probs[0] + 1e-9)
print(f"Categorical Cross Entropy Loss: {loss:.4f}")

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

numpy_ufuncs_math.py 
# --- ধাপ ০১: আন-নরমালাইজড স্কোর ভেক্টর তৈরি ---
import numpy as np
z = np.array([2.0, 1.0, 0.1])
print("Logits:", z)

# --- ধাপ ০২: স্টেবল সফটম্যাক্স তৈরি ---
exp_z = np.exp(z - np.max(z))
softmax_probs = exp_z / np.sum(exp_z)
print("Softmax Probabilities:", np.round(softmax_probs, 4))

# --- ধাপ ০৩: নেগেটিভ লগ-লাইকলিহুড লস ---
loss = -np.log(softmax_probs[0] + 1e-9)
print(f"Categorical Cross Entropy Loss: {loss:.4f}")
