Universal Functions (ufuncs) & Math — সার্বজনীন গণিত ফাংশন: ufuncs, exp, log ও clip

মেশিন লার্নিং অ্যাক্টিভেশন ও লস ক্যালকুলেশনে ব্যবহৃত ফাস্ট ম্যাথমেটিক্যাল ফাংশন। np.exp, np.log, np.sqrt, np.clip এবং নিউমেরিক্যাল স্টেবিলিটি টেকনিক।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

Universal Functions (ufuncs) আর্কিটেকচার

NumPy এর ufunc (Universal Function) হলো এমন ফাংশন যা অ্যারের প্রতিটি উপাদানের ওপর স্বয়ংক্রিয়ভাবে পয়েন্টওয়াইজ (Element-by-element) প্রয়োগ হয়।

  • np.exp(x): প্রতিটি উপাদানের সূচকীয় মান \(e^x\) বের করে (Softmax ও Sigmoid তৈরিতে ব্যবহৃত)।
  • np.log(x): স্বাভাবিক লগারিদম \(\ln(x)\) (Cross-Entropy লস ক্যালকুলেশনে ব্যবহৃত)।
  • np.clip(arr, min_val, max_val): অ্যারের মানগুলোকে নির্দিষ্ট একটি সীমার মধ্যে আটকে রাখে। গ্রেডিয়েন্ট এক্সপ্লোশন বা log(0) এর মতো নিউমেরিক্যাল অস্থিতিশীলতা রোধে এটি অপরিহার্য।
  • np.abs(), np.sqrt(), np.power(): মৌলিক গাণিতিক রূপান্তর।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

numpy_ufuncs_math.py 
import numpy as np

# ১. মডেলের র' লজিট (Logits)
logits = np.array([-2.5, 0.0, 1.2, 3.5, 12.0])

# ২. নিউমেরিক্যালি স্টেবল সিগময়েড অ্যাক্টিভেশন
# Sigmoid(z) = 1 / (1 + exp(-z))
# এক্সট্রিম ভ্যালুর জন্য ক্লিপিং
clipped_logits = np.clip(logits, -10.0, 10.0)
sigmoid_probs = 1.0 / (1.0 + np.exp(-clipped_logits))

# ৩. বাইনারি ক্রস-এন্ট্রপি লস প্রিপারেশন: log(prob)
# log(0) যেন -inf না দেয় সেজন্য এপসিলন যোগ
eps = 1e-7
safe_probs = np.clip(sigmoid_probs, eps, 1.0 - eps)
log_loss_terms = np.log(safe_probs)

print("Original Raw Logits:  ", logits)
print("Clipped Safe Logits:  ", clipped_logits)
print("Sigmoid Probabilities:", np.round(sigmoid_probs, 4))
print("Safe Log Probabilities:", np.round(log_loss_terms, 4))
🖥️ Terminal Output 
Original Raw Logits:   [-2.5   0.    1.2   3.5  12. ]
Clipped Safe Logits:   [-2.5   0.    1.2   3.5  10. ]
Sigmoid Probabilities: [0.0759 0.5    0.7685 0.9707 0.9999]
Safe Log Probabilities: [-2.5786 -0.6931 -0.2633 -0.0297 -0.0001]

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• np.clip(logits, -10.0, 10.0): ১২.০ মানটিকে ১০.০ এ ক্ল্যাম্প করে সূচকীয় ওভারফ্লো ঠেকানো হয়েছে।
• 1.0 / (1.0 + np.exp(-z)): সম্পূর্ণ সিগময়েড ফাংশনটি ভেক্টরাইজড ufunc দিয়ে এক লাইনে ক্যালকুলেট হয়েছে।
