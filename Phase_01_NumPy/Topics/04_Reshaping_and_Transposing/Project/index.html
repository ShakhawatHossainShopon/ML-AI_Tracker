Project Breakdown Phase 01 • Topic 04 Mobile View

রিশেপিং, ট্রান্সপোজিং ও ফ্ল্যাটেনিং প্রজেক্ট ল্যাব (Reshaping, Transposing & Flattening Lab)

মেমোরি কপি না করেই অ্যারের ডাইমেনশন রূপান্তর। reshape(-1), flatten vs ravel এর মেমোরি পার্থক্য এবং নিউরাল নেটওয়ার্ক ইনপুটের জন্য ট্রান্সপোজ (.T ও transpose)।

01 ধাপ ০১: ফ্ল্যাট পিক্সেল স্ট্রিম লোড

২৮x২৮ সাইজের মোট ৭৮৪টি গ্রে-স্কেল পিক্সেল ডেটা তৈরি।

step_01.py 
import numpy as np
pixels = np.random.randint(0, 256, size=784, dtype=np.uint8)
print(f"Loaded raw pixel vector of size {pixels.size}")

02 ধাপ ০২: ইমেজ গ্রিডে রিশেপ

১D ভেক্টরকে 28x28 ইমেজ ম্যাট্রিক্সে রূপান্তর করা।

step_02.py 
image_2d = pixels.reshape(28, 28)
print("Reshaped to 2D Image Grid:", image_2d.shape)

03 ধাপ ০৩: ব্যাচ চ্যানেল ফরম্যাটিং

ডিপ লার্নিং ইনপুট স্ট্যান্ডার্ড (1, 28, 28, 1) শেপে কনভার্ট।

step_03.py 
cnn_input = image_2d.reshape(1, 28, 28, 1)
print("CNN-Ready Tensor Shape:", cnn_input.shape)

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

reshaping_transposing_demo.py 
# --- ধাপ ০১: ফ্ল্যাট পিক্সেল স্ট্রিম লোড ---
import numpy as np
pixels = np.random.randint(0, 256, size=784, dtype=np.uint8)
print(f"Loaded raw pixel vector of size {pixels.size}")

# --- ধাপ ০২: ইমেজ গ্রিডে রিশেপ ---
image_2d = pixels.reshape(28, 28)
print("Reshaped to 2D Image Grid:", image_2d.shape)

# --- ধাপ ০৩: ব্যাচ চ্যানেল ফরম্যাটিং ---
cnn_input = image_2d.reshape(1, 28, 28, 1)
print("CNN-Ready Tensor Shape:", cnn_input.shape)
