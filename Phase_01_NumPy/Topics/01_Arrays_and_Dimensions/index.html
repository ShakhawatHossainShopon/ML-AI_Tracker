Arrays & Dimensions in NumPy — অ্যারে ও ডাইমেনশন: ১D, ২D ও ৩D টেনসর অ্যানাটমি

NumPy ndarray হলো ডিপ লার্নিং ও ডেটা সায়েন্সের মৌলিক ব্লক। ভেক্টর (১D), ম্যাট্রিক্স (২D) ও টেনসর (৩D+) এর মেমোরি লেআউট, shape, size ও dtype ইন্টারনালস।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

NumPy ndarray আর্কিটেকচার ও মেমোরি স্ট্রাকচার

পাইথনের স্ট্যান্ডার্ড list-এর তুলনায় NumPy-এর ndarray (N-dimensional array) বহুগুণ দ্রুত এবং মেমোরি-সাশ্রয়ী। এর প্রধান কারণ ndarray মেমোরিতে একটি একক সংলগ্ন ব্লকে (Contiguous Memory Block) সমজাতীয় (Homogeneous) ডেটা সংরক্ষণ করে।

  • ১D Array (Vector): একটি মাত্র অক্ষ বা Axis 0 থাকে (যেমন: একক অডিও সিগন্যাল বা টাইম-সিরিজ ফিচার)। Shape: (n,)
  • ২D Array (Matrix): দুটি অক্ষ—Axis 0 (সারি/Rows) এবং Axis 1 (কলাম/Columns) (যেমন: টেবুলার ডেটাসেট বা গ্রে-স্কেল ইমেজ)। Shape: (rows, cols)
  • ৩D Array (Tensor): তিনটি অক্ষ—Axis 0 (ব্যাচ বা চ্যানেল), Axis 1 (হাইট), Axis 2 (উইডথ) (যেমন: RGB কালার ইমেজ বা সিকোয়েন্স ব্যাচ)। Shape: (channels, height, width)
  • গুরুত্বপূর্ণ অ্যাট্রিবিউটস:
    arr.ndim: মোট অক্ষের সংখ্যা (ডাইমেনশন)।
    arr.shape: প্রতিটি অক্ষে উপাদানের সংখ্যা।
    arr.size: মোট উপাদানের সংখ্যা।
    arr.dtype: উপাত্তের ধরন (যেমন: int32, float64)।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

numpy_dimensions_demo.py 
import numpy as np

# ১. 1D ভেক্টর (স্টক প্রাইস হিস্ট্রি)
price_vector = np.array([120.5, 122.0, 121.8, 124.5], dtype=np.float32)

# ২. 2D ম্যাট্রিক্স (৩ জন ক্লায়েন্টের ৪টি করে ফিচার)
client_matrix = np.array([
    [25, 50000, 720, 1],
    [34, 85000, 680, 0],
    [45, 120000, 750, 1]
], dtype=np.int32)

# ৩. 3D টেনসর (২টি RGB কালার পিক্সেল ব্যাচ)
image_tensor = np.zeros((2, 3, 3), dtype=np.uint8)

print("--- 1D Vector ---")
print("Shape:", price_vector.shape, "| Dimensions:", price_vector.ndim, "| Total Elements:", price_vector.size)

print("\n--- 2D Matrix ---")
print("Shape:", client_matrix.shape, "| Rows (Axis 0):", client_matrix.shape[0], "| Cols (Axis 1):", client_matrix.shape[1])

print("\n--- 3D Tensor ---")
print("Shape:", image_tensor.shape, "| Dtype:", image_tensor.dtype, "| Memory Bytes:", image_tensor.nbytes)
🖥️ Terminal Output 
--- 1D Vector ---
Shape: (4,) | Dimensions: 1 | Total Elements: 4

--- 2D Matrix ---
Shape: (3, 4) | Rows (Axis 0): 3 | Cols (Axis 1): 4

--- 3D Tensor ---
Shape: (2, 3, 3) | Dtype: uint8 | Memory Bytes: 18

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• price_vector.shape: (4,) যা প্রকাশ করে এটি একটি একক মাত্রার ৪ দৈর্ঘ্যের ভেক্টর।
• client_matrix.shape: (3, 4) প্রকাশ করে ৩টি সারি এবং ৪টি কলামের 2D ম্যাট্রিক্স।
• image_tensor.nbytes: ১৮ বাইট সংলগ্ন মেমোরি ব্যবহার করেছে যা অত্যন্ত সাশ্রয়ী।
