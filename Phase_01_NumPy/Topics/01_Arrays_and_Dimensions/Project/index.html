অ্যারে ও ডাইমেনশন: ১D, ২D ও ৩D টেনসর অ্যানাটমি প্রজেক্ট ল্যাব (Arrays & Dimensions in NumPy Lab)

NumPy ndarray হলো ডিপ লার্নিং ও ডেটা সায়েন্সের মৌলিক ব্লক। ভেক্টর (১D), ম্যাট্রিক্স (২D) ও টেনসর (৩D+) এর মেমোরি লেআউট, shape, size ও dtype ইন্টারনালস।

01 ধাপ ০১: কাঁচা লিস্ট থেকে মাল্টি-ডাইমেনশনাল অ্যারে তৈরি

পাইথন লিস্টকে সংলগ্ন মেমোরি স্পেসে ndarray হিসেবে কনভার্ট করা।

step_01.py 
import numpy as np
raw_sensors = [[10.1, 10.5, 10.2], [11.0, 11.2, 10.9]]
sensor_arr = np.array(raw_sensors, dtype=np.float64)
print("Sensor Matrix:\n", sensor_arr)

02 ধাপ ০২: শেপ এবং মেটাডেটা ইন্সপেকশন

ডিপ লার্নিং লেয়ার ফিডিংয়ের জন্য শেপ এবং সাইজ ভ্যালিডেশন।

step_02.py 
print(f"Shape: {sensor_arr.shape}")
print(f"Item Size: {sensor_arr.itemsize} bytes per float")
print(f"Total Array Memory: {sensor_arr.nbytes} bytes")

03 ধাপ ০৩: ব্যাচ টেনসর এক্সপ্যানশন

নতুন অ্যাক্সিস যোগ করে ব্যাচ ডাইমেনশনে উন্নীত করা।

step_03.py 
batched_data = np.expand_dims(sensor_arr, axis=0)
print("Batched Tensor Shape:", batched_data.shape)

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

numpy_dimensions_demo.py 
# --- ধাপ ০১: কাঁচা লিস্ট থেকে মাল্টি-ডাইমেনশনাল অ্যারে তৈরি ---
import numpy as np
raw_sensors = [[10.1, 10.5, 10.2], [11.0, 11.2, 10.9]]
sensor_arr = np.array(raw_sensors, dtype=np.float64)
print("Sensor Matrix:\n", sensor_arr)

# --- ধাপ ০২: শেপ এবং মেটাডেটা ইন্সপেকশন ---
print(f"Shape: {sensor_arr.shape}")
print(f"Item Size: {sensor_arr.itemsize} bytes per float")
print(f"Total Array Memory: {sensor_arr.nbytes} bytes")

# --- ধাপ ০৩: ব্যাচ টেনসর এক্সপ্যানশন ---
batched_data = np.expand_dims(sensor_arr, axis=0)
print("Batched Tensor Shape:", batched_data.shape)
