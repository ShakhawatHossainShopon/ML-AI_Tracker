Linear Algebra Operations in NumPy — লিনিয়ার অ্যালজেব্রা: ডট প্রোডাক্ট, ইনভার্স ও লিনিয়ার সিস্টেম সমাধান

np.dot, @ অপারেটর, np.linalg.inv এবং np.linalg.solve। লিনিয়ার রিগ্রেশনের নরমাল ইকুয়েশন ও কোসাইন সিমিলারিটি ক্যালকুলেশনে লাইব্রেরির অন্তর্নির্মিত BLAS/LAPACK অ্যাক্সিলারেশন।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

NumPy লিনিয়ার অ্যালজেব্রা (np.linalg) ইঞ্জিন

NumPy লিনিয়ার অ্যালজেব্রা অপারেশনের জন্য ব্যাকএন্ডে অপ্টিমাইজড BLAS/LAPACK লাইব্রেরি ব্যবহার করে।

  • ম্যাট্রিক্স গুণ: @ বনাম *:
    A * B হলো উপাদানভিত্তিক গুণ (Hadamard Product)।
    A @ B বা np.dot(A, B) হলো প্রকৃত গাণিতিক ম্যাট্রিক্স গুণ।
  • ম্যাট্রিক্স ইনভার্স: np.linalg.inv(A):
    \(A \cdot A^{-1} = I\)। শুধুমাত্র নন-সিঙ্গুলার স্কয়ার ম্যাট্রিক্সের ইনভার্স সম্ভব।
  • লিনিয়ার সিস্টেম সমাধান: np.linalg.solve(A, b):
    \(Ax = b\) সমীকরণ সিস্টেম ইনভার্স করার চেয়ে solve() দিয়ে সমাধান করা অনেক বেশি দ্রুত ও নিউমেরিক্যালি স্থিতিশীল।
  • নর্ম গণনা: np.linalg.norm(v):
    ভেক্টরের দৈর্ঘ্য বা জ্যামিতিক দূরত্ব পরিমাপ (L2 Norm)।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

numpy_linear_algebra_demo.py 
import numpy as np

# ১. ম্যাট্রিক্স মাল্টিপ্লিকেশন (A @ B)
A = np.array([[2, 1], [1, 3]], dtype=float)
B = np.array([[4, 2], [1, 5]], dtype=float)

matrix_mult = A @ B

# ২. লিনিয়ার সিস্টেম অফ ইকুয়েশনস সমাধান:
# 2x + y = 8
# x + 3y = 11
b = np.array([8, 11], dtype=float)
solution_x = np.linalg.solve(A, b)

# ৩. ভেক্টর নর্ম ও ডট প্রোডাক্ট
v1 = np.array([3.0, 4.0])
norm_v1 = np.linalg.norm(v1) # sqrt(3^2 + 4^2) = 5.0

print("Matrix A:\n", A)
print("Matrix B:\n", B)
print("-" * 50)
print("Matrix Product (A @ B):\n", matrix_mult)
print("\nSolution to Ax = b [x, y]:", solution_x)
print(f"Norm of vector [3, 4]:     {norm_v1:.2f}")

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• A @ B: ২x২ দুটি ম্যাট্রিক্সের স্ট্যান্ডার্ড রো-কলাম ইনার প্রোডাক্ট হিসাব করেছে।
• np.linalg.solve(A, b): গাউসিয়ান এলিমিনেশন দিয়ে [x=2.5, y=3.0] সমাধান সরাসরি বের করেছে।
