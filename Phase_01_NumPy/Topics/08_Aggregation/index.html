Statistical Aggregations & Axes — পরিসংখ্যানগত অ্যাগ্রিগেশন: axis=0 বনাম axis=1 ও argmax

বহুমাত্রিক ডেটায় রিডাকশন অপারেশন। sum, mean, std, var, min, max এবং ক্লাসিফায়ারের সর্বোচ্চ প্রোবাবিলিটি ক্লাস বের করার জন্য argmax ও argmin এর কার্যকর ব্যবহার।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

অক্ষ-ভিত্তিক (Axis-wise) অ্যাগ্রিগেশন ও রিডাকশন

২D ম্যাট্রিক্সে কোনো পরিসংখ্যান নেওয়ার সময় সবচেয়ে গুরুত্বপূর্ণ প্রশ্ন হলো: আপনি কি প্রতিটি কলামের মান চান, নাকি প্রতিটি সারির মান চান?

  • axis=0 (Vertical Reduction / Column-wise): সারিগুলোকে সংকুচিত করে কলাম বরাবর হিসাব করে।
    যেমন: ১০ জন রোগীর ৩টি টেস্টের গড় (ফলাফল: ৩টি গড় টেস্ট ভ্যালু)।
  • axis=1 (Horizontal Reduction / Row-wise): কলামগুলোকে সংকুচিত করে সারি বরাবর হিসাব করে।
    যেমন: প্রতিটি রোগীর সমস্ত টেস্টের সম্মিলিত গড় (ফলাফল: ১০টি রোগীর গড়)।
  • np.argmax(arr, axis=...): সর্বোচ্চ মানের সূচক বা ইনডেক্স ফেরত দেয়।
    ডিপ লার্নিং ব্যবহার: সফটম্যাক্স প্রোবাবিলিটি অ্যারে থেকে প্রেডিক্ট করা ক্লাস লেবেল বের করতে y_pred = np.argmax(probs, axis=1) ব্যবহৃত হয়!

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

numpy_aggregations_demo.py 
import numpy as np

# ৫ জন ছাত্রের ৩টি বিষয়ের মার্কস ম্যাট্রিক্স
# সারি: ছাত্র, কলাম: [Math, Physics, CS]
scores = np.array([
    [85, 90, 95],
    [70, 65, 80],
    [95, 98, 92],
    [60, 75, 70],
    [88, 85, 90]
])

# ১. অক্ষবিহীন সার্বিক গড়
total_mean = np.mean(scores)

# ২. কলাম বরাবর গড় (axis=0) -> প্রতিটি সাবজেক্টের গড়
subject_means = np.mean(scores, axis=0)

# ৩. সারি বরাবর যোগফল (axis=1) -> প্রতিটি ছাত্রের মোট নম্বর
student_totals = np.sum(scores, axis=1)

# ৪. argmax: কোন ছাত্র সর্বমোট সর্বোচ্চ পেয়েছে
top_student_idx = np.argmax(student_totals)

print("Score Matrix (5x3):\n", scores)
print("-" * 50)
print(f"Overall Class Mean:               {total_mean:.2f}")
print(f"Subject Means [Math, Phys, CS]:   {subject_means}")
print(f"Student Total Marks:              {student_totals}")
print(f"Top Student Index:                Student {top_student_idx} (Total: {student_totals[top_student_idx]})")

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• np.mean(scores, axis=0): Axis 0 সারিগুলোকে ড্রপ করে ৩টি কলামের গড় ভেক্টর আউটপুট দিয়েছে।
• np.argmax(student_totals): সর্বমোট সর্বোচ্চ স্কোরের ছাত্রের ০-বেসড ইনডেক্স ২ (৩য় ছাত্র) নিখুঁতভাবে চিহ্নিত করেছে।
