ব্রডকাস্টিং: মেমোরি কপি ছাড়া অসম ডাইমেনশনে অপারেশন প্রজেক্ট ল্যাব (Broadcasting Rules & Mechanics Lab)

NumPy-এর সবচেয়ে যাদুকরী ফিচার। ভিন্ন শেপের দুটি অ্যারের মধ্যে লুপ বা মেমোরি ডুপ্লিকেশন ছাড়াই কীভাবে এলিমেন্টওয়াইজ গাণিতিক অপারেশন সম্ভব হয় তার রুলস ও অ্যাপ্লিকেশন।

01 ধাপ ০১: ব্যাচ ফিচার ম্যাট্রিক্স লোড

৫ জন রোগীর রক্তচাপ ও পালস রেটের ডেটাসেট তৈরি।

step_01.py 
import numpy as np
vitals = np.array([
    [120, 80, 72],
    [140, 90, 85],
    [115, 75, 68],
    [130, 85, 78],
    [155, 95, 90]
], dtype=np.float64)
print("Patient Vitals:\n", vitals)

02 ধাপ ০২: ফিচার মিন ও সিগমা হিসাব

প্রতিটি ভাইটালের গড় ও স্ট্যান্ডার্ড ডেভিয়েশন ভেক্টর বের করা।

step_02.py 
v_mean = np.mean(vitals, axis=0) # Shape: (3,)
v_std = np.std(vitals, axis=0)   # Shape: (3,)
print("Feature Means:", np.round(v_mean, 1))
print("Feature Stds: ", np.round(v_std, 1))

03 ধাপ ০৩: ব্রডকাস্টেড স্ট্যান্ডার্ডাইজেশন

ভেক্টর বিয়োগ ও ভাগ করে স্ট্যান্ডার্ডাইজড Z-ম্যাট্রিক্স তৈরি।

step_03.py 
z_vitals = (vitals - v_mean) / v_std
print("Standardized Vitals Matrix (Mean 0, Std 1):\n", np.round(z_vitals, 2))

০৪ সম্পূর্ণ কার্যকর কোড ও মোবাইল সামারি

numpy_broadcasting_demo.py 
# --- ধাপ ০১: ব্যাচ ফিচার ম্যাট্রিক্স লোড ---
import numpy as np
vitals = np.array([
    [120, 80, 72],
    [140, 90, 85],
    [115, 75, 68],
    [130, 85, 78],
    [155, 95, 90]
], dtype=np.float64)
print("Patient Vitals:\n", vitals)

# --- ধাপ ০২: ফিচার মিন ও সিগমা হিসাব ---
v_mean = np.mean(vitals, axis=0) # Shape: (3,)
v_std = np.std(vitals, axis=0)   # Shape: (3,)
print("Feature Means:", np.round(v_mean, 1))
print("Feature Stds: ", np.round(v_std, 1))

# --- ধাপ ০৩: ব্রডকাস্টেড স্ট্যান্ডার্ডাইজেশন ---
z_vitals = (vitals - v_mean) / v_std
print("Standardized Vitals Matrix (Mean 0, Std 1):\n", np.round(z_vitals, 2))
