Vectorization vs Python For-Loops — ভেক্টরাইজেশন: পাইথন লুপ দূর করে শতগুণ দ্রুত কম্পিউটিং

সি-লেভেল ভেক্টরাইজেশন ও SIMD প্যারালালেলিজম। কোটি কোটি উপাদানের হিসাব পাইথন লুপ বনাম NumPy ভেক্টরাইজেশনে চালানোর স্পিড কম্প্যারিজন এবং কোডিং বেস্ট প্র্যাকটিস।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

ভেক্টরাইজেশন কেন নাটকীয়ভাবে দ্রুত?

সাধারণ পাইথন লুপে প্রতি ইটারেশনে ডাইনামিক টাইপ চেকিং এবং গ্লোবাল ইন্টারপ্রেটার লক (GIL) ওভারহেড থাকে।

  • ভেক্টরাইজেশন (Vectorization):
    এটি পুরো অপারেশনকে কমপাইল্ড সি (C) কোডে পুশ করে দেয়। আধুনিক সিপিইউ-এর SIMD (Single Instruction, Multiple Data) প্রসেসর রেজিস্টার ব্যবহার করে একসাথে ৪ থেকে ৮টি ফ্লোট প্রসেস করা যায়।
  • পারফরম্যান্স পার্থক্য:
    একই গাণিতিক কাজ ভেক্টরাইজেশনে সম্পন্ন করলে পাইথন লুপের চেয়ে সাধারণত ৫০x থেকে ২০০x গুণ দ্রুত ফলাফল পাওয়া যায়!
  • রুল অব থাম্ব: ডেটা সায়েন্সে কখনো অ্যারের উপাদানের ওপর পাইথন for loop চালাবেন না—সর্বদা ভেক্টরাইজড এক্সপ্রেশন লিখুন।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

vectorization_benchmark.py 
import numpy as np
import time

# ১ মিলিয়ন (১০ লাখ) সংখ্যার ডেটাসেট
size = 1000000
a = np.random.rand(size)
b = np.random.rand(size)

# ১. পাইথন ফর-লুপ মেথড
start_loop = time.time()
loop_result = [a[i] * b[i] + 2.5 for i in range(size)]
loop_time = time.time() - start_loop

# ২. NumPy ভেক্টরাইজড মেথড
start_vec = time.time()
vec_result = a * b + 2.5
vec_time = time.time() - start_vec

speedup = loop_time / max(vec_time, 1e-9)

print(f"Dataset Size:           {size:,} elements")
print(f"Python For-Loop Time:   {loop_time:.4f} seconds")
print(f"NumPy Vectorized Time:  {vec_time:.4f} seconds")
print("-" * 50)
print(f"Speedup Factor:         {speedup:.1f}x Faster with NumPy!")
🖥️ Terminal Output 
Dataset Size:           1,000,000 elements
Python For-Loop Time:   0.3125 seconds
NumPy Vectorized Time:  0.0031 seconds
--------------------------------------------------
Speedup Factor:         100.8x Faster with NumPy!

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• vec_result = a * b + 2.5: কোনো লুপ ছাড়া এক লাইনে ১০ লাখ উপাদানের গুণ ও যোগ সম্পন্ন হয়েছে।
• 100.8x Faster: সি-লেভেল মেমোরি অ্যাক্সেসের কারণে এক্সিকিউশন সময় ৩১২ মিলিসেকেন্ড থেকে কমে মাত্র ৩ মিলিসেকেন্ডে নেমে এসেছে।
