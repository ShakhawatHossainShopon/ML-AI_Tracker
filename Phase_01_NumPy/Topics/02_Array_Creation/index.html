Array Creation Routines in NumPy — অ্যারে তৈরির আধুনিক মেথড: zeros, ones, arange ও linspace

ম্যানুয়াল লিস্ট ছাড়াও অ্যালগরিদমিক প্রয়োজনে ইনিশিয়ালাইজেশন। np.zeros, np.ones, np.arange, np.linspace এবং np.eye দিয়ে আইডেন্টিটি ম্যাট্রিক্স ও রেঞ্জ গ্রিড তৈরি।

০১ থিওরি ও মূল কনসেপ্ট (Theory & Core Concepts)

ফ্যাক্টরি ফাংশন দিয়ে অপ্টিমাইজড অ্যারে তৈরি

মেশিন লার্নিং ও সায়েন্টিফিক কম্পিউটিংয়ে বড় বড় অ্যারে হাতে লিখে তৈরি করা অসম্ভব। NumPy এর অন্তর্নির্মিত ফ্যাক্টরি ফাংশনগুলো মুহূর্তের মধ্যে প্রয়োজনীয় শেপ ও টাইপের অ্যারে বরাদ্দ (Allocate) করে।

  • np.zeros(shape): সব উপাদান 0 দিয়ে পূর্ণ অ্যারে তৈরি করে (যেমন: ওয়েট ইনিশিয়ালাইজেশনের পূর্ববর্তী বাফার)।
  • np.ones(shape): সব উপাদান 1 দিয়ে পূর্ণ অ্যারে তৈরি করে (যেমন: বায়াস ভেক্টর)।
  • np.full(shape, fill_value): নির্দিষ্ট কোনো কনস্ট্যান্ট মান দিয়ে অ্যারে ভর্তি করা।
  • np.arange(start, stop, step): পাইথন range()-এর সমতুল্য কিন্তু ফ্লোটিং-পয়েন্ট স্টেপ সাপোর্ট করে।
  • np.linspace(start, stop, num): একটি নির্দিষ্ট সীমার মধ্যে সমান দূরত্বে অবস্থিত num সংখ্যক বিন্দু তৈরি করে (কার্ভ প্লটিং ও অপ্টিমাইজেশনে অপরিহার্য)।
  • np.eye(N): \(N imes N\) সাইজের আইডেন্টিটি ম্যাট্রিক্স তৈরি করে যার প্রধান কর্ণে ১ এবং বাকি সব জায়গায় ০ থাকে।

০২ বাস্তব কোড উদাহরণ (Real-World Code Example)

array_creation_routines.py 
import numpy as np

# ১. 0 এবং 1 দিয়ে ইনিশিয়ালাইজেশন
zeros_bias = np.zeros((3, 1), dtype=np.float32)
ones_filter = np.ones((2, 2), dtype=np.float32)

# ২. arange বনাম linspace
step_range = np.arange(0, 10, 2.5)   # [0, 2.5, 5.0, 7.5]
linear_grid = np.linspace(0, 1, 5)   # [0.0, 0.25, 0.5, 0.75, 1.0]

# ৩. আইডেন্টিটি ম্যাট্রিক্স
identity_mat = np.eye(3)

print("Zeros Bias (3x1):\n", zeros_bias)
print("\nOnes Filter (2x2):\n", ones_filter)
print("\narange(0, 10, 2.5):", step_range)
print("linspace(0, 1, 5): ", linear_grid)
print("\nIdentity Matrix 3x3:\n", identity_mat)
🖥️ Terminal Output 
Zeros Bias (3x1):
 [[0.]
 [0.]
 [0.]]

Ones Filter (2x2):
 [[1. 1.]
 [1. 1.]]

arange(0, 10, 2.5): [0.  2.5 5.  7.5]
linspace(0, 1, 5):  [0.   0.25 0.5  0.75 1.  ]

Identity Matrix 3x3:
 [[1. 0. 0.]
 [0. 1. 0.]
 [0. 0. 1.]]

💡 কোড বিশ্লেষণ ও ব্যাখ্যা (Line-by-Line Breakdown):

• np.linspace(0, 1, 5): 0 থেকে 1 এর মধ্যে সুষম ব্যবধানে ঠিক ৫টি স্যাম্পল জেনারেট করে।
• np.eye(3): লিনিয়ার অ্যালজেব্রার আইডেন্টিটি অপারেশনের জন্য নিখুঁত ডায়াগোনাল ম্যাট্রিক্স প্রস্তুত করে।
